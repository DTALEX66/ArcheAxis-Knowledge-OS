## 1. 官方一句话定位

> 本地优先、支持多格式资料整理、多源联网检索比对与持续纠错的人机双向知识与学习工作台。

完整长版：**将个人资料、模型识别结果与公开知识组织在同一工作台：保留原件便于回查，优先复用成熟组件和百科、社区／论坛、学术检索接口，对照多个来源发现误识别、补充与分歧，持续修订并支持知识展示、人的学习与 AI 复用，逐步完善开放互操作和长期学习能力。**

来源、原件和模型输出均可比较与修订，不预设单一来源具有高权威或唯一性。“可信”体现可回查、可比较、可纠错及清楚的使用状态。普通内容可以先保存、展示和学习；多源结果、联网失败与专业场景下的进一步判断分别呈现。保存原件与后续版本便于定位错误，不将原件中陈述默认当作事实真值。定位是目标，当前实际接口与能力状态沿活动指针核实。

## 2. 系统级定义与反漂移边界

**是**：从资料摄入、原件资产、转换、证据、知识、人类深度学习、可调用/可复用 AI 学习资产、视觉表征、空间学习、开放互操作、备份/同步到撤销治理的一体化数据与体验系统。

**不等于**：通用操作系统、通用 Agent Runtime、自治工作流平台、多 Agent 产品、Obsidian 克隆、轻量 PDF 工作台。

## 3. 两条同时成立的路线

```text
当前 Release Spine（必须先可靠）
真实 PDF/多格式 → 原件保全 → 可解释转换 → 阅读/编辑 → 证据锚点
→ 开放 Vault 往返 → 人类学习 ↔ AI 资产双向学习最小闭环 → 稳定单用户桌面版

完整系统蓝图（必须永久保留）
研究与知识生产 → 完整学习方法 → 课程/动态视觉/动画/仿真
→ 2D/2.5D/3D 空间记忆 → VR/AR → 多设备/扩展/可选协作
```

deferred ≠ deleted；binding_long_term ≠ 当前 Release required；exploration ≠ 产品承诺。

## 4. 固定一级空间

`Workspace、Library、Evidence、Learning、AI Assets、Settings`

- 聊天/执行器/Agent 只能是受控可选 Adapter，**不能成为默认首页或可信知识来源**
- 第三方品牌（Obsidian 等）只出现在适配器/兼容说明

## 5. 七条产品内核

1. 本地优先与数据主权
2. 原件优先与可重建派生物（OCR/ASR/摘要/索引/向量/可视化 = 可删除派生物）
3. 多源检索比对、持续纠错与可修订知识
4. 人机双向双学习（共享可信基底，分别评估，双向回流 Candidate Review）
5. 开放格式与不锁定（版本化 Adapter、完整导出、损失报告、回滚）
6. 全生命周期治理（摄入→转换→核验→沉淀→学习→调用→修订→失效→归档）
7. 视觉/空间能力是正式学习层（不被删除，但受来源/fallback/性能/无障碍/学习证据约束）

## 6. 四条绝对分层

```text
文件存在                ≠ 文件中陈述为真
转换/OCR/ASR 质量       ≠ 内容事实准确性
AI 生成候选             ≠ 已批准知识或 AI 资产
UI 出现/源码存在        ≠ 安装版真实可用或已发布
```
