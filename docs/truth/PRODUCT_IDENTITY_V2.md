## 1. 官方一句话定位

> 本地优先的个人 Human–AI 双向知识与学习工作台：以资料与知识对象为中心，贯通多格式整理、多源比较、学习与表达和 AI 资产复用。

完整长版：**以资料、知识、研究问题、学习活动和AI资产为持久对象，复用统一来源、固定版本、关系与权限。人从收集、阅读和多源比较进入知识整理、学习表达、实践记录、反馈复习；AI从经验候选进入审查、授权采用、实际使用、纠正与独立复测。上下文任务Agent在既有工作区协助检索、计划、解释和操作，结果回到已有对象；不以聊天历史替代正文、活动或业务状态。成熟引擎、课程播放器、开放文件/API优先适配，专业制作与执行默认留在外部工具；AAOS承接计划、可选成果、版本和复盘。两侧共享知识底座，内容校验、人类掌握与AI采用分别评估，并通过重启、导出、恢复持续使用。**

来源、原件和模型输出均可比较与修订，不预设单一来源具有高权威或唯一性。“可信”体现可回查、可比较、可纠错及清楚的使用状态。普通内容可以先保存、展示和学习；多源结果、联网失败与专业场景下的进一步判断分别呈现。保存原件与后续版本便于定位错误，不将原件中陈述默认当作事实真值。定位是目标，当前实际接口与能力状态沿活动指针核实。

## 2. 系统级定义与反漂移边界

**是**：从资料摄入、原件资产、转换、证据、知识、人类深度学习、可调用/可复用 AI 学习资产、视觉表征、空间学习、开放互操作、备份/同步到撤销治理的一体化数据与体验系统。

**不等于**：通用操作系统、通用 Agent Runtime、自治工作流平台、多 Agent 产品、Obsidian 克隆、轻量 PDF 工作台。

## 3. 两条同时成立的路线

```text
当前 Release Spine（按新任务包验收）
常用多格式 → 原件/固定版本 → 可用转换/定位 → 阅读/整理/多源比较 → 知识修订
→ 人的学习/表达/外部实践计划与记录/反馈复习 ↔ AI候选/采用/实际使用/纠正复测
→ 四消费者当前性一致 → 重启/导出/恢复 → 同候选可靠单用户桌面版

完整系统蓝图（必须永久保留）
研究与知识生产 → 完整学习方法 → 课程/动态视觉/动画/仿真
→ 2D/2.5D/3D 空间记忆 → VR/AR → 多设备/扩展/可选协作
```

deferred ≠ deleted；binding_long_term ≠ 当前 Release required；exploration ≠ 产品承诺。

Release Spine覆盖新包X1—X8与原CL/J的本期required；不会以PDF代表全部格式，也不会把远期空间/设备/扩展全部变成本期前置。

## 4. 五个稳定入口与共享辅助入口

`工作台、资料与知识、研究与比较、学习与表达、AI助手`

资源与交换、导入导出、全部能力、设置和版本来源保留为固定辅助入口/上下文工具。22个历史page ID与内部SpaceId是路由身份，不强制改造成五个新领域，不按186细项新增页面。旧六空间枚举不再规定当前主导航；既有对象和数据不因导航归并删除。

AI助手包括会话与任务，以及AI知识/评测等子区；不能只改标签而没有实际消费者。正文、学习活动与作品为主，助手按需展开。新型活动允许局部renderer或外部启动/结果导入，不承诺所有扩展永远零前端修改。当前UI暂停不因文档更新恢复。

专业软件用于外部制作和执行。首版L0教程链接、计划与人工文字记录可独立完成；成果文件/预览和L1导入可选，L2 API/MCP/插件按实际价值、版本、方向和授权逐项接入，L3复杂自动执行仍独立准入。AAOS不重建专业编辑器、完整IDE或科研运行平台，WORK-LAB保持可选。

## 5. 七条产品内核

1. 本地优先与数据主权
2. 原件优先与可重建派生物（OCR/ASR/摘要/索引/向量/可视化 = 可删除派生物）
3. 多源检索比对、持续纠错与可修订知识
4. 人机双向双学习（共享可信基底，分别评估，双向回流 Candidate Review）
5. 开放格式与不锁定（版本化 Adapter、完整导出、损失报告、回滚）
6. 全生命周期治理（摄入→转换→核验→沉淀→学习→调用→修订→失效→归档）
7. 视觉/空间能力是正式学习层（不被删除，但受来源/fallback/性能/无障碍/学习证据约束）

## 6. 四条绝对分层

```text
文件存在                ≠ 文件中陈述为真
转换/OCR/ASR 质量       ≠ 内容事实准确性
AI 生成候选             ≠ 已批准知识或 AI 资产
UI 出现/源码存在        ≠ 安装版真实可用或已发布
```
