## 本轮关闭的问题

不可改写的 `v0.6.0` 至 `v0.6.6` 历史标签保留。逐轮暴露并关闭：

1. 发布身份注入晚于安装器构建；
2. schema v3 生产者、运行时消费者与读回器契约漂移；
3. ZIP Python 路径未规范化；
4. ZIP 窗口关闭沿用 `CloseMainWindow()` 导致竞争；
5. Portable 数据库验收多加一层 `data/`；
6. 版本替换误改第三方 `socket2` 锁定版本；
7. PowerShell `"$entry.Name"` 未使用子表达式，生成假锁文件路径。

最终修复使用 `"$($entry.Name)"` 并增加工作流合同回归测试；v0.6.7
随后通过完整构建、安装生命周期和资产读回。
