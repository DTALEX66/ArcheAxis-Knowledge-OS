## 助手建议与证据边界

- 建议Dock六入口：工作台、知识、研究、学习、全部能力、小栖；具体排列不是逐项签收的固定规格。
- 建议按功能族复用双链／大纲／集合视图／画布／练习复习，不能因此声称某款软件全功能或原生插件已兼容。
- 建议原件先保全，知识接纳单列；这是现行普通保存原则的继续，不新增保存审批。
- 语音输入、朗读、唤醒与音视频资料转写分开；小栖不整体接入另一套Jarvis运行时、记忆库、调度器或Ollama。
- 两份历史文档的产品命名／技术栈／静态代码分析基线由现行规范接续；六项差异化增量继续冻结，不因阅读而激活。
- 调研报告中的仓库存在、stars、网络TCP/TLS可达、演示及工期估计，不等于AAOS真实消费者、许可适用、调用成功或产品验收。
- 当前原生阅读工具可达性FAIL、本地模型无最终答案、云端NOT_EXECUTED及同候选／安装／Owner验收缺口继续保留；本次未重跑这些测试。
