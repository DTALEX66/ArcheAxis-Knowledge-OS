## 10. 人类学习与机器学习历史主线
### 10.1 9/7 四层算法核
```text
Hybrid Retrieval: FTS5/BM25 + Embedding + Cross-Encoder Reranker
Evidence: Atomic Claim + support/contradict/insufficient/contested + independence/temporality
Human Learning: FSRS → later BKT
Machine Learning: model disagreement + human gold + data-quality audit
```
### 10.2 Learning Compiler
```text
RawAsset → Conversion/Quality → Claim + Evidence + KnowledgeUnit
         → PedagogicProfile / prerequisites / misconceptions
         → LearningRecipe
         → Visual / Animation / Simulation / Practice / Memory / Teach-back
         → LearningEvent → FSRS/BKT/Feedback → next Recipe
```
### 10.3 核心边界
- `Mastery != Truth`；人的掌握不证明事实为真。
- `Model confidence != Evidence`；模型置信度不等于证据充分。
- Learning Asset / AI Asset 都是派生对象，必须可追溯到 Claim/Evidence/RawAsset。
- 人工纠错和 AI 观察先成为 Candidate，再经 review；不能自动改写真值。
