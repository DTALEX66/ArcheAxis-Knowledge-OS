# AAOS UI 深度调整包 · 2026-10-02

本包把已有正式桌面界面收敛为六大空间，并保留全能力菜单。先打开 `preview/index.html` 查看交互，再把 `prompts/01_主执行提示词.txt` 和整个包交给本地执行器。

正式产品继续采用 C#/Avalonia + Rust Core + 隔离 Python worker。本包交付的是可复刻的界面规格、离线高保真参考、迁移数据和执行任务；没有修改你的 Windows 工作树、合并 PR、安装插件或更新绿色版。

## 这次调整了什么

- 六大空间：工作台、资料与知识、证据、学习、机器知识、系统。
- 50 个菜单入口，覆盖 16 个 Capability Atlas 能力家族；保留未来能力，并标出待开发、待接入、部分接通或待核验。
- 未来菜单可打开说明、依赖、前置条件、完成条件和开发提醒。未接通的执行按钮保持不可用。
- 19 个既有命令路由全部保留；阅读、编辑和对象详情按对象上下文打开。
- 全局 Inspector 统一展示来源、证据、版本、关系和历史。活动区保留处理与收据入口。
- 阅读、复习、AI 纠错贯通同一资料语境；词法搜索、语义检索和问答分别显示能力状态。
- 沿用 Aurora Teal 与黑白深色主题；收敛高频视觉噪声、巨型 KPI 和重复面板。

## 文件怎么用

| 位置 | 用途 |
|---|---|
| preview/index.html | 离线高保真多工作面，双击即可打开；无需联网或安装依赖 |
| screenshots/ | 页面布局与两种主题的截图，作为复刻目标 |
| specs/ | 信息架构、组件行为、未来能力、逐页迁移与验收 |
| integration/ | 导航/能力登记、路由映射、设计令牌和原生资源片段 |
| prompts/ | 可直接复制给 Codex、Hermes 或 DSH 的执行提示词 |
| evidence/ | 输入时点、源文件摘要与本次预览检查结果 |

截图与 HTML 始终标注固定样例。预览交互没有调用真实后端、没有模型调用、没有文件上传、没有 localStorage 写入。它们是实施参考，不能作为正式桌面、FSRS、机器学习或 Green 已验收证据。

本包沿现行 R6 / M0 实施，不另立 R7 权威。菜单保留长期能力不等于立即开发全部能力。先把同一真实资料贯穿导入、阅读、证据、知识、学习、机器纠错与重启读回，再逐步点亮未来入口。

截图：14个主要工作面 + 2张黑白主题 + 3张响应式阅读，共19张。预览关键交互、50菜单导航及320–2560宽回退检查已通过；这不替代Windows原生验收。
