# 未来能力不是失效按钮

最新要求：未来全能力和保留能力加入菜单，提示待开发，并提醒开发者遗漏的能力。本包落实为 50 项登记、16 家族覆盖与独立能力详情页。

## 能力详情必须包含

能力名与 canonical capability_id、所属空间、永久核心/长期/探索保留、开发状态、运行状态、最后核验时点与证据、用户价值、现有可复用基础、缺失接口、前置依赖、回退方式、验收条件、下一条开发任务。

普通使用者默认看能力说明、状态和下一步；开发者展开权威映射、需求 ID、合同与证据。未开发能力的执行按钮不可用，但可查看说明、来源、复制开发提醒。

## 全能力扩展规则

目前 16 家族是本次实际读取 Atlas 的完整集合，不代表恢复了所有本地未上传规划。新的历史条目或细分能力进入已有登记入口，以 capability/requirement/origin 追溯，不另建一份独立事实库。

目录包括原件、多格式、交叉证据、人类深度学习、AI 学习资产、LER、动画仿真、空间/沉浸、研究课程项目、互操作、搜索图谱、桌面与协作、受控探索、备份同步发布、模型治理、学习可视化。Teach-back、学习画像、领域包、Rule/Standard/Skill/Context、跨软件适配作为家族中的细分菜单继续保留。

CAP-0130 的 sandbox、trace、cancel、rollback 属于受控探索说明，不在产品主导航新增 Agent Fleet、Runtime 或 MCP Console。外部软件、开源供体和模型厂商列在对应能力的依赖/适配详情，不每个做一级菜单。

开发者核对清单：已接线但未验收不能标完成；有后端但没有正式入口标待接入；未知运行状态标待核验；无真实服务不提供成功反馈；完成开发需实际接线、失败恢复、真实数据、原生交互、重启读回与证据绑定，再更新状态。

“未来入口”本身可先完整落地，并不要求同步实现全部未来后端。当前执行仍围绕最短真实闭环，菜单提醒不能再次扩大本轮范围。
