## 本次逐页调整

| 工作面 | 深化后的主视区 | 主要状态与交互 |
|---|---|---|
| Home | 继续学习/最近资料/待复核/待纠错，统计辅助 | 空、离线、处理失败；快捷入口跳同一对象 |
| Capture | 来源接入、原件状态、转换质量、可恢复失败 | 接收≠完成；原件保留，取消与重试等回读 |
| Library | 真实资料列表、空间、状态、版本、查询 | 选中看 Inspector，打开阅读；空结果不是错误 |
| Reader | 正文、结构、锚点、来源上下文 | 引用回跳、选区候选、对象版本校验 |
| Evidence | 待复核与认可，后续冲突/交叉核验 | 人工审核后读回；候选不能自动变认可 |
| Knowledge | 内容+证据+人工认可+版本 | 新修改形成候选，历史版本与原件不覆盖 |
| Search | 词法结果与来源、问答能力独立 | 未接通问答/向量不显示伪成功或随机分数 |
| Learning | 学习目标、来源、下一题与状态依据 | 不以复习排程代替掌握判断 |
| Review | 单题、独立作答、揭示依据、评分、收据 | 无重复提交；失败保留答案和幂等身份 |
| Machine | 任务输入/输出、使用知识版本、错误 | 当前已有读回；真实模型与写入仍需接通 |
| Correction | 输出差异、人工修正、审核、独立复测 | 人工确认不自动训练模型或升级技能 |
| Plugins/Models | 能力健康、默认、回退、版本与回滚 | 未接通状态标未知，停用不能再被调用 |
| Future Detail | 能力定义、保留级别、依赖、完成条件 | 能看说明/复制提醒，执行按钮待开发 |

路由迁移不自动迁移数据库或修改 Core HTTP 契约。先建立导航兼容映射，再逐页复用已有 handler、身份校验和状态读回；发现缺口记录待接入，不创造未经验证的生产 API。
