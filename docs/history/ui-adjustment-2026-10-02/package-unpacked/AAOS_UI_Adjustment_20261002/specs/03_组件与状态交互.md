# 组件与状态交互

## Inspector：对象语义统一，详情按类型变化

始终有来源、版本、关系、历史、状态五类信息。Source 增加原件与转换；Knowledge 增加资格化、人工认可和覆盖关系；Evidence 增加原文位置和引用；Learning 增加问题、知识版本、作答与排程；MachineTask 增加实际模型、输入、输出、纠错与复测。

常规界面显示来源名、时间、可读版本和状态，不堆 raw ID、完整 hash 或 token。完整身份留在高级/开发详情；权限由 Core 决定，不从 UI 文案推导。引用点击定位并核对 source/transform/anchor；失效定位显示明确原因，不回跳到随机页。

## 状态分为三条独立轴

| 状态轴 | 例子 | 真值来源 |
|---|---|---|
| 开发状态 | 待开发、部分接通、待核验、已验收 | 现行 R6 台账与对应 SHA/验收证据 |
| 运行状态 | 可用、降级、不可用、未知 | 当前 Core/Provider 健康与能力投影 |
| 对象状态 | 原件已保全、知识候选、人工认可、已弃用 | 具体对象与版本的持久化状态 |

“待接入”用于有历史构件/现有 UI 路由但没有正式生产接口的工作面；“待开发”用于规划保留且尚未证明实现的细分能力；“待核验”用于已有构件但本次尚无完整验收；“探索保留”用于 CAP-0130，不能被误写成核心自治平台。

展示表不得把 Atlas 的 supported 自动映射为当前产品可用。Atlas 含历史 Tauri 字段，当前正式宿主仍是 Avalonia；旧字段保留追溯，新菜单适配按现行权威处理。

## 交互与失败恢复

- 导入：接收后保留 source/job 身份。转换失败时显示来源已保全、失败原因、可用回退和重试条件。发出取消请求后先显示“取消请求已发送”，最终状态等回读。
- 候选：创建后显示待复核；人工审核 POST 后重新读 V3/qualification。403 显示权限问题，404 分辨未知对象/未注册接口，409 提示版本或幂等冲突。
- 搜索：200+空数组显示无结果；请求失败保留查询。当前只有词法接口，问答与语义能力独立标状态。
- 学习：答案和提示使用记录保留。评分展示依据，不把 FSRS due 或模型置信度当掌握百分比。提交后凭 event/assessment/knowledge version 读回；读回失败保留幂等身份与答案。
- 纠错：原输出与修改并列，确认弹窗说明影响对象与版本。确认不直接升级 Memory/Rule/Skill，复测另有身份与结果。
- Provider：修改 default/fallback/enable 前核对 capability/generation；提交失败回滚 UI 临时状态。停用的 Provider 不再被选中，重启读回设置一致。
- 空状态提供唯一下一步；错误状态有原因和恢复；不可用状态给出能力要求；未知状态不能改写成零或健康。

## 键盘与可访问性

Ctrl+K 打开命令搜索；保留既有中文/英文别名，未来能力同样可检索。Esc 关闭弹层、恢复发起控件焦点；Tab 按视觉顺序。原生控件公开正确 AutomationProperties.Name/Pattern，焦点与选中区分。长标题可换行或合理省略并提供完整名称；不只靠 tooltip 呈现关键条件。中文 IME 组合输入不触发提交。

列表虚拟化、封面按需加载，长正文延迟加载，批量状态刷新节流。正式 native 交互以 Windows 当前 Candidate 实测，不以本包 Web 预览通过代替。
