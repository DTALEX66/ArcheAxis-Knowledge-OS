# 实施顺序

| 切片 | 工作 | 退出条件 |
|---|---|---|
| U0 | 核对本地/主干/PR、dirty/untracked/工具链与前端owner | 不丢本地成果，锁定实际测试对象 |
| U1 | 导航登记、六空间、旧route/alias兼容、50项能力菜单 | 19路由兼容、16家族完整；未来详情可访问 |
| U2 | Shell、主题、Inspector、活动区、键盘与DPI | 同一组件语言，窄窗口不裁切 |
| U3 | Library→Reader→Evidence→Knowledge→Search | 同一真实资料、来源、锚点、审核与读回 |
| U4 | Learning→Review | 真人作答、知识版本、排程与重启一致 |
| U5 | Machine→Correction→Retest | 实际模型与实际错误；缺接口诚实不可用 |
| U6 | Provider、Backup/Restore和当前候选 | 生命周期、隔离恢复、完整用户旅程 |

每个切片原生运行、截图、交互和必要回读后，再更新现有 R6 状态。只写 task-owned 修改，单文件 single writer。不先启动全量 MVVM 重写；在真实页面切片中抽取组件与职责。

本包 PNG 是可复刻的布局目标，不是像素绝对锁死。针对 Windows 原生控件、DIP、中文字体与已有真实内容做合理适配；无依据的功能、占位图表、固定KPI和模拟成功不能进入产品。

UIA证据必须绑定当前Candidate，不复用旧DLL证据。Headless/Web预览只检查参考实现，不证明原生Avalonia点击、IME、DPI、真实数据与安装状态。

本任务未授权merge、发布、替换Green或修改用户全局配置。完成具体、可审阅的候选和证据后，按现有R6流程处理相应Owner决策；已有授权的可逆UI工作继续完成。
