# 信息架构与布局调整

## 一级空间

| 空间 | 日常目标 | 保留与未来 |
|---|---|---|
| 工作台 | 继续当前资料、学习与待处理事项 | 活动和处理记录；避免万能 KPI 看板 |
| 资料与知识 | 捕获→资料→阅读→知识→搜索 | 多格式质量、Vault/软件适配、研究、语义检索、引用图谱 |
| 证据 | 人工复核、证据定位与认可 | 交叉核验、冲突、覆盖关系 |
| 学习 | 今日学习、练习与复习 | 掌握状态、课程、Teach-back、画像、LER、动画、仿真、空间记忆、2D/2.5D/3D/VR/AR、领域包 |
| 机器知识 | 任务读回、输出核验和纠错 | 复测、AI Memory、Rule/Standard、Skill、Context Pack、评测/调用审计、人机互学 |
| 系统 | 插件/Provider、模型、恢复与设置 | 全能力目录、数据出境、多设备、同步/导出、可选协作、安装/发布、受控执行探索 |

“蓝图”保留在系统全能力目录，同时长期能力直接出现在所属空间的二级菜单。避免只有一个隐藏蓝图入口；也避免将每个未来模块升成一级空间。

六空间保留历史语义。前一轮提出的“5 产品域 + System”是概念建议，本包以已存在的六空间为基础深化：Evidence 保留独立治理入口，Source/Knowledge/Anchor 详情进入 Inspector。

## 导航的具体规则

1. 默认显示六个有文字的一级空间，不把 19 个路由平铺到左侧，不只保留无标签圆点。
2. 只展开当前空间的二级导航，分别呈现当前工作面和“保留与未来能力”。未来分组默认展开，可滚动、可由用户收起；开发检查模式必须能全部展开。
3. 每个未来项能打开能力详情页。菜单与说明页可用，业务执行不可用。菜单不做灰色不可点击死入口。
4. `source-reader` 和 `original-editor` 作为来源对象工作面，旧命令/路由仍可导航。没有所选对象时显示选择来源，不创建虚构对象。
5. 对象树按资料/项目/文档结构生成。第三级是选中的真实对象、版本或锚点，不是另一份功能菜单。
6. Search 为资料与知识中的工作面，Ctrl+K 为跨空间命令与入口搜索；支持中文、英文别名和“待开发”能力检索。
7. 每个功能只有一个 canonical 菜单入口。首页快捷入口、Inspector 引用、全能力目录均跳转同一登记项，不复制页面或事实库。
8. 返回保留空间、查询、筛选、选中对象、阅读位置。切换页面不能静默丢弃编辑草稿或未提交答案。

## 应用布局

Windows 原生窗口行为 → 顶部应用栏 → 左侧空间/上下文导航 → 主工作区 → 可折叠 Inspector → 底部活动区。

| 区域 | 默认逻辑尺寸 | 行为 |
|---|---:|---|
| 左导航 | 248 DIP，紧凑 232 DIP | 六空间文字、当前二级菜单；仅导航区域独立滚动 |
| 应用栏 | 60 DIP | 面包屑、Ctrl+K、捕获、Inspector 开关；标题栏按现有原生方案处理 |
| 页内边距 | 28 DIP，大窗口 32–36 | 内容层级和列表密度稳定 |
| Inspector | 320 DIP，范围 280–400 | 所有对象用同一模板，用户可关闭；关闭后主区扩展 |
| 活动区 | 44 DIP，展开约 190 | 任务/收据列表与详情；不复制全局导航 |
| 阅读正文 | 16–18 DIP，最大约 760 DIP | 长段落避免超宽，页码/结构/锚点可回跳 |
| 文档结构栏 | 164 DIP，紧凑 136–145 | 仅阅读时按需显示，不常驻第三套菜单 |

分界以可用逻辑宽度判断，不能用物理像素代替 DIP：≥1600 可常驻 Inspector；1360–1599 使用紧凑面板；1100–1359 默认收起、按需覆盖；900–1099 阅读结构折叠；<900 导航转抽屉，仍显示空间文字。正式桌面最小窗口尺寸沿用现有契约；预览另检查 320 宽回退，不代表新增移动产品。

在 2560×1440、150% DPI 时，逻辑宽度约 1707 DIP，可保留完整模式；200% 时约 1280 DIP，应启用覆盖 Inspector，不能缩小文字来硬塞。

## 视觉规则

使用现有 FluentTheme 12.1.2、AaosTheme 和 ThemePalette；不同时挂载第三方全局主题。保留已有品牌标识。Aurora：#061118 / #0C1C26 / #102630 / #1FC8C5 / #F3EFE6；Monochrome：#080A0C / #171A1D / #202428 / #E1E4E6 / #F1F2F3。

细边框减弱到结构层级；高对比边只用于焦点、选中或明确状态。青色实心主按钮用深色字。星辉金只用于证据与少量待复核提示；不能表示“天然可信”。未来项用文字标签，状态不只靠颜色。

按钮约 8 DIP 圆角，面板 12，弹窗 16；正文 14，阅读 17，说明 12，页标题 28。不使用重复 Emoji 功能图标。复用现有 AaosIcon，保持统一线宽和尺寸。

Hover 120ms、过渡 180ms、抽屉 220ms；减少动态效果时立即到最终状态。循环光效、粒子、全屏模糊不作为日常阅读背景，隐藏工作面停止动画。现有 Cosmic 资产作为合法视觉供体继续保留，不据此替换当前产品布局。
