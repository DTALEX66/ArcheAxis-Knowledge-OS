# 原生接入说明

JSON为本包提案，不能代替现有Authority、数据库或运行健康。实施时用现有现行登记/投影填充开发状态与runtime状态；capability_id、requirement_id和source_main_sha保留追溯。复制或引用这个Schema时仍需服从项目契约，不把固定状态硬编码为生产真值。

LegacyRoutePlacements.cs仅提供19项旧路由的空间归属，必须继续调用原handler与别名。原生菜单模板绑定真实登记集合；Future条目执行NavigationCommand打开详情，业务ExecutionCommand则按runtime readiness禁用。不要把未开发菜单本身禁用。

AaosUiAdjustment.Geometry.axaml是选择性合并的资源片段，不替换App.axaml或整个AaosTheme。本包只验证XML结构，没有在Windows/Avalonia中编译或运行这些片段。颜色继续由现有ThemePalette管理；不要硬编码一份新永久配色权威。

预览内的catalog.js、icons.js、固定资料和答案不进入正式产品数据。生产数据通过现有Supervisor和Rust Core读回，单写入者、actor/session、workspace identity、收据和幂等边界不变。
