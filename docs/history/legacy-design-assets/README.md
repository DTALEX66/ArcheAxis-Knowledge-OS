# Legacy design reference assets (historical)

This is a **historical / retired / superseded** inventory. It exists so that the
legacy product name appears only on a declared historical surface, and not on an
active surface such as `docs/current/`, which
`scripts/check_repository_conventions.py` scans for exactly that reason.

These files are the legacy V3 design line. They are **reference material only**,
superseded by the current authority (C#/Avalonia, Chinese-first, black/white dark
baseline) and are not the active visual specification. The `ComfyUI/` model
library area and the Open Design visual chain refer to the same legacy line.
