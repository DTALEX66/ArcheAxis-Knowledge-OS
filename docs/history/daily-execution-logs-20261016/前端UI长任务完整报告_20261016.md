## 🎨 设计系统完善

### 视觉层级

**1. 主色系（保持单色）**
- 主色：白色/浅灰（#f5f5f5）
- 背景：深黑（#050505/#0b0b0b）
- Accent：根据主题（蓝色/青色）

**2. 组件规范**
- 卡片圆角：8px（md）/12px（lg）
- 卡片阴影：3级（sm/md/lg）
- 间距系统：4px基准（使用CSS变量）

**3. 动画规范**
- 基础过渡：150-200ms ease-out
- 卡片悬浮：transform + shadow
- 模态出现：scale + fade 200ms
- 翻转动画：rotateY 600ms cubic-bezier

**4. 交互反馈**
- 悬浮：上移2-4px + 阴影加深
- 点击：scale(0.98)
- 禁用：opacity 0.5
- 加载：pulse动画

### 响应式设计

**断点定义**：
```css
1440px+ : 宽屏（完整三栏）
1024px  : 标准（可收起侧栏）
768px   : 平板（单栏 + 导航调整）
480px   : 移动（最小布局）
```

**适配策略**：
- 工作台：卡片网格 → 单列
- 导航栏：完整 → 简化 → 汉堡菜单
- 搜索：居中 → 隐藏 → 独立按钮
- 小栖：固定右下 → 浮动按钮
