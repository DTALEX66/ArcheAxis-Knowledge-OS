### 1. AAOS-01 缺陷修复 - 单文件导入回执校验
**文件**：`frontend/src/spaces/CanonicalLibrarySpace.tsx`  
**位置**：第267行

**问题**：
- 原代码直接 `await coreCommand` 不验证返回值
- 直接显示"原件已导入"，未确认实际是否成功

**修复**：
```typescript
// ✅ 修复后
const imported = await coreCommand<{ source_id?: unknown; sha256?: unknown; duplicate?: unknown }>("source_import", { ... });
if (typeof imported.source_id !== "string" || !imported.source_id 
    || typeof imported.sha256 !== "string" || !/^[a-f0-9]{64}$/.test(imported.sha256) 
    || typeof imported.duplicate !== "boolean") {
  setMessage("导入回执未确认 source_id/sha256/duplicate；请保留原件并重试。");
  setFailure(true);
  return;
}
```

**验证**：
- ✅ 验证 source_id 为非空字符串
- ✅ 验证 sha256 为64位十六进制
- ✅ 验证 duplicate 为布尔值
- ✅ 失败时提前返回，不显示假成功

**参考**：FolderIngest.tsx:123-124 的正确实现模式
