# Design System: ArcheAxis Knowledge / 星环知识系统

这是Stitch参考的AAOS定制说明，不上传Stitch，不覆盖活动指针/Owner决定。未来任何生成或远端修改仍需明确授权。

## 1. 氛围与布局
工作空间密度6/10、差异3/10、动画2/10。完整星际/大地图环境＋内缩玻璃主控台，露出背景边缘；独立虚拟人物窗保留。应用内Dock不是系统任务栏，不创建OS桌面替身。ConsoleWindow与原生窗口分别调整，分屏标签及恢复复用DockWorkspace。

## 2. 配色与材质
从现有 --ax-* 语义token与五主题取色，默认cosmic（有效用户偏好保留）。原型深底#050B17、青色#00C7E3仅作参考采样，不直接硬编码全应用。单层1px同圆角高光、受控磨砂和阴影；正文对比优先，减少透明与forced-colors有回退。状态警示/危险色保持语义，不强迫只剩一个颜色。

## 3. 字号与密度
复用当前Segoe UI/系统中文无衬线和Cascadia Mono/Consolas等宽栈；正文1rem、UI .875rem、辅助 .8125rem参照现有token。不得为了通用技能另装字体或缩小全文。长中文/URL/表格可换行、独立滚动；ID和原始结构集中诊断，引用来源与版本留在业务界面。

## 4. 组件与状态
研究问题、支持/反对/冲突、原文定位、资料关联、草稿与人工接纳分层明确。只显示真实后端状态，连接/加载/推理/保存/同步分别表达；无接口是阻断，不给假运行按钮。小栖文字助手不是虚拟人物renderer的替代；旧知识/引用/学习不因扩展卸载而丢失。

## 5. 尺寸与输入
按主窗/主控台/Dock/portal实际容器响应，包含640×480、13档矩阵、窄矮组合、Windows DPI和应用缩放；窄窗将侧栏变抽屉/标签，允许正文选取。菜单不越屏，Esc/pointercancel、键盘等价/焦点返回/IME完整保留。触控与桌面点击区按现有规范校验，不把固定2560截图缩成一张图。

## 6. 动画与性能
短时transform/opacity，减少动画时关闭；不采纳通用技能的无限循环/瀑布延迟要求。长列表与图谱依现有renderer和数据规模测量，截图不能证明流畅。后台空闲不持续闪烁或循环耗电。

## 7. 禁止与验收
禁止重新搭壳/替换renderer、硬编码假成功/学术结论、远端字体CDN作为离线依赖、整页user-select:none、body裁切遮住控件、用首张基准掩盖差异。五主题/全业务22语义角色及UI-P01—24仍完整保留；静态参考、合成浏览器、真实Core、原生安装、Owner视觉认可分别验收。
