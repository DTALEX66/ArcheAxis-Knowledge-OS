# 十月以前历史记录集中归档

已将141份明确属于2026年9月及更早的公开过程记录移出日常文本树，7,087,861原字节无损保全为[ZIP](preoct-public-records.zip)（939,642B）。包含十月补注、当前合同或程序依赖、原始输入的候选均保留原处。没有删除Git历史，也没有执行历史指令。

[集中恢复映射](MANIFEST.json)逐项记录`files[].path`、原长度、SHA-256及Git blob。ZIP成员名严格等于`path`。独立恢复演练、最终141原路径缺失后验和全部ZIP成员SHA/CRC核验通过；旧冻结manifest原字节保持，消费者通过压缩身份核原SHA，不降低验证标准。

恢复时从`archive.path`读取`files[].path`成员，验证`bytes`和`sha256`后写回同一原路径，拒绝覆盖已有文件。也可通过`source_commit`和`path`从Git历史恢复。压缩体积差不是物理磁盘释放量；原失败结论、历史日期及资格边界不改写。
