# AAOS 一级至三级导航结构重审（2026-10-01）

状态：`AUDITED / IMPLEMENTATION_PARTIAL`。依据用户指定的产品母版 `01_01_产品信息架构`、`02_02_模块地图`、`03_03_导航结构`、`04_04_首页结构`、`10_10_工作区`、`11_11_记忆地图`、`12_12_搜索与复习`，当前 Avalonia `MainWindow.axaml`/`.axaml.cs`，R6/M0 与 9/28 AA-UI-01/02。母版是当前视觉与信息架构基线；允许 MiniMax Design 提出更好看的 UI、元素、动效、交互和功能组织，但必须逐项给出对照、用户任务收益、可访问性、真实后端边界及原生验收证据。不能为了“像母版”牺牲可用性，也不能把设计创新当成伪造功能的许可。

## 审计发现

1. `MainWindow.axaml:85-142` 已有 10 个日常一级入口，但所有文字 `IsVisible="False"`，只剩图标和 tooltip；用户的 `03_03_导航结构` 母版是图标加常显中文标签。这使模块发现性依赖悬停，不适合桌面主导航。84 DIP 固定轨道（`MainWindow.axaml.cs:27,4182-4184`）缺“宽窗可读标签/窄窗图标折叠”的明确层级。
2. `MainWindow.axaml:189-243` 的二级栏按 section 切换，但首页仅“继续工作/最近证据”，缺快速捕获与学习队列；工作区仅概览/研究暂不可用，缺母版文件树、项目、回收站的结构占位；记忆仅地图/知识详情，缺个人记忆、关联对象；复习有一级入口却共用人类学习二级组。重复跳转如“证据锚点/资料与来源/原件阅读/知识详情”混在一个组中，没有清楚的对象范围。
3. `MainWindow.axaml:244-246` 的三级“对象详情”是静态 TextBlock；`MainWindow.axaml.cs:775-786` 填入的是流程说明，不是 source_id、knowledge_id、job_id、learning item 等可导航对象。不得称三级对象导航已完成。
4. `MainWindow.axaml.cs:125-145` 和应用菜单仍将资料库、Reader、知识库、研究、任务、插件、模型等平铺为路由。命令与旧链接要保留稳定 alias，但可见菜单应按领域分组；插件、模型和 Agent/Runtime 不升为日常一级入口。蓝图现为只读短标题，具体长期能力应可浏览且明确 `待开发`，不能因省略一级轨道而消失。
5. 当前 Home 去掉二级栏（`MainWindow.axaml.cs:4183,4324-4337`），能增加 Hero 空间，但首页的“快速捕获/最近证据/今日学习”须在主内容显露且可键盘抵达。移动/紧凑导航需与桌面语义一致，不能把一级入口藏成无说明图标。

## 具体布局规则与验收

- 宽桌面左侧显示图标与常显中文标签，高亮当前工作流；中等宽度允许 84 DIP 图标轨，但应提供当前页面标题、可键盘展开的完整名称和稳定 tooltip；窄窗用可访问的紧凑/抽屉导航。实际断点由原生截图与 100/125/150/200% DPI 决定，不在审计文档写死视觉尺寸。
- 二级只显示当前工作流的**对象/任务**，去掉同级路由重复按钮；不可用能力可显示 `待开发` 和缺少的 Core 合同，不能做会静默跳回首页的假入口。三级是实际对象选中后的 breadcrumb、版本与动作；没有对象 ID 时显示可理解的空态，不展示虚构路径。
- 保留 `CommandPaletteRoutes`、旧菜单 route、深链接兼容；可见应用菜单按工作流/系统分组。导航命令需稳定 ID、能力/权限检查、键盘焦点和 back/forward；高风险动作遵循后端审批。对照 `RECORD-0928:AA-UI-01/02`、R6 A12、GJ-10/GJ-11 逐项验收。
- 下一步先实施“常显标签与响应折叠、独立复习二级、首页/工作区/记忆缺项、对象级三级”四项；每项用源码、Core 回读、原生截图及键盘路径标明 `IMPLEMENTED_LOCAL`/`TESTED_LOCAL`，未闭合保持 `OPEN`。本审计本身不证明已实施。
