# 星环知识平台（ArcheAxis Knowledge）UI v3

## 视觉系统升级

v3 在“Archive Desk / 证据档案室”基础上，采用冷静的 Apple 液态玻璃工作台：

- **背景**：冷白与雾灰为底，使用极低对比的蓝色光场建立深度；不使用霓虹或营销式渐变。
- **内容**：原件和长文保持实色纸面；阅读器强调页码、锚点与版本，优先保证可读性。
- **壳层**：顶栏、导航、Inspector、浮层和状态容器使用半透明玻璃、背景模糊、细边界与内高光；正文不依赖透明度。
- **色彩**：深蓝墨色用于阅读；蓝青只对应锚点、当前推进和可定位关系。支持、冲突、警告和未知有各自文字、图形与颜色。
- **排版**：研究标题使用系统衬线候选 `Iowan Old Style / Songti SC / STSong`；正文仍是系统 CJK UI 栈。中文标题保持 1.35 行高与零负字距。

## 构图语言

不使用统一卡片网格。工作台为“证据地图 + 研究台账”，阅读器为“页码轨 + 原件纸面”，证据页为“Claim 记录 + 立场台账”，学习页为“路线 + 证据地图”，AI 资产页为“治理登记表”。

## 边界

本版本保持 16 条逻辑路由、Mock Adapter、`UNBOUND` 接口和未来蓝图能力限制。它不连接真实路径、端点、数据库、模型或用户资料；接口仅作为未来整合契约保留。
