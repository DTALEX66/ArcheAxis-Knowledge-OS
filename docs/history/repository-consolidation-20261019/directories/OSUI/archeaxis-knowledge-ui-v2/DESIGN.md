# 星环知识平台（ArcheAxis Knowledge）UI 原型

## 选择方向

选择 C「双态适应」。它以稳定、可阅读的实色任务面承载原件、Claim 和证据；顶栏、导航、Inspector 与 Dock 使用轻薄的半透明壳层。语义令牌在浅色 / 深色与 Full / Compact 密度间一致，不把暗色误做成运维监控界面。

## 关键决定

- 一级空间固定为工作台、资料库、证据、学习、AI 资产、设置。
- 所有页面常驻 `演示数据 · MOCK ADAPTER` 与 `UNBOUND` 说明；不连接真实端点。
- Claim、Evidence 与 EvidenceBundle 由锚点和文本标签连接；不以单一可信度百分比取代核验信息。
- 原件阅读器将原件、派生文档、锚点和检查提示并置；失败页面说明原件安全和可恢复动作。
- Dynamic Visual Lesson 与 Spatial Memory 标记为未来蓝图，不提供暗示可执行的假操作。

## 三方向 Jury 摘要

| 方向 | 得分 | 结论 |
| --- | ---: | --- |
| A 静谧研究 | 79 | 阅读舒适，但对冲突与多窗格任务的区分不足。 |
| B 深层知识 | 76 | 适合 Canvas，但容易滑向监控 / HUD 语言。 |
| C 双态适应 | 88 | 以同一语义令牌支持长时研究、深色聚焦与紧凑工作流。 |

不可合并项：不将 B 的高对比仪表化密度带入 A 的正文面；不将 A 的大留白带入紧凑复核表格。

## 边界与假设

- 原型为框架中立的 HTML/CSS/JS 实现；所有 Adapter 方法保持 UNBOUND。
- 所有数据均为显式 fixture，不是用户资料、真实任务、真实评测或真实能力回读。
- 仅使用系统字体与内联线性 SVG；未使用第三方图片、Logo 或联网字体。
