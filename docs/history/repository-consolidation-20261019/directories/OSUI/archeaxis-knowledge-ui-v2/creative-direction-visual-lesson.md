# 动态视觉课件工作台：创意总监方向说明

## 什么是“好看”

受众是需要把有出处的材料组织成可解释学习段落的研究者、学习者与审阅者。它的美感不来自“播放一个炫酷视频”，而来自一种可见的严谨：场景有边界、每个画面能找到依据、时间推进可被暂停和检查。

## 目标与约束

- **业务目标**：把 EvidenceBundle 组织为可审查的视觉课件结构，而不是把证据隐藏在播放器后面。
- **品牌气质**：冷静、精确、像研究桌而不是内容创作软件或 AI 控制台。
- **信息密度**：场景树、舞台、证据脚注和时间轴同时可见；主舞台保留呼吸空间。
- **色彩与材质**：v2 的档案纸面、细坐标纹理和单一青蓝锚点。支持、冲突等语义色仅在数据状态出现。
- **字体**：宋体/衬线只承担课件标题与概念名；系统 CJK UI 字体承担操作与正文。
- **动效**：仅允许场景焦点转移、时间线游标与证据定位；全部可暂停，并有静态分镜替代。
- **素材标准**：当前为未来蓝图，不生成虚假的视频、人物、讲师或数据图表。舞台以可编辑的几何关系和来源标识呈现。

## 禁止项

- 不出现霓虹、全页渐变、发光粒子、自动播放、自动镜头飞行或“AI 生成中”的假状态。
- 不把场景树做成普通卡片列表，不用营销式 Hero，也不把来源脚注弱化成视觉装饰。
- 不伪造观看人数、完成率、掌握度、配音、时长估算或评测结论。

## 资源组合

| 资源 | 用途 | 未选原因 / 边界 |
| --- | --- | --- |
| `app.css` / `DESIGN-v2.md` | 继承档案纸面、字体、颜色与壳层令牌 | 不另起风格，避免页面割裂。 |
| `motion-accessibility.md` | 将时间线、暂停和 reduced-motion 作为结构要求 | 不做自动动画。 |
| `route-data-dependency-matrix.md` / `mock-adapter.js` | 明确课件页不读真实 API，保持 `UNBOUND` | 不绑定端点或制造加载成功假象。 |
| Creative Director 工作流 | 用“解释结构优先于装饰”的标准审核构图 | 不需要外部图片、视频、插件或连接器。 |

## 方向选择

选择“证据分镜台”：左侧是场景索引，中部是可读的概念舞台，下方是可定位的时间线，右侧沿用全局证据 Inspector。它比时间轴编辑器更安静，也比普通播放器更能表达证据约束。
