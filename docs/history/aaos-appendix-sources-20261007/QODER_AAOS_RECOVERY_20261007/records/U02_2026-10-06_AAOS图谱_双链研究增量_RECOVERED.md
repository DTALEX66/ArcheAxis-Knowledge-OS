# U02｜2026-10-06 AAOS 图谱 / 双链研究增量

状态：RECOVERED_CANONICAL_EXPORT  
性质：从 2026-10-06 历史会话连续性记录与《AAOS 完整项目描述与未来蓝图》中的 U02 追溯条目恢复的规范化导出。  
重要边界：这不是“原始聊天全文逐字导出”。下列“研究候选/供体”不得被写成已采纳、已接入或已实现。

## 1. 用户方向

- 本增量只针对 AAOS / ArcheAxis Knowledge。
- 前端调整不取消图谱/双链研究；继续保留并深化双向链接、反链上下文、知识关系、Graph 与研究探索能力。
- 必须区分：最新用户决定 / 当前实现 / 未来蓝图 / 候选研究；不能把助手建议冒充实现事实。
- 本研究继续服从 U01 最新规则：内容可先保存；Evidence 不是知识入库门槛；识别忠实度与专业依据分析分开。

## 2. 双向链接与知识关系

长期目标包含：

- 页面 / 块引用；
- Backlink / 反链上下文；
- 别名与链接消歧；
- 类型关系；
- 未解决引用与知识缺口；
- 用户手工链接、导入链接、AI 推断关系具有不同 provenance；
- AI 推断关系先作为 candidate 或明确的 inferred 状态存在。

关系事实与图上布局必须分开。用户移动节点不改变关系含义；Graph 视图只是对真实对象/关系的投影，不能成为第二业务数据库。

## 3. 图谱检索与探索研究增量

继续保留以下研究/扩展目标：

1. 真实 Core Graph projection；
2. 局部图 / 邻域按需加载；
3. typed relationships / 类型关系；
4. backlink context / 反链上下文；
5. candidate relationship governance / 候选关系治理；
6. 后续 multi-hop GraphRAG；
7. exploration session / 探索会话；
8. spatial projection / 空间投影与长期 2D/3D 探索。

这些是研究和未来扩展方向，不能据历史助手描述声称已经实现。

## 4. 候选研究线索

历史研究中出现过 SilverBullet、TriliumNext、Logseq、Heptabase、Capacities、AWS Graph Explorer、Cognee、KAG、LightRAG / GraphRAG 等相关线索。

它们只能作为 donor / candidate / reference 线索：

- 不默认当前仍维护；
- 不默认许可、兼容、性能或集成状态合格；
- 必须先对真实 AAOS 缺口做核验与 benchmark；
- 图组件、GraphRAG 算法、关系真值内核是不同层，不能混为一体。

## 5. 状态边界

- 历史总图中 Retrieval / Graph / Research 属部分进行中 / partial；生产级 vector / reranker / graph / research 接线与 benchmark 仍是缺口。
- 可视化/空间表征属于更长期 planned；探索能力可为 deferred。
- 因此，本 U02 只恢复方向与研究边界，不签发“已完成”或“已部署”结论。
