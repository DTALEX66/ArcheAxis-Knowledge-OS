# U01｜2026-10-06 最新保存 / 证据 / 双学习规则

状态：RECOVERED_CANONICAL_EXPORT  
性质：从 2026-10-06 历史会话决策与《AAOS 完整项目描述与未来蓝图》中的 U01 追溯条目恢复的规范化导出。  
重要边界：这不是“原始聊天全文逐字导出”；不得把后续助手推断冒充用户原话。

## 1. 用户已明确的最新规则

1. **内容可以先保存。**
   - 原创笔记、灵感、未经验证的假设、个人判断、研究草稿、AI 生成内容、未复核 OCR/ASR 结果，都允许先进入系统保存、阅读和编辑。
   - 缺少专业文献、无法联网、API 没额度、尚未云端复核或尚未人工认可，不得成为统一的知识入库门槛。

2. **Evidence 是治理 / 研究能力，不是知识入库许可证。**
   - Evidence 用于追溯、研究、支持/反驳/不足/争议分析与治理。
   - 没有 Evidence 不等于内容不能保存；有 Evidence 也不等于主张绝对正确。

3. **“识别忠实度核验”与“专业依据分析”必须分开。**
   - 识别忠实度：判断机器结果是否忠实于特定原件版本，例如 PDF 漏段、OCR 错字、表格错位、ASR 漏词、视频遗漏、图片误判。
   - 专业依据分析：判断某个主张得到哪些专业来源支持、反驳、认为证据不足或存在争议，并保留适用时间、上下文与来源独立性。
   - 识别正确不证明观点正确；专业资料也不能悄悄改写原件。

4. **网络资料不能偷偷替换原件。**
   - 外部资料只能形成疑点、修订建议、支持/反驳/不足/争议等研究结果。
   - 原件、机器解释、外部证据、用户采用版本必须保持可区分、可追溯。

5. **状态不能压成单一“可信度”。**
   - 内容身份、来源/版本、识别忠实度、专业依据、用户采用、学习掌握、AI 资产资格是不同维度。
   - Mastery ≠ Truth；Model Confidence ≠ Evidence；用户采用 ≠ 普遍事实成立。

## 2. Human Learning / AI Learning / 双向回流

AAOS 必须同时保留 Human Learning 与 AI Learning，并明确双向学习/回流。

### Human Learning

知识/证据可形成学习目标、解释、例子、关系、练习、主动提取、复习、Teach-back、技能迁移与掌握信号。人的错误、掌握情况、Teach-back 和修订可以产生新的证据需求、知识修订与 AI 资产纠错信号。

### AI Learning

知识/证据可形成 Memory / Rule / Skill / Standard / Context 等候选资产。候选必须带 provenance、scope、freshness、conflict 等治理信息，并按相应人工/策略门禁处理后才能成为可调用资产。AI 输出、总结、题目、链接建议、技能草案默认先是 candidate，不能静默覆盖用户版本。

### 双向规则

- Knowledge / Evidence → Human Learning material / AI candidate。
- Human learning feedback / correction / revision → Knowledge update / AI candidate correction。
- AI 使用结果 → 可形成新的研究、纠错或候选，但不能自动升级为事实或 Evidence。
- 人的学习记录不能直接当公共事实；AI 调用结果不能自动变成证据。

## 3. 稳定产品语义

基础旅程：捕获或导入 → 保存原件/内容 → 阅读编辑 → 记录来源、身份、版本和状态 → 按需核验/研究/修订 → 继续用于知识、学习与研究 → 人/AI 使用反馈回流。

WORK-LAB 与 DESIGN-LAB 的接入只能增强，不得成为 AAOS 保存笔记、学习或恢复数据的强制前提。
