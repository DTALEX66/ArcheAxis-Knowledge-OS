# AAOS 完整落地任务包
## 全能力可发现 · 原生视觉精修 · 学习科研接入 · 全知识库兼容 · 可信闭环

版本：2026-10-04 / CONVERSATION-CONSOLIDATION-1.1-FULL-COMPAT。
范围：本次可见对话、用户上传的 DSH 16 问原文，以及明确标注的官方资料核验。
性质：供本地执行器使用的增量执行汇编；不是新的产品宪法，不是运行状态证明，也不是软件安装包。

> 最重要的交付：真实 Avalonia 界面好看且好用；现有及仍有效的未来能力全部可发现；真实能力可调用、数据可追溯、结果可恢复。不得用删功能换简洁，不得用灰色死按钮代替未来能力，不得用 build green 代替视觉验收。

## 从哪里开始

需要单文件阅读时使用根目录的 `AAOS_完整任务包_合并阅读版.md`；它合并全部专题、完整工作项、验收表、角色提示词和 DSH 原文。

先将本包放在一个独立可读目录，不要把整个 ZIP 覆盖到仓库根。将 `prompts/00_统一接管启动提示词.txt` 发给当前主执行器；由其读取 01、02、08，再按任务读取专题文件。

单 Agent：按 `08_执行顺序与分工.md` 逐项执行。
多 Agent：DSH 负责 Core/worker/契约；Codex 负责原生界面；Hermes 负责只读对账、集成候选和回归。此分工是本包建议，若现场已有 owner，先保持原 owner；同文件只允许一个写者。
中断恢复：只读取交接回执和本任务所需章节，不重新全仓调研，不重新扩写蓝图。

## 使用边界

本轮通过 GitHub 连接器只读核对了 PR #157 元数据和默认分支 R6 执行台账前 120 行；不是全仓审计。没有重新执行 DSH 测试，没有修改 AAOS 源码，没有启动 Windows 客户端，也没有安装 API 或模型。DSH 的 schema 与测试数仍只属于原报告时点；PR 读取结果单独列为本轮快照。

`registries/capability_map.seed.json` 只覆盖本次对话明确提及的能力线索，不是 97-source、369 项研究池或历史全部 ZIP 的复原。执行器必须与真实 Authority/Capability Atlas 对账；不得把种子条目数量当作项目能力总量。

包内不含历史 47 个素材 ZIP、不含第三方源代码/字体/Logo、不含新的 UI 渲染截图。它是指导交付真实软件界面的任务包，不是已经完成 UI 的证明。

## 先做什么

先保护现场、确认唯一写者和权威映射；随后并行修复能力分发与原生视觉样板；完成真人复核和副本恢复演练。Crossref/OpenAlex、学习供体和 Agent 任务属于后续受控增量，不塞进当前 M0 门禁。

## 包校验

已有 Python 时，在本包目录执行：

```text
python checks/verify_taskpack.py
```

它只检查任务包文件、哈希、引用和登记结构，不调用网络、不执行项目代码、不修改用户数据库；通过不代表 AAOS 通过验收。没有 Python 时无需为了阅读本包自动安装工具链。
