# 全能力导航与原生视觉交付规范

## 1. 核心原则

全能力可发现，默认任务聚焦；允许折叠，不删能力；未来能力有可点击详情，不伪装能执行。界面质量必须以真实 Avalonia 窗口裁决，不用截图生成图、HTML 演示或代码编译替代。

本文件是本轮设计建议与执行要求。六域名称、宽度、颜色均不得越过已批准 Authority。E0 完成现行映射后，冻结一份本轮视觉基线及其引用，不让各 Agent 独立生成设计系统。

## 2. 菜单组织

| 建议产品域 | 二级/上下文内容 | 长期能力的显示方式 |
|---|---|---|
| 工作台 | 继续阅读、继续学习、最近资料、待复核、进行中任务、快捷捕获 | 只显示真实统计；完整能力地图入口常驻 |
| 知识 | 导入/资料库/阅读/编辑/知识对象/证据/研究检索/搜索与问答/互操作 | 高级检索、图谱、版本与未来适配仍可发现 |
| 知识库兼容（知识域内） | 迁移向导、平台能力对标、字段映射、损失预览、迁入迁出、往返回读、增量冲突 | 不新加必需一级域；未来适配可打开范围与真实限制 |
| 学习 | 诊断、路线、课程、练习、复习、错题、掌握证据、Teach-back、学习画像 | 认知负荷、编码、长期巩固等在该域就近显示 |
| AI 学习 | 任务、受控使用、评估、纠正、重测、记忆/规则/技能候选与复用 | 更复杂经验学习标为规划，不声称权重已训练 |
| 探索与蓝图 | 全能力地图、视觉学习、LER、仿真、空间记忆、2D/2.5D/3D、VR/AR | 与所属业务域共享能力详情，不另建重复状态 |
| 系统与能力 | 能力中心、来源连接、插件、产品技能、模型/Provider/适配器、任务回执、健康、备份恢复、设置 | 候选平台在目录可发现，不算已安装 |

本次对话曾出现“工作台/资料与知识/证据/学习/机器知识/系统”等旧分组。不能靠猜测取消证据域。先查有效 IA 决定与代码路由，形成旧路由→目标位置→兼容入口表；未获正式 supersession 时，保留现有一级域，将本表作为内部信息归组，不强制换壳。

### 折叠规则

一级分组固定可见。二级按任务聚合，默认只展开当前域/用户已固定域；允许多个分组展开，保存展开、滚动、选中和固定状态。默认不展开所有子项；用户可选择全部展开，仍可滚动且不挤压正文。

侧栏最多长期显示两级层次，细节在上下文面板/页内标签展开，避免六层目录。展开箭头与打开页面动作分离，键盘左右键/Enter/Space 的语义一致；焦点可见，屏幕阅读器能获得展开和选中状态。

全局搜索覆盖能力名、别名、平台、技能及未来能力；返回真实状态、完整路径与可行动作。搜索未来能力打开详情，不自动执行/安装。

“全部能力”是可发现性要求，不是要求把全部对象、文件、数据行或开源仓库都设成菜单项。开发者 SKILL/MCP 配置与产品技能列表分开。

## 3. 未来能力详情模板

标题与一句话用途；真实规划/实现状态；典型场景；输入/输出说明；已确认依赖；当前已实现部分；待完成/阻塞点；参考供体关系；相关蓝图/变更记录；替代方案。无依据字段写“尚未定义”，不要自动生成发布日期。

可用项：打开功能、查看记录。未配置项：配置、权限详情、测试。失败项：原因/重试。开发项：查看已完成与待完成。规划项：查看说明/依赖。历史项：查看替代能力与历史。

概念图明确“概念预览”，不得展示虚假连接成功、演示 KPI 或运行日志。未来入口文字保持可读，不用低对比灰色整页禁用。

## 4. 主界面空间

沿用现有壳：左导航、顶栏、主工作区、可收起 Inspector、Activity Dock。不要机械常开所有面板。Inspector 承接来源、证据、版本、关系、历史和状态，Activity Dock 仅在任务/错误需要时展开。

首张样板选“阅读＋证据复核”：选定候选队列、居中原文/锚点、相邻候选结论与审核动作。全导航、队列、目录、Inspector 不得同时挤成五窄栏；队列/目录共享上下文空间或按任务切换，窄窗口收起辅助栏。原文与候选关联不能丢。

## 5. 视觉系统

方向：安静壳层、清晰内容、精确层次、细腻光影与动效。一个语义色系、一个图标家族、少量圆角和间距层级。已有 AAOS 品牌标识与批准颜色先保留，不引入其他项目 Logo。

建议首轮调校：界面正文 14–16 DIP，阅读 16–18 DIP，标题 24–30 DIP；间距优先沿用 4/8/12/16/24/32；侧栏参考 224–248 DIP（窄窗口折叠），折叠栏约 64 DIP；页内边距参考 24–32 DIP。它们是调校起点，不是验收捷径。

中文系统字体回退必须实测，不能只优化拉丁文本。单位使用 DIP，记录物理像素与系统缩放，不把 2560×1440 直接视为逻辑布局大小。

阴影/边框仅用于需要区分的层；正文和表格使用稳定实体底色。主操作明显，状态颜色辅以文字/图标。不要把每个模块套两层卡片，不要把所有页套成四 KPI 后台模板。

普通正文对比度参照 4.5:1；这是视觉基线，不是整应用 WCAG 认证。可点击的未来能力不能借“禁用控件例外”降低可读性。[S15]

动画建议：轻反馈 120–200ms，抽屉约 220–280ms；支持 reduced motion、隐藏页停止循环动画。保留必要高光/层次，不使用常驻星空粒子、满屏模糊或多处循环发光。控制显存和后台开销，避免干扰用户本地推理。

## 6. 不同页面的设计重点

| 页面 | 主内容 | 验收重点 |
|---|---|---|
| 工作台 | 继续任务、最近资料、待处理 | 无假 KPI，无多余开发术语 |
| 资料库 | 真实标题、格式、来源、状态、筛选 | 长标题、密度、选中/多选、稳定滚动 |
| 阅读/证据 | 原文与候选对照、锚点、审核 | 不跨多页丢对象，版本清晰、正文主导 |
| 学习/复习 | 当前问题、答案揭示、评分与进度 | 队列自动只读加载，空/错分开，评分不伪造 |
| AI 学习 | 纠正、重测、候选差异、复用证据 | 不把记忆资产叫权重训练，不自批准 |
| 能力中心 | 任务能力与提供方关系、配置动作 | 目录/实现/连接状态分离，不是 Logo 墙 |
| 迁移与兼容 | 源/目标、范围、风险、字段映射与进度 | 有损项醒目但不制造恐慌，原软件回读与单向成功分开 |
| 未来详情 | 场景、范围、依赖、真实进展 | 可浏览，有信息，无假执行按钮 |

## 7. 参考吸收与限制

OpenHuman：能力发现、连接/配置/重试/禁用，不迁移 Tauri/React 或核心。官方自述仍为 Early Beta，不能把参考对象热度当成熟度。[S02]
AFFiNE/思源：内容组织与中文知识操作。Files：Windows 列表、工具栏与详情体验。这些是前面对话保留的设计供体，本包未重新安装或测试。
Bear/Things 3：Apple 2017 Design Awards 参考；Craft：2021 Mac App of the Year，奖项不能混写。[S16][S17]
Linear：学习其减少噪声和多状态迭代方法，不把 AAOS 变成工单系统。

不复刻商标、未经授权图片或字体；不要求装齐所有组件库。沿现有 FluentTheme/FluentAvalonia，缺口时才对 Semi+Ursa 或 SukiUI 做单个控件试验；不能叠多套全局主题，不锁 latest。

开发技能先枚举后使用：Avalonia 官方资料/已配置 Build MCP、现有设计技能；社区技能的版本适用性需验证。缺失就报告，不虚构已安装，不全局覆盖其他 Agent 设置。

## 8. 视觉验收流程

同一份实际资料、同一窗口条件，对照参考、改造前、改造后。预览 fixture 必须显式标注，正式验收用真实数据。原生截图绑定完整 SHA/dirty diff、构建路径、PID、主题、缩放和时间。

样板必须被独立审查或 Owner 认可；未认可时只修样板，不把问题批量复制。后端仍可继续独立任务。自动像素回归只能发现变化，不能替代美感与任务体验判断。[S03]

不设“85 分即可好看”等伪精确评分；逐项列严重/主要/轻微问题：对齐、字级、密度、对比、导航、任务连续性、状态、动效。视觉门禁通过需要无严重/主要未解决项，并有明确人工意见。

## 9. 完整性门禁

从批准的有效能力集合与 UI 可发现集合做差集：未映射为零、死链为零、重复真值为零。比较基数必须记录来源版本。不能仅与本包 seed 比较后声称历史全覆盖。

全部已实现页面都要访问；全部规划能力都能打开详情；地图与侧栏指向同一能力对象。注销/禁用平台不会删除相应能力说明，只更新动作和运行状态。

## 10. 本次对话的能力线索全集（待与 Authority 合并）

以下是本次对话的需求种子，不是历史能力总量，不预判已实现或未实现。与旧蓝图同 ID 合并、只补差，不批量替换。全部知识库对标发现的新能力还应追加进所属业务域。

### 工作台

继续阅读；继续学习；最近资料；待复核事项；进行中任务；快捷捕获。

### 知识

### 学习

学习诊断；学习计划；先修关系；学习路线；课程与学习产物；基于资料的讲解；练习与题库；测验与评估；间隔复习；卡片与填空；错题与反馈；掌握证据；复述教学；学习画像；认知负荷；记忆编码；主动训练；技能实战；元认知；长期巩固；学习笔记；复习调度；学习历史与统计。

### AI 学习

机器知识任务；受控知识使用；评估与对照；人工纠正；纠正后重测；记忆候选；规则候选；技能候选；候选审核；已认可机器知识；复用证据；知识上下文包。

### 探索与蓝图

完整能力地图；视觉学习；学习体验呈现 LER；知识图谱；思维导图；画布与白板；仿真学习；空间记忆；记忆宫殿；2D 学习空间；2.5D 学习空间；3D 学习空间；VR 学习；AR 学习；科研工具与验证；未来能力路线。

### 系统与能力

能力中心；平台与本地连接；产品插件；产品技能；知识库适配器；共享模型引用；模型与科研提供方；能力健康；任务与作业；调用回执；配额与成本；权限与数据范围；备份；恢复与回滚；设置；快捷键；无障碍；离线模式；跨端同步；移动访问；加密与凭据；审计记录；对外知识 API；领域自动化；许可与供体来源。
