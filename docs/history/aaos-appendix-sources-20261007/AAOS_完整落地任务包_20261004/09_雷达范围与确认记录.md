# 原雷达专项范围与确认

2026-10-04，本次整理读取自动化返回状态：原“模型 / API / 价格与额度雷达”处于启用状态，提示词已经包含用户同意增加的 AAOS 学习/科研/研发专项。未新建重复雷达，未改变原调度和时区。

本次返回同时显示 notifications_enabled=false、email_enabled=false。任务启用不代表推送或邮件已开启；本包没有替用户开启这些通知，也不承诺一定收到手机/邮件推送。

新增专项：Crossref/OpenAlex/Wikidata/Wikipedia/MediaWiki/arXiv/Unpaywall/Semantic Scholar/Europe PMC；Zotero API、GitHub 内容 API、HF Hub API；书生·端砚的真实开发接口资格、MIT OCW 的内容使用规则；OpenHuman、DeepTutor、LearningMAP、OpenTutor、OpenMAIC、Docling 的集成相关接口/许可/安全/兼容变化。

沿原规则只在高价值变化时输出，通常约 5 条、最多 8 条；不因 Star 普通增长或版本号递增通知。首次无旧快照时写首次建立基线，不伪造差分。官方 API 与第三方平台区分，内容许可与代码/模型许可区分。

新增知识库兼容任务中的其他平台：本包保留版本资格化要求，但本轮没有自动将全部新候选加入监控或再改雷达。执行器不得误把文档里的候选列表当已配置监控。

自动化只检索公开信息，不上传用户研究资料，不购买/注册/安装，不自动更改 AAOS 依赖或产品配置。雷达提示和生产依赖升级必须有独立审查与测试。
