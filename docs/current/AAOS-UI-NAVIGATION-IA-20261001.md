# AAOS 正式桌面导航信息架构（2026-10-01，实施中）

依据用户 2026-10-01 最新要求、UI 套件 `01_01_产品信息架构` / `02_02_模块地图` / `03_03_导航结构`、`AGENTS.md`、R6/M0、`docs/truth/CAPABILITY_ATLAS_V2.yaml`，并对照 9 月 28 日完整包与 9 月 30 日 UI 包。B10 的平铺菜单仅为交互原型。项目权威仍由 `docs/CONFIGURATION_AUTHORITY_INDEX.md` 索引；根 `AUTHORITY.md` 缺失标记 `AUTHORITY_REFERENCE_MISSING`。

三级导航规则：一级选择日常工作流；二级选择该工作流下的对象或任务；三级进入真实对象的详情、版本或动作。第三级须有对象 ID/真实 Core 投影或明确显示 `待开发`，不得以样例对象充当用户数据。空状态与接口未接状态单独表达。设置与恢复在底部系统区；未来能力独立为只读蓝图区，不混入当前日常工作流。

| 一级工作流 | 二级对象/任务 | 三级详情或动作 | 当前证据边界 |
| --- | --- | --- | --- |
| 首页 | 今日概览、快速捕获、最近证据、学习队列 | 来源详情、任务回执 | Core 可读部分，未提供的 KPI 保持空/不可用。 |
| 捕获 | 快速捕获、导入来源、转换任务、回执 | Source 原件、转换结果、Job 回执 | 导入/任务为真实 Core；自由文字原创持久化待接口。 |
| 证据库 | 来源、证据锚点、知识版本 | 原件、锚点、证据关系、版本详情 | anchors/source/knowledge V3 部分真实；无原图缩略图时不伪造。 |
| 原创 | 草稿、编辑、引用与版本 | 编辑对象、引用来源、版本 | Core 正式 Original 写入/引用 API 未闭合，标记待开发。 |
| 人类学习 | 计划、课程、学习产物、评估 | 学习项、Assessment、FSRS | 队列/复习部分真实；其他按接口可用性展示。 |
| 机器学习 | 任务、受控调用、评估、纠错/重测 | 任务 ID、运行回执、评估结果 | 仅真实任务 ID/回执可用；不展示伪模型健康状态。 |
| 工作区 | 文件树、项目、研究、回收站 | 项目、文件、版本 | 当前 Core 投影有限，空树/待接口必须明示。 |
| 记忆 | 个人记忆、知识关联、记忆地图 | 节点、来源、关联 | 图节点/边 Core 投影未闭合；示意图标注装饰。 |
| 搜索 | 全局结果、语义、图谱 | 命中来源、锚点 | 词法搜索可用；语义/图谱按接口标待开发。 |
| 复习 / FSRS | 今日队列、卡片、复习记录 | 学习项、答题、调度 | 使用真实队列/调度，不造卡片。 |

系统区：设置、连接与能力状态、任务回执、备份恢复。未来能力：视觉课件、仿真、空间记忆 3D/VR/AR、协作、生态互通、模型治理与 Agent/插件等，以 Capability Atlas ID 和来源为只读投影。保留旧 route/命令别名，避免链接或键盘入口失效。所有可点击入口都要有真实结果、真实空状态或明确不可用说明。

本文件是导航实施和验收索引，不宣称三级已全部接入。实际通过状态以源码、桌面截图、Core 响应及当前验收记录为准。
