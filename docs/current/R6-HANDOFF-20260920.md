## 云端审计读回

上传后审计者应核对：

```text
git rev-parse HEAD
git rev-parse origin/main
git ls-remote origin refs/heads/main
git status --short
```

只有三处主线 SHA 完全一致，且 `git status --short` 中没有本次交接以外的已跟踪修改，才能记录为 `BRANCH_PUBLISHED`。远端检查缺失、CI 检查缺失或产品运行证据缺失时，状态必须保持 `PARTIAL`、`BLOCKED` 或 `UNVERIFIED`。
