# AAOS-01 Q02：**默认模式稳定派生；但命令行读取不稳定**

## 1. 一个清晰、可复现的对照

| 模式 | 观察到 `python.exe` 子进程 | 轮次 |
| --- | --- | --- |
| **默认模式**（不设 portable root） | ✅ **每次都有** | 84 · 85 · **90** |
| portable 模式（设 `ARCHEAXIS_PORTABLE_ROOT`） | ❌ **一次都没有** | 88 · 89 |

**这是本轮最实在的收获**：差别稳定复现，不是偶发。
**也就是说：我的 portable 绕道确实改变了行为**（而且是往坏的方向）。

## 2. 哈希护栏第三次通过

```
"live_db_sha_before": "0fe14e08a6de6018218c4fbb62726b632d98f4359bcdfdd3b661e64a777ef613"
"live_db_sha_after":  "0fe14e08a6de6018218c4fbb62726b632d98f4359bcdfdd3b661e64a777ef613"
"live_db_unchanged": true
```

**三次独立运行（86 · 88 · 90）都得到同一个结论** —— 默认模式运行宿主**不动那个数据库**。
**所以「默认模式是安全的」这句话，现在有三重实测支撑。**

## 3. ⚠️ 但命令行的读取不稳定 —— 而这限制了我的结论

```
"non_webview_children": [ "python.exe||" ]     // 名字有，CommandLine 是空串
"saw_migrate": false    "saw_core": false
```

| 轮次 | 轮询间隔 | 拿到的命令行 |
| --- | --- | --- |
| 84 | 150 ms | ✅ **完整**：`python.exe -B -I -m app.runtime_entrypoint migrate` |
| 85 | 150 ms | ❌ 空 |
| **90** | **30 ms** | ❌ **空** |

**所以「读不到命令行」与轮询快慢无关** —— 更像是 `Get-CimInstance` 的 `CommandLine` 在某些时刻返回空
（进程刚起、或权限上下文差异）。

**由此我必须收紧结论**：

| 不能声称 | 因为 |
| --- | --- |
| 「后端只跑了 migrate，没跑 core」 | **`saw_core: false` 只说明我读不到命令行** |
| 「core 从未运行」 | 同上 |

**这正是我上一轮批评自己的那类错误 —— 拿一个弱信号下强结论。这次我不下。**
