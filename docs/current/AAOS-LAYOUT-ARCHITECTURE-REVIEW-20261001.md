# AAOS 界面布局架构审计（2026-10-01）

状态：`PARTIAL`。依据当前 Desktop 源码与 UI 套件产品母版作静态审查；原生窗口、双主题和 DPI 逐页截图尚未验收。此文是实施审计，不取代项目 Authority、R6 或 M0。

## 产品主体与布局原则

ArcheAxis Knowledge 是以证据为锚的人类学习、机器学习、以及两者相互学习成长的长期重型产品。三者是并列主体：导航、首页概览、专属页面、跨主体流转和未来蓝图均须保留清晰空间。M0 规定近期实施顺序，不删减任何主体或把机器学习缩成设置项、把人类学习缩成复习按钮、把双向成长缩成装饰性图表。未有真实 Core 接口的区域应明确标为待开发或真实不可用状态。

## 待实施的布局合同与验收

1. 一级是可见的核心工作流；二级是任务/对象；三级是真实对象 ID、版本和动作。参见 `AAOS-NAVIGATION-STRUCTURE-REVIEW-20261001.md`。长远蓝图可发现且标 `待开发`，不可占用日常一级工作流。
2. 为宽窗、中窗、720 窄窗及 100/125/150/200% DPI 建区域矩阵，规定顶栏、二级栏、Inspector、活动 Dock、底栏、抽屉与焦点恢复；统一基于实际可用内容宽计算列数。
3. 修正 Search 固定五列、Original 固定七列工具栏、移动顶栏，以及 Home/Learning/Review 在 Inspector 展开时的拥挤风险；逐页验证 Aurora、Ivory/明亮、黑白配套和 reduced motion。
4. 人类学习、机器学习、相互学习成长各须有可到达的入口、真实状态区域和清晰流转。以人类评估/纠错→机器复测，以及机器评估/建议→人类采纳/学习等真实对象链作验收；未接通写 `UNVERIFIED/BLOCKED`，不填假数。
5. 以原生 Avalonia/原 Green 截图、键盘操作、窗口缩放和接口回执记录证据。此审计尚未执行运行时验收。
