## 本轮错误与处理

1. 首次 v0.6.9 PR CI 因版本提升遗漏 `diagnostics`、根包版本、ZIP 生命周期脚本
   和 `uv.lock` digest 而失败。根因是版本真相面分散；已在 `c64278d` 一次补齐，
   后续 PR/main CI 全绿。
2. 本地复跑部分 API 测试时，复用的最小验证环境缺少 `fastapi`。这是
   `ENVIRONMENT_FAIL`，不是产品回归；相同测试已由锁定依赖的 GitHub CI 通过。
3. 独立下载三个大型 Windows 资产时 GitHub CLI 并发传输过慢，按 Owner 指令停止。
   wheel 与 5 个元数据资产共 6/9 已完成本机 SHA-256 对照；全部 9 项 provider
   digest 已读回，Release 工作流自身的全资产下载读回成功。未把 6/9 夸大为 9/9
   本机独立下载。
4. 主要耗时来自发布身份注入后重复执行 Windows NSIS/三包构建与生命周期，不是
   前端日常开发构建。日常 CI 已减重；正式发布仍保留这一次重门禁。
