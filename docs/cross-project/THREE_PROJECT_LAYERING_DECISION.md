# 三项目分层架构决策（v5 · 知识中心 + 分阶段演进）

本文档锁死三项目关系。核心不变式：ArcheAxis 是唯一知识总库 + 双向人机重型学习系统（定位永不漂移，NOT an Agent OS）。所有知识的最终归宿是 ArcheAxis，但采用分阶段演进：现有资产先归各自所有，OS 完整后逆向归档。

## 1. 唯一知识总库（ArcheAxis = OS 系统）

所有知识的最终归宿是 ArcheAxis。ArcheAxis 定位永不漂移：双向人类到 AI 的重型学习系统级项目，未来蓝图锁定重型学习系统级（SYSTEM_MASTER_BLUEPRINT_V2 + FROZEN_EXECUTION_BASELINE H0-H10）。

知识分两侧：
- 人类学习侧：知识直接留在 ArcheAxis 供人类学习，不转化出去
- AI 侧：知识通过 API 供给各转化器项目，由项目转化沉淀为可执行资产

## 2. 转化器项目（开放集合）

周边项目是知识的调用者与归档回写者，不是知识拥有者。它们只做：调用（读知识）+ 转化沉淀（知识 → 规则/规范/技能/插件）+ 归档（执行产出回写 Candidate）。

开放集合：当前 WORK-LAB + DESIGN-LAB，未来任意 N 个项目接入。

## 3. 分阶段演进（核心，v5 新增）

### 阶段 1（当前）：现有资产归各自所有
- WORK-LAB / DESIGN-LAB 现有的规则、技能、插件，是已经转化沉淀完成的产物，归各自项目所有，继续使用
- 不强制现在归档到 ArcheAxis（OS 尚不完整，H1 后端未 merge，知识治理闭环未完备）
- 各项目照常运转，现有资产不迁移、不删除

### 阶段 2（未来）：OS 完整后逆向归档
- 触发条件：ArcheAxis 知识治理闭环完整可用（candidate → review → verified 全链路 + 稳定知识 API 契约）
- 动作：各项目把规则/技能/插件逆向转化归档到 ArcheAxis——从可执行资产逆向提炼为知识（Knowledge Unit / Machine Knowledge Unit），归档治理
- 单向演进：各自所有 → OS 统一，不回头

### 分阶段的意义
- 不破坏现有工作：WORK-LAB/DESIGN-LAB 的规则/技能照常可用
- 不给未成熟的 OS 强加知识总库的担子
- 未来 OS 成熟后，知识自然逆向收敛，最终实现唯一真源

## 4. 知识生命周期循环（阶段 2 之后的主循环）

ArcheAxis 知识（真源）→ 项目调用 → 转化沉淀（规则/技能/插件）→ 执行 → 产出新知识 → 归档回写 Candidate → ArcheAxis 治理 → verified → 再转化 → 双向进化

## 5. 分层

### 第一层 ArcheAxis（唯一知识总库 + 人类学习系统，NOT Agent OS）
- 所有知识最终真源 + 唯一治理权
- 人类学习侧直接在此完成，AI 侧知识 API 供给项目
- 不存可执行载体，不拥有 Agent 运行时

### 第二层 转化器项目（开放集合，调用 + 转化 + 归档）
- 当前：WORK-LAB（控制转化器）+ DESIGN-LAB（设计转化器）
- 阶段 1 各自持有已转化沉淀的规则/技能/插件，阶段 2 逆向归档到 ArcheAxis

### 第三层 执行（宿主 + 客户端）
- Agent 执行 = 客户端（DSH/Hermes/Codex），模型/视觉运行时 = 宿主（Open Design），由 WORK-LAB 治理

## 6. 归属速查

| 内容 | 归属 |
|---|---|
| 所有知识（事实/经验/规则/方法/规范/Lesson）| 最终归 ArcheAxis（阶段 2 逆向归档）|
| 现有规则/技能/插件 | 阶段 1 归各自项目所有，阶段 2 逆向归档 |
| 人类学习侧知识 | ArcheAxis 原生，不转化出去 |
| 项目角色 | 调用 + 转化 + 归档，不拥有知识（阶段 2 后）|
| 未来新项目 | 开放接入，同样调用 + 转化 + 归档 |

## 7. 红线（8 条）

1. 人机双向不可偏废（人类重型学习链与 AI 使用链同等重要）
2. ArcheAxis 独立系统，不是任何项目的模块
3. 唯一知识真源 = 唯一治理权（candidate 治理 ArcheAxis 独占）
4. NOT an Agent OS（不拥有 Agent Runtime/多 Agent 调度）
5. 未来蓝图锁定重型学习系统级（H0-H10 + SYSTEM_MASTER_BLUEPRINT_V2）
6. 受控调用边界：ArcheAxis P3 = 知识/学习资产调用，不是 Agent/工具调用
7. 受限探索边界：ArcheAxis P10 = 知识治理辅助受限 tracer，不是通用 Agent 执行
8. 分阶段演进：现有资产阶段 1 归各自所有，阶段 2 OS 完整后逆向归档，不破坏现有工作

## 8. 结论

所有知识的最终归宿是 ArcheAxis（OS），但采用分阶段演进：现有规则/技能/插件先归各自项目所有，OS 完整后逆向归档。周边项目（开放集合）是调用者与归档回写者。人和 AI 共享同一份知识底座，知识单向归 OS，项目开放扩展，分阶段收敛，双向进化，越用越强。
