# 风险与回滚

## 风险：定位替换过度

不能全局机械替换“认知”一词。

保留：

- 历史文档标题；
- canonical ID；
- 认知画布等功能名；
- 代码兼容名称。

只修正产品主定位和展示层。

## 风险：把未来目标写成当前能力

必须区分：

- 当前实现；
- Candidate；
- Planned；
- Future。

## 风险：前端包基线过期

此前两个前端包以 `2cdf11e` 为可见基线。
当前云端已是 `a92e673`。

执行前必须在新 HEAD 重放设计和测试，不得直接覆盖。

## 风险：技术栈升级混入定位 PR

禁止在定位 PR 中：

- 升 Python；
- 升 Tauri；
- 改数据库；
- 拆 Dependency；
- 迁 React。

## 回滚

定位 PR 原则上无 Schema 变化：

- 可通过单 Commit Revert；
- 不需要数据库回滚；
- 不改变用户数据；
- 不改变 Release；
- 不删除历史文件。
