# 元枢系统最终项目定位

## 中文标准定位

> **元枢系统 ArcheAxis OS，是一套面向个人与 AI 协同使用的、本地优先、证据驱动的双向重型学习知识系统。**

## 英文标准定位

> **ArcheAxis OS is a local-first, evidence-driven, bidirectional learning and knowledge system for individuals and AI.**

## 核心价值

> **同一份知识，人学得更深，AI 用得更准。**

扩展表达：

> 让个人与 AI 围绕同一套受治理的知识底座共同学习、共同使用、持续校正。

## 一源、双学、双向反馈

```text
原始资料 / Source Asset / Evidence
                    │
                    ▼
          受治理的统一知识底座
              ┌─────┴─────┐
              ▼           ▼
          个人学习链     AI 使用链
              │           │
              └─────┬─────┘
                    ▼
        人工审核与双向知识演进
```

## 个人学习链

```text
资料
→ 理解
→ 结构化
→ 课程/笔记
→ 练习
→ 复习
→ 掌握
→ 应用
→ Teach Back
→ 迁移
```

## AI 使用链

```text
Knowledge Unit
→ Retrieval
→ Context Pack
→ Machine Knowledge
→ Task Support
→ Tool / Agent
→ Trace
→ Evaluation
→ Candidate Lesson
```

## 双向反馈

### 人 → AI

- 学习笔记；
- 纠错；
- 错题；
- Teach Back；
- 实践案例；
- 人工标注；
- 审批决定；
- 领域经验。

上述内容只能先成为 Candidate。

### AI → 人

- 新来源；
- 新 Claim；
- 冲突；
- 未知项；
- 解释；
- 练习题；
- 案例；
- 任务结果；
- 失败经验；
- Lesson。

AI 输出也只能先成为 Candidate。

## “重型”的定义

“重型”不是界面复杂，而是长期承载：

- 大规模多格式资料；
- 原始资产与转换产物；
- 来源与 Evidence；
- 多版本知识；
- 项目知识空间；
- 多年学习记录；
- 复习与掌握度；
- AI 可用知识；
- 任务与 Trace；
- Evaluation；
- 备份、迁移和恢复。

## 对外不再主打

- 认知操作系统；
- 通用认知 OS；
- Agent OS；
- 个人 AI OS；
- 自主认知系统。

## 内部仍可保留

- 认知画布；
- 认知检查器；
- 认知增强；
- 认知闭环研究。

建议逐步替换：

| 旧术语 | 新术语 |
|---|---|
| 认知闭环 | 学习—知识—应用闭环 |
| 认知检查器 | 上下文与证据检查器 |
| 认知演化 | 双向反馈与知识演进 |
| Cognitive Workspace | Human–AI Learning Workspace |
| Cognitive OS | Learning & Knowledge System |
