# AXOS 开源增强总览与最终裁定

## 合法吸收方式

| 方式 | 说明 |
|---|---|
| Provider | 通过 AXOS 稳定接口提供解析、检索、模型、评测等能力 |
| Sidecar | 独立进程运行，许可证、崩溃和依赖与核心隔离 |
| Algorithm Reference | 只吸收算法、数据结构或流程思想 |
| Benchmark | 只用于结果对照 |
| UX/Architecture Reference | 只用于 Human-first、审批、工作台和权限设计 |

## 推荐核心组合

### 摄取
Docling + PaddleOCR-VL + GLM-OCR + Crawl4AI + Repomix + faster-whisper

### 知识与记忆
SQLite Facts + LanceDB + Qwen3 Embedding/Reranker + TinyCortex PoC + Graphiti 时态语义 + Bob's Big Brain Compiler 知识编译思想

### Agent 与工作流
Hermes + PydanticAI + 可选 LangGraph；TinyAgents/TinyFlows作为未来 Rust 运行时和工作流合同对照

### 压缩与评测
TinyJuice CCR + OpenTelemetry/OpenInference + DeepEval/Ragas/Promptfoo + Inspect AI

### Human Learning 与工作台
Py-FSRS + marimo + H5P + React Flow + MCP Apps

## 严禁事项

- 不把 OpenHuman、RAGFlow、Letta、Cognee 等整套平台嵌入 AXOS。
- 不允许外部项目直接成为正式知识、任务或权限事实源。
- 不让向量库承担不可重建的唯一数据。
- 不让 Agent 自行晋升知识、修改安全策略或覆盖 Audit。
