# ArcheAxis OS 开源能力吸收执行包

扫描基准日期：2026-07-25

这不是“用某个开源平台替代 AXOS”的推荐包，而是 **AXOS 开源能力吸收注册表**。

## 内核原则

1. AXOS 永远掌握事实、版本、权限、Job、Outbox、Audit、Eval 和知识晋升。
2. 外部项目只允许以 Provider、Sidecar、算法参考、Benchmark 或 UX 参考进入。
3. OpenHuman 只吸收能力，绝不作为 AXOS 的入口、替代项目或第二事实源。
4. GPL、商业许可和自定义许可项目默认隔离验证。
5. 所有 PoC 必须可删除、可回滚、可复现，不改项目目录外文件。
