# PoC 验收测试集

## 文档解析
测试：数字PDF、扫描PDF、表格、公式、横竖混排、印章、PPTX、XLSX。
门槛：
- 页码与证据坐标覆盖率 ≥ 98%
- 表格结构准确率 ≥ 92%
- 关键字段准确率 ≥ 95%
- 低置信度必须进入人工队列

## 检索
指标：
- Recall@5、Recall@20
- MRR、nDCG@10
- Citation Coverage
- 过期事实命中率
- 冲突事实识别率

## Agent
- 任务完成率
- 工具选择正确率
- 参数校验失败率
- 取消响应时间
- 中断恢复成功率
- 人工接管率
- 越权操作率必须为0

## 压缩
- 错误、警告、Diff changed lines、函数签名保留率 100%
- 有损输出必须含 recovery_token
- 恢复后与原始内容字节级一致

## 记忆
- 重复写入去重
- 新旧事实共存和失效
- 来源回放
- 外部同步内容带 taint
- 正式知识不能被认知记忆覆盖

## Windows
- 3060 Ti显存峰值
- 模型装卸时间
- 多进程崩溃恢复
- UTF-8配置损坏恢复
- 长路径、权限和文件锁
- DLL缺失预检查
