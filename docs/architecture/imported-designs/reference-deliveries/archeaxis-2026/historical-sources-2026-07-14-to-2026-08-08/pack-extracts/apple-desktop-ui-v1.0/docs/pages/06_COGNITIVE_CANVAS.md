## 三种模式

### Research

Source → Claim → Evidence → Conflict / Unknown → Package

### Knowledge

Knowledge Unit → Relation → Learning → Mastery → Machine Knowledge

### Execution

Goal → Context → Plan → Permission → Tool → Evidence → Evaluation → Lesson

## 原则

- 节点与边来自后端合同；
- 不生成第二套影子数据库；
- A4 先只读；
- 不允许客户端构造 Evidence；
- Inspector 显示节点真实属性；
- 支持 Mini Map、Zoom、Filter、Export；
- 大画布需性能预算。
