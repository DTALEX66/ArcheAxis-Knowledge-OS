# 页面 07：证真回放

## 参考图

`references/screens/07_execution_replay.png`

## 目标

像调试器一样回放任务过程，同时让普通用户看懂发生了什么。

## 页签

- 回放时间线；
- 执行概览；
- 证据快照；
- 评估结果；
- 审计历史。

## 时间线事件

- Task created；
- Planning；
- Retrieval；
- Tool；
- Permission；
- Human review；
- Artifact；
- Evaluation；
- Lesson；
- Completed/Failed。

## 真相要求

只有持久化事件才能出现在时间线。
不得用前端计时器补齐历史阶段。
