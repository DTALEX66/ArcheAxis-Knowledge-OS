## 实现规则

### 可显示

- 后端真实 DTO；
- Release Manifest 能力状态；
- 真实 Job/Outbox/Receipt；
- 真实 Candidate/Approved；
- 真实 Empty/Planned。

### 不可显示

- 前端随机数；
- 演示用固定统计；
- 根据时间推算任务进度；
- 伪 Agent；
- 没有后端合同的成本；
- 内部 ID；
- 用户绝对路径；
- 完整凭据。

## 文案

推荐：

- “尚未接入”
- “当前仅提供聚合状态”
- “任务级详情将在后续阶段接入”
- “未验证”
- “需要人工复核”

禁止：

- “智能体正在深度思考”但无真实事件；
- “已验证正确”但 correctness 未验证；
- “实时”但只是轮询静态数据；
- “安全”但没有权限合同。
