# 页面 05：藏识知识编辑器

## 参考图

`references/screens/05_knowledge_editor.png`

## 目标

将知识目录、正文、属性、证据、关系和质量放在同一个专业编辑工作台。

## 结构

- 左：知识树和标签；
- 中：Knowledge 内容；
- 右：
  - 属性；
  - 来源与证据；
  - 关系/反向链接；
  - 质量与状态；
- 底部：保存、版本、发布/晋升。

## 风险

当前 Knowledge 多数为候选治理投影，不应直接提供自由写入和“发布更新”。

## A2

先做只读详情与真实状态。

## 后续

编辑必须通过版本化 Knowledge contract 和 command receipt。
