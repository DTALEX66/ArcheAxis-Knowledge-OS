FE03 执行本清单。当前包包含参考图、源图标、字体、材料 CSS、React 配方、原创轻量 SVG 背景与小栖状态 SVG。七个 key-view JSON 是新的生成与复核 brief，本轮没有重新生成这七张效果图。

## 视觉来源与选择

R3 是默认硬核宇宙玻璃的主材质参考。R1/R2 保留作为更梦幻的对照，不使用其紫粉高饱和作为默认正文风格。R5 借用中央人物与周边入口的首页构图，学习内容不使用武器、货币或游戏战力面板。R6 用作人物与文字留白参考，无法据截图判断真人使用视频、2D 或实时 3D，也不把其中真人作为已获权利资产。

## 必须分离的资产

1. 场景底图：无 Logo、无 UI、无人物、无文字，分别输出 1920×1080 与 3840×2160；保留可裁切的主体安全区。轻量版静态压缩资源，增强动态后续。
2. 行星、星环、星尘与地景：可独立合成的源层；需要 cutout 时使用真正透明背景。细节适配三种窗口比例，不能用白底冒充透明。
3. 玻璃表面与边缘光：主体面板由 CSS／矢量实现，背景高光或复杂纹理可用有权利位图；不要把所有文字按钮烘焙成一张图。
4. 小栖：原始角色源、首页人物、半身与头像呈现、状态动作、尺寸与降级配置；角色来源统一由 GF03 维护。
5. 图标与组件：优先包内 Lucide、Radix、Dockview 及当前编辑器。图标线宽、尺寸、选中光边和状态文字引用统一 tokens。
6. 七类关键界面：首页、阅读、陪学、模型、能力目录、配置、错误。保存概念效果、可编辑 UI 构成与最终安装版截图三类不同产物。

## 导出和清单

每项记录 id、用途、source、author/rights、license、source_hash、output_hash、dimensions、alpha、quality_profile、load_policy、renderer_owner、version 和 production_state。SVG／CSS／TSX 作为可编辑源，WEBP／AVIF／PNG 按实际查看工具与透明支持选择；涉及栅格编辑或角色生成时用图像工具保留参考，不能通过程序硬裁参考图宣称完成新人物或场景。

所有 UI 正式文字、模型名字、用量与状态由代码渲染。效果图人物不证明真实口型；宣传要有实际构建版本与状态。当前 orbital-background.svg 是代码原生轻量起点，不声称为已升级完成的写实宇宙宣传图。
