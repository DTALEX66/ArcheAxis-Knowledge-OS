# 冷色三主题规格

这是对旧报告暖白与金色方案的明确覆盖。黑色保留现有React底色；珍珠白采用中性至冷蓝灰；深空保留海军蓝/青绿，铂银与冰蓝提供星环装饰。冷紫只作小面积场景可选色，禁止成为第四主题。

## 令牌与材质

`adapters/themes.css`为语义Tokens草案；先对照当前tokens.css变量和主题偏好端口增量映射，不直接整体覆盖。维持一套结构与组件；主题切换只改Tokens与主题资产映射。UI主题/密度可以持久化为UI偏好，知识/学习/AI业务数据不得写localStorage。

- 背景/导航/面板/浮层至少四层；细边框与内亮优先，暖色高光为零。黑色基础页不铺紫色大渐变。
- 珍珠白使用冷白表面、蓝灰边线和柔和冷灰阴影；避免奶油黄或暖灯光照片。不要简单反色深空图。
- 深空场景主图用冷海军蓝、青绿、冰蓝，允许少量冷紫星光。正文表面稳定，星环不穿过文字区。
- 圆角6/10/14px；按钮紧凑/标准/触控分别32/36/44px候选，触控目标按真实使用验证。图标16/20/24px，优先已有24视口和1.7线宽几何。
- 正文阅读宽建议680–820px，默认760px；全能力菜单232px候选、Inspector300px候选。均是初始布局预算，须按Windows/DPI实测修订。
- 微交互140ms，面板200ms；运动关闭时静态降级。禁止持续全屏动画、必要控件闪烁、信息仅靠颜色或hover。

警示使用冷蓝灰＋三角图标＋具体文字，成功/危险使用独立状态色（危险偏冷玫红）。关键错误不能用Toast一闪而过；禁用态仍保留原因。

## 资产映射

黑色优先旧monochrome/planet供体；珍珠白优先透明或裁切后的冷调主题版本；深空优先旧aurora/planet供体。旧图中暖金/米色区域应改图/遮罩/换供体，不能只改CSS。正文、交互图标及星环品牌笔刷改为语义令牌。
