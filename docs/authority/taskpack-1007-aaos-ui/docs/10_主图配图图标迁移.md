# 主图、配图与图标迁移

## 已核供体

仓库已有 `aaos-brand-mark.svg`、AaosBrandMark.axaml、AaosIcon.tsx；本包附固定SHA原文。星环几何保留，金色固定笔刷改冷色Tokens，小尺寸品牌变体仍需实际图标验证。AaosIcon已有9种glyph，按原视口/线宽优先复用。

已核主图路径存在：`home-planet-hero-20261001.png`、`home-planet-hero-monochrome-20261001.png`、`aaos-home-hero-aurora/monochrome[-b03-v1/v2/v3].png`、`evidence-anchor-empty-state`、`knowledge-constellation`等，详见现行asset manifest/source audit。部分旧Home确实使用planet；很多旧资产仍未引用。主图二进制没有在本轮完整重新获取查看，不能写成全部视觉已验/已迁移。

## 迁移步骤

1. 从用户指定UI套件目录和仓库现有Assets逐文件核对：实际存在、当前引用、尺寸/色彩、作者许可、sha256。47个旧ZIP不按名称假设每个都有效，先读取已有审计再补缺。
2. 用旧planet/aurora做深空主图候选，monochrome做黑色候选；珍珠白选透明/冷背景版本，必要时裁切、降饱和、遮罩。暖金/米色不进入生产三主题。
3. 上传初版图作为视觉参考，避免直接整张概念截图塞进主图；效果图中的第三方Logo和示例文字不迁移。
4. 正式资产统一命名和主题映射；Raster建议WebP/PNG按实际透明需求、SVG保持安全静态；尺寸预算/懒加载/低内存路径实测。装饰alt为空，传达信息的配图用准确描述；知识事实必须另有正文/证据。
5. 每个主图/空态/功能图标必须有实际组件引用，manifest写入用途/来源/许可/hash/主题/验证状态。没有引用的候选留调研池，不假装完成。
