# Windows下载、部署与回退

本流程在用户Windows项目工作树执行，本次报告环境未替用户安装依赖。PowerShell脚本要求7.2+；不需要WSL/Docker/Linux。Git、Node/NPM使用项目已有工具链，禁止npm --force/--legacy-peer-deps。

## 0 PowerShell工具与脚本语法预检

先运行 `pwsh --version`，脚本要求7.2+。Windows PowerShell 5.1与PowerShell 7可并存；若LTSC现场没有pwsh/winget，按微软官方Windows安装页选x64 MSI或ZIP，不依赖商店：<https://learn.microsoft.com/powershell/scripting/install/install-powershell-on-windows>。使用已有合格版本即可，不为本包升级整个系统。

解包后先执行 `pwsh -File "本包绝对路径\scripts\check-powershell.ps1"`；它用PowerShell原生Parser检查全部脚本。本包已经Tree-sitter语法解析，仍未在用户Windows原生环境运行。

## 1 解包与预检

把包解压到用户确认的 `D:\All projects\UI套件\AAOS_UI_Taskpack_20261007`（如果用户现场路径不同，明确传入实际路径）。源码下载缓存放本包目录或项目 canonical `.project-local/cache/aaos-ui-sources`，不放产品数据目录。项目开发命令必须经 `scripts/runtime/dev.py`；脚本使用其现有command参数路由。

```powershell
$UiPack = 'D:\All projects\UI套件\AAOS_UI_Taskpack_20261007'
$AaosRepo = '填写真实AAOS Git工作树根目录'
pwsh -File "$UiPack\scripts\preflight.ps1" -RepoRoot $AaosRepo
```

预检只读：仓库身份、HEAD、dirty、关键权威是否存在、当前依赖/开发路由、工具可用。HEAD变化时先对账变更，不能checkout旧SHA覆盖新代码。保留dirty；如有修改先识别归属。可在已确认现场创建隔离worktree，但不要强制reset/clean，也不要复制用户数据和未知缓存。

## 2 获取所选源码（已附离线文件）

```powershell
pwsh -File "$UiPack\scripts\get-sources.ps1" -CacheRoot "$UiPack\source-cache"
# 若离线副本缺失，可下载清单中固定commit的文件：
pwsh -File "$UiPack\scripts\get-sources.ps1" -CacheRoot "$UiPack\source-cache" -AllowNetwork
```

先校验本包vendor副本再复制；网络仅补缺且下载后比对SHA256，不执行下载代码。源码目录与收据可复现。Galaxy是HTML/CSS存档，不需要NPM安装；保留作者注释和MIT通知。

需要浏览更多候选时，使用Git下载固定commit完整来源（可在source-cache的独立新目录逐库执行，不更改AAOS仓库）：

```powershell
git clone --filter=blob:none --no-checkout https://github.com/uiverse-io/galaxy.git "$UiPack\source-cache\galaxy-repo"
git -C "$UiPack\source-cache\galaxy-repo" checkout --detach adbd2adde0a299a3956ea288fb444ec01891ca41
git -C "$UiPack\source-cache\galaxy-repo" rev-parse HEAD
```

其他库的固定commit见 `spec/pool-revisions.json`；同样clone到独立目录并比对HEAD。禁止把整个node_modules/示例站点复制进AAOS。网络无法获取时用14个已附文本文件，候选不足再按真实需求增量选取。

## 3 锁定并安装最小依赖

仅需弹层/标签适配样例时安装core profile；菜单/表单/虚拟表格/图标/图谱/运动分阶段按真正的import安装。解析模式只查询NPM并写版本收据，不改package；安装模式要求已有锁定收据。网络可用性、NPM安全检查和React peer由现场确认。

```powershell
# 先解析当前已发布版本、peer和engines，生成固定版本收据
pwsh -File "$UiPack\scripts\install-ui.ps1" -RepoRoot $AaosRepo -Profile core -ResolveOnly
# 使用上一步生成的完整绝对路径（脚本输出）
pwsh -File "$UiPack\scripts\install-ui.ps1" -RepoRoot $AaosRepo -Profile core -ResolvedLock '上一步输出的npm-lock.json'
```

版本没有在任务包中假设为已发布：GitHub package.json版本不等于NPM发布版本。首次解析锁定实际版本/peer/engines，随后按该文件安装。已有依赖不被无声升级；dirty package.json/package-lock阻止安装以保护现场，执行者先完成归属对账再继续。严格peer冲突或engine不满足则保留错误，换兼容版本/减少profile，不强行升级基础栈。

安装参数：`--save-exact --strict-peer-deps --engine-strict --ignore-scripts`。忽略安装脚本是本轮纯JS组件的限定流程；若未来有需构建的原生包，单独核实其安装脚本与项目约束，不悄悄放开。Core profile当前只含Dialog/Tabs分包。

## 4 吸收源码到产品

`adapters/AaosPrimitives.tsx`和`primitives.css`可作为基础样例复制进现有 `frontend/src/design-system/` 约定目录；先做局部Dialog/Tabs/Input/Button样板，与现有Component/CheckPanel一起验证。`themes.css`只增量映射现有令牌；禁止覆盖原恢复/业务CSS。

把shadcn结构与Radix行为合并到AAOS自有组件；去cn/registry内部路径、第三方品牌、默认暖色、无用依赖。Galaxy/magicui只在模块范围命名class/keyframes，不放全局button/body选择器。需要的许可证放项目 `THIRD_PARTY_NOTICES` 或现有规范指定目录，source-lock并入既有资源索引。

三主题/图标/主图映射由一个theme registry提供；主题选择端口存UI偏好。任何知识/审核/学习/AI资产操作继续现有Core DTO，不在样例里实现第二真值。

## 5 验证与候选部署

优先阅读当前AGENTS及CI脚本；命令使用已确认脚本参数。基础命令示意：

```powershell
Set-Location $AaosRepo
python scripts/runtime/dev.py -- npm --prefix frontend run build
python scripts/runtime/dev.py -- npm --prefix frontend test -- --run
# Rust/worker/宿主相关检查按改动范围使用现行 scripts/ci/run_tests.ps1 等入口
```

本包不自动安装覆盖Green、不发布安装包。完成源码/真实旅程之后，按Q14现行正式流程生成独立候选，并运行同SHA/版本的真实Windows WebView2、离线、重启、退出、IME和DPI验证。不能用cargo build直接替代Tauri内嵌前端构建，不能借用旧候选canonical21资格。

## 6 回退

仅回退本次确认所有权的代码/依赖差异，保留预检记录与提交diff。已提交的增量用revert；未提交增量按精确文件/patch撤销，不能git reset --hard或clean。依赖回退恢复本次前的package与锁文件，再按现行开发入口npm ci；不触碰Core数据/schema/CAS、未知缓存、备份或Green。失败收据保留，不用“成功截图”替代失败记录。
