# 未来能力与界面边界

未来能力必须可发现并有用途/对象/前提/依赖/降级/下一步；只有真实合同/连接/运行资格具备才允许对应执行。以下映射保持10/4未来延展语义，不把未来全部实现纳入本轮装饰重构。

| 既有任务 | 能力 | 界面边界 |
| --- | --- | --- |
| F00 | 统一契约/能力/恢复 | 沿现有权威、Core身份/协议/事件，不建另一知识真值 |
| F01 | 稳定块编辑 | Document/Block codec、未知节点保留、同版本保存 |
| F02 | 集合/属性/关系/视图/公式 | Table只是渲染；Core拥有领域规则与持久化 |
| F03 | 多平台互通 | 平台×版本×功能×方向×样本，真实回读及损失 |
| F04 | 人类诊断/练习/讲解/迁移 | 客观结果/自评/掌握指标独立；FSRS仅调度 |
| F05 | 课程与教学 | CoursePackage、按需OpenMAIC供体、离线事件/脚本隔离 |
| F06 | 研究/项目/实验 | Project/Artifact/Experiment/Rubric；文献供体按范围接入 |
| F07 | AI资产与纠正 | 候选→评测→真人认可→范围化使用→漂移/纠正→撤回；参数训练单独前置 |
| F08 | 动画与参数仿真 | Manim动画≠交互仿真；单位/算法版本/参数/结果可追溯 |
| F09 | 空间记忆 | SpatialPackage World/Room/Locus/Route，2D→2.5D→3D；文本/2D降级同对象 |
| F10 | 同步协同 | Yjs等供体未来按合同；不绕Core权限/业务写者 |
| F11 | 插件/worker/受控agent | 有限接口/权限/预算；不扩成通用Agent OS或先做市场 |
| F12 | 移动/Web/加密 | 客户端能力/安全及离线同步按前置 |
| F13 | XR/AR | Godot/OpenXR等不同设备真实验证；不靠3D截图宣称支持 |
| F14 | 升级/退出与可持续 | 依赖升级矩阵、离线导出、迁移/回滚、source notices |

普通界面不因未来模块不存在而装满依赖。图谱、3D、课程执行、协作和模型训练各自按前提渐进接入；可浏览详情不能伪装已可运行。
