## 推荐触达目录

- design-system：现有tokens/themes/primitives；壳：app/components/spaces/entry projection；具体路径采用仓库现行约定。
- features/内容/证据/学习/AI：在对应Canonical组件/现有端口中精修；不要重写Core writer或搬进旧Python后端。
- 资产：正式前端统一资源目录和manifest；旧主图、SVG几何、作者与hash登记；不要复制全部UI ZIP与无引用资产到生产bundle。
- 文档：已有Authority/decisions做最小UI delta；唯一Q账本新增本轮事实；截图、收据进canonical开发输出。

每批DoD：真实实现diff；与既有逻辑一致；三主题与适用状态；源码/许可证可追踪；代表旅程；失败/未验清单。当前源码和本包111拆分条目都不能签发全部完成资格。
