## 基础组件共同合同

Button有variant、size、busy、disabledReason、accessibleName；图标按钮名字可读。Input有label/help/error关联、controlled值；中文IME必须判定isComposing后处理快捷键。Checkbox/Radio/Switch不以主题色表示全部状态；危险动作不用开关。Tabs是页内切换，文档关闭/草稿保护交给Feature。Dialog有title/description、受控open、焦点圈定/恢复、Escape；触发器未丢失。Dropdown/Popover/Tooltip关键信息有键盘和非hover路径。Tree父子/展开/选中分离；Table稳定row ID与真实分页；Resizable含最小正文宽和键盘调整。

## 公共数据状态

读组件：loading/empty/ready/partial/error/offline/unavailable；写组件：dirty/saving/saved/readback_failed/conflict/retry；任务：queued/running/succeeded/failed/cancelled/blocked；知识与AI资产：candidate/accepted/revoked。基础纯视觉元素按适用范围使用交互态，不把所有状态机械加入每一个图标。

## 验收旅程

同一资料：导入/保存→重启读回→原件阅读与锚点→编辑新版本→识别/依据核验→真人知识认可（仅对应领域流程）→练习/复习→受控AI回答→纠正候选/审核/复测→导出/独立回读→副本恢复。每一步保留真实ID、版本和回执；核心链没有实现时写清缺口，不以假数据或样例截图补齐。
