# 组件池找回与选择

## 原研究证据

已读取：9/28《AAOS_UI深度优化调研与Codex执行方案》、9/30《三项目商业级前端UI完成任务报告》、两份《执行摘要》、427行《执行概要》、9/30《Executive Summary》，并读取10/4快速重构和未来延展两包。原池的关键聚合源为 `uiverse-io/galaxy`，不是未经核实的 `buikevin/galaxy-design` 或“Galaxy UI CLI”。旧研究跨AAOS/WORK-LAB/DESIGN-LAB，不能把其他项目菜单/功能一并迁入AAOS。

历史研究里还有 `@shadcn/ui`、`galaxy-design-cli`、`@galaxy-ui/react` 等未证实示例。本包删除这些执行命令；当前官方shadcn安装文档使用 `shadcn` CLI，但本轮默认按已锁定源码吸收，不运行latest初始化去替换整个CSS。

## 默认接入方案

现有AAOS业务组件和CSS → 选定shadcn结构/交互供体 → Radix分包提供焦点/键盘 → AAOS语义Tokens统一外观 → Galaxy只提供局部动效/材质。Magic UI限首页/空态小面积可选装饰，普通阅读/学习页面不常驻重型shader/3D背景。

已取回14个文本文件，8个组件源码样本。文件commit/blob/SHA256见 `spec/source-lock.json`，许可证原文在各vendor目录；整个包校验见 `scripts/verify_pack.py`。上游raw仅供参考，必须经适配层处理后接入产品。

## 本包源码适配点

| 来源样本 | 必须适配 |
|---|---|
| shadcn Button/Input | 去Tailwind依赖的样式改为AAOS class；cn改本地合并；native React props及焦点/invalid语义保留 |
| shadcn Dialog/Tabs | 上游radix-ui聚合包改所选Radix分包；registry内部路径消除；Lucide X换已有图标/可读关闭文本；title/description/焦点恢复保留 |
| Galaxy Skeleton | 原warm红底仅在vendor档案；产品改surface/raised令牌；float改布局；减少运动与读屏隐藏 |
| Galaxy Spinner | 品牌冷色令牌、适当尺寸、role=status文本；未知进度不虚构百分比 |
| Magic UI BorderBeam | 上游暖色默认值改冰蓝/青绿；motion按需；聚焦/状态不依赖动态边缘 |
| Magic UI OrbitingCircles | 补关键帧/令牌/可关闭动画；仅装饰aria-hidden；静态2D降级 |

当前shadcn源码已经出现aria/base/radix多个基座，不能用旧教程随机混拷贝。包内选定new-york-v4样本，版本固定；React18项目不为其升级React/Vite/Tauri。若确需Tailwind完整生成路线，先在隔离样板中验证版本/插件/全局preflight和离线产物，通过后再做最小接入；该路线不替代本包默认纯CSS适配。
