# 验证与验收矩阵

## 本包可核内容

源文件commit/blob/SHA256一致；主题平涂文字4.5:1/控制边界3:1；111条组件ID唯一和三主题覆盖；PowerShell脚本Tree-sitter语法解析（未执行Windows原生脚本）、3个适配文件严格TypeScript类型检查、报告/样例HTML锚点、JS和DOM交互冒烟（Dialog API替身）、ZIP CRC/内容SHA；结果写 `evidence/taskpack-validation.json`。源码/静态检查不等于运行UI验收。

## 产品必须执行

| 维度 | 场景/断言 | 证据 |
|---|---|---|
| 导航 | 全有效能力、旧别名、Ctrl+K、未来详情、任务跳转 | 权威→入口矩阵、断链检查、实窗截图 |
| 三主题 | 黑色/珍珠白/深空；全部关键组件与代表状态 | 同对象/同窗口截图、像素与主题ID |
| 输入 | 中文物理IME、组合期快捷键、长文本/粘贴、撤销 | 操作回执与窗口证据，模拟输入不替代物理IME |
| 键盘/无障碍 | Tab/ShiftTab/箭头、Escape、焦点返回、Dialog圈定、读屏标签 | 交互测试和实机检查 |
| 保存/历史 | dirty、autosave、冲突保留、版本/hash、unknown node、重启 | Core回执/版本读回，不以Toast作唯一证据 |
| 学习 | 答案揭示、客观反馈/自评/调度、幂等 | 真实事件与题目内容、同一资料 |
| 核验/AI | 三维核验独立、候选审核/复测/撤回、范围化资产 | 版本/依据/评测和真人流程身份 |
| 多格式/互通 | 本轮实际支持格式、原件/锚点、损失、外部读回 | platform×version×feature×direction×sample矩阵 |
| 故障/恢复 | offline、worker失败/300s超时、取消、崩溃、备份副本恢复 | 原失败收据、支持动作、恢复后读回 |
| 适配/性能 | 1920/2560＋100/125/150/200%、窄窗、长表、懒3D、减少运动 | CSS px/DPI/进程树、内存/耗时，预算条件可追踪 |
| 宿主 | 独立候选无devserver、Tauri内嵌资源、退出资源释放 | 同SHA的候选hash与现行Q14旅程身份 |

## 完成判定

编译/静态截图/能力握手各自只证明对应范围。记录IMPLEMENTED/TESTED_LOCAL/INSTALLED_RUNTIME_VERIFIED/OWNER_ACCEPTED等必须符合现行台账定义；不重用旧SHA资格。未测试、部分通过、失败要分别保留，不把困难核心缺口归入“第二包未来”。普通内容保存不因专业依据/识别失败禁止；需要真人认可的资产流程使用现行权威。

建议最小代表页面：全能力/首页、资料表、Reader+Inspector、Editor历史/冲突、核验、Learning问题/反馈、纠错对照、AI资产、互通profile、Job失败、恢复。每页三主题至少正常与主要边界态；全面组件状态在组件lab/既有测试入口覆盖。
