# 全能力导航与布局

一组合左菜单 + 中央任务区 + 按需对象/Inspector + 底部活动区。全局不同时常驻两个功能菜单列。对象树/资料列表可在具体任务出现，内容窄时转列表/详情或抽屉；学习Focus Mode收起统计/AI辅助。顶栏含品牌、命令搜索、真实状态、主题；多文档标签只在内容工作流出现。

| 分组候选（可改） | 任务范围 | 能力关联 |
| --- | --- | --- |
| 工作台 | 最近/继续、任务概览、项目入口 | CAP-0090/0120 |
| 内容与知识 | 捕获/导入、原件、文档/创作、知识、集合/版本 | CAP-0010/0020/0110 |
| 证据与研究 | 锚点、专业核验、支持/反证、文献、项目/实验 | CAP-0030/0090 |
| 学习与教学 | 诊断、练习、复习、讲解/迁移、课程/仿真 | CAP-0040/0060/0070 |
| AI资产与纠正 | 受控回答、纠错/审核/复测、记忆/规则/技能 | CAP-0050/0150 |
| 图谱与空间 | 搜索/图谱、2D/2.5D/3D记忆空间、XR | CAP-0080/0110/0160 |
| 互通与协同 | 平台profile、迁入迁出/往返、同步/冲突 | CAP-0100/0120/0140 |
| 系统与能力 | 能力、Provider/worker、预算/权限、主题、备份恢复 | CAP-0120/0130/0140/0150 |

这八项是当前任务语义分组候选，不是新的“八大空间”权威。实施时按有效Atlas/Requirement修订。用户要全能力展示，不要仅装饰性的菜单，也不要未来能力全部灰掉。

## 单一入口投影

`entry_id`、canonical_target、legacy_aliases、capability_ids、requirement_ids、authority_source、group_id、label、description、icon、keywords、implementation、connection、health、qualification、detail_target、task_target、preconditions、fallback、evidence_links、next_step。

菜单、Ctrl+K、能力页共同使用有效注册投影。上述字段是UI投影建议，不能覆盖Atlas身份或另建一个手工维护能力数据库。现有SPACES九入口作为别名迁移；同能力可从多个任务进入，但规范目的地唯一。收藏/最近用entry_id。

## 响应式验收

布局预算：左菜单232px；Inspector300px；正文默认760px最大宽；ActivityDock折叠摘要40px候选。1280 CSS px附近应优先收辅助列，具体阈值取决于内容最小宽。窄窗菜单抽屉，阅读/编辑/题目主区仍可用；不要求手机模拟桌面四列。

记录实机窗口像素、DPI、CSS px三者。2560×1440在200%缩放不能按2560 CSS px计算。测试1920×1080、2560×1440与100/125/150/200%；另测1440和1280 CSS px、最小可用窗口。Inspector快捷键和切主题不触发额外API写入或丢失草稿。
