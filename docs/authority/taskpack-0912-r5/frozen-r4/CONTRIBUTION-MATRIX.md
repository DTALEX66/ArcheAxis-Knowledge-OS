# 跨任务切片的执行归属

切片是跨任务功能索引，不是额外串行队列。depends_on_slices为整体行为验收前置，不阻塞契约/fixture先行。父任务按原DAG及本表归属贡献验收，不以尚未就绪下游贡献阻塞上游；整条切片闭环在各贡献汇合后验收。HL09/HL12按M0/M1分别检查。

例如X04先完成HL02/03契约，X05实现持久化，X07/X08再验真实使用；不会要求X04先等待依赖它的X05。验收上下文和依赖仍以原TASKS为准。

| 切片 | 父任务 | 本任务贡献 |
|---|---|---|
| HL01 | X00 | 登记来源、决策资格、历史缺口与唯一入口；不等待Core导入完成。 |
