# 07｜可以直接使用的训练与评价模板

以下模板是本报告的操作化设计，不是已整体随机验证的标准治疗或教学协议。题量、时长和通过标准均应按任务设置；高风险专业按正式要求执行。

## T01｜一个学习单元的提取—反馈卡

```text
主题/目标：
可信材料与日期：
事实问题（需要精确记住什么）：
解释问题（为什么、在什么条件下）：
辨别问题（与哪个概念容易混淆）：
应用问题（换一个情境怎么做）：
先不看材料回答：
信心：低 / 中 / 高
核对发现的错误与遗漏：
下一步：补理解 / 改问题 / 增加反例 / 延迟再测
延迟复测日期与结果：
```

参考：[R02](https://pubmed.ncbi.nlm.nih.gov/33683913/) [R10](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.03087/full)。不要先让AI把答案显示出来再自评“我知道”。错误要有证据，不只写“粗心”。

## T02｜记忆宫殿的最小可用实验

```text
目标：要无遗漏记住哪个顺序？为什么顺序重要？
原始可靠清单：
选一条已熟悉路线，设置少量清楚、不重复的位置：
位置 | 知识点 | 图像线索 | 容易混淆的内容
建路线时间：
编码时间：
不看原表按序回忆：
遗漏 / 错序 / 误解：
延迟回忆：
脱离路线后能否说明知识含义或实际使用：
总成本（包括维护）：
是否值得继续：
```

参考：[R06](https://bpspsychub.onlinelibrary.wiley.com/doi/10.1111/bjop.12799)。本包建议先从一个小清单试，而不是建立庞大的虚拟世界。与问题卡比较时材料难度要尽可能接近；这仍是个人试用，不应宣称完成严谨因果实验。

## T03｜样例→缺步→独立变式

```text
目标技能：
前置知识检查：
正确样例来源：
样例中的关键决策与依据：
缺掉的一个关键步骤：
独立补全并解释选择：
新任务与原例的相同点：
新任务改变了什么：
独立完成结果：
错误类型：前置不懂 / 选法不当 / 执行错误 / 依赖提示
下一轮撤去或补回的指导：
```

参考：[R08](https://link.springer.com/article/10.1007/s10648-023-09745-1) [R35](https://link.springer.com/article/10.1007/s10648-019-09465-5)。解释只针对关键点，避免每一步都强制写长篇说明。当前不会不意味着应该永远看完整解答。

## T04｜交错练习的题单

```text
易混类别A：适用条件 / 不适用条件
易混类别B：适用条件 / 不适用条件
易混类别C：适用条件 / 不适用条件
先确认各类基础解法是否已学会：
混排题目，不在题头标类别：
每题先回答：我选什么方法？依据是哪条信息？
再执行：
复盘时分开统计：类别判断错 / 方法执行错
陌生新题测试：
```

参考：[R04](https://pubmed.ncbi.nlm.nih.gov/31556629/)。混排用于需要辨别的材料。不要强行认为所有单词、长文或不同软件之间的交替都更优。

## T05｜概念图与因果解释

```text
核心问题：

这条关系的证据或教材位置：
成立条件：
例外与反例：
最容易误读的连接：
合上图，解释一个跨节点问题：
能否预测某个条件变化后的结果：

```

参考：[R07](https://link.springer.com/article/10.1007/s10648-018-9434-x) [R11](https://link.springer.com/article/10.1007/s10648-017-9403-9) [R25](https://journal.psych.ac.cn/xlkxjz/CN/10.3724/SP.J.1042.2023.02263)。图的目标是把关系暴露出来，不是增加颜色、层级和图标数量。对于不容易想象的人，准确的文字、表格或外部图同样可作支持，不必强迫生动画面。

## T06｜AI陪练提示词与验收

可直接复制的提示词：

> 本次目标是让我掌握知识，不只是拿到答案。先依据我提供的材料提出一个问题，等我作答后再反馈。先指出我回答的具体缺口，优先给最小必要提示，不要立刻完整代答。引用材料位置；没有依据时明确标“待核”。不要把我对答案的熟悉感评为掌握。每个阶段后给一个未见过的同目标题，要求我不借助AI作答。最后输出错误类型、还需核对的事实和下次训练动作，而不是泛泛表扬。

注意：提示词不是技术保证。使用者仍需检查AI是否遵守，并用可信参考答案核对。医学、法律等事实必须有正式来源；不上传敏感个人或客户资料。

```text
材料来源与版本：
我独立做出的答案：
AI给了哪一级提示：无 / 方向 / 关键一步 / 完整解答
我实际改正了什么：
新题（无AI）结果：
延迟复测（无AI）结果：
AI错误及来源复核：
```

参考：[R20](https://pubmed.ncbi.nlm.nih.gov/40560616/) [R21](https://www.nature.com/articles/s41598-025-97652-6) [R22](https://link.springer.com/article/10.1007/s10648-026-10133-8)。

## T07｜设计、写作与内容制作的反馈记录

```text
任务与受众：
必须保持的约束（尺寸、品牌内容、格式、预算等）：
本轮只训练的一个短板：
参考案例及合法使用范围：
原版：
修改了哪个变量：
评价维度（事先确定）：
评价者指出的具体差距：
修订动作：
换一组内容/新尺寸后是否仍可完成：
哪些部分由工具完成、哪些本人能独立解释：
```

这是一份反馈驱动的应用设计，而非已有设计专属效应量的保证。不要把客户偏好与基础错误混为一谈，也不把观看量当唯一学习指标。[R10](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.03087/full) [R20](https://pubmed.ncbi.nlm.nih.gov/40560616/)

## T08｜程序理解与调试

```text
最小程序及版本：
运行前我预测的输入—输出：
预测理由：
实际运行与差异：
只改变一个条件后的预测：
故障现象：
候选原因与验证证据：
最小修复：
能防止复发的测试：
关掉教程和AI后重写同目标变式：
```

属于样例、反馈和无辅助测试原则的工程应用，不是本包验证的某语言专属课程。只在授权环境制造可控错误，不在生产系统随意试验。[R08](https://link.springer.com/article/10.1007/s10648-023-09745-1) [R10](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2019.03087/full) [R20](https://pubmed.ncbi.nlm.nih.gov/40560616/)

## T10｜学习策略的个人试用与停用标准

```text
具体目标：
试用方法：
对照自己的什么既有做法：
材料是否难度近似、是否有先学优势：
总时间（输入、制作、复习、维护）：
即时结果：
延迟结果：
未见过题目的结果：
是否只是因为测验重复而更熟：
仍有哪些混杂因素：
保留 / 调整 / 暂停，以及理由：
```

要比较两种方法，可使用难度近似的内容并交替安排，保持测验条件一致。但小规模个人试用不能排除材料差异、顺序效应与反复测验影响。用途是改善个人决策，不是宣布发现普遍规律。

## T11｜阅读一篇论文的证据卡

```text
标题 / 年份 / DOI：
已读深度：书目 / 摘要 / 正文相关段落 / 全文与附录
问题：对谁、用什么方法、对照什么、测什么结果？
设计：实验 / 观察 / 元分析 / 叙述综述 / 预印本
主要结果（区分数值、单位、置信区间）：
是否有延迟测试和无辅助测试：
主要偏倚、缺失与冲突证据：
更正、撤稿、预印本与正式版关系：
能够推出：
不能推出：
实践建议是原作者建议还是自己的推导：
允许存储或再利用的许可：
```

模板专门避免把“元分析”三个字当作自动高质量认证，也防止把发表日期误作纳入研究的截止日期。[R23](https://asmepublications.onlinelibrary.wiley.com/doi/10.1111/tct.70353) [R33](https://www.nature.com/articles/s41562-026-02532-2) [R34](https://pubmed.ncbi.nlm.nih.gov/40833419/)

## T12｜20张起步卡的制作与质量抽检

数字20只是一个小批量示例，不是实验确定的最佳剂量。先按任务选少量关键内容；每张卡保存问题、参考答案、必要上下文、来源、版本、目标技能。测试过程中区分“不会”“答对但吃力”“答对且可靠”，不要为缩短排期虚报记忆状态。

抽检重点：答案是否正确？卡片是否只测表面措辞？是否缺少条件？是否过度拆碎？是否过时？能否连接真实任务？卡片数越来越多而新任务仍不会时，应减少新增并补理解，而不是继续制造数量。

工具行为说明以[当前Anki手册](https://docs.ankiweb.net/deck-options)为准；平台效果的边界见[R24](https://link.springer.com/article/10.1007/s40670-026-02643-5)。
