# ArcheAxis-Knowledge-OS｜独立增强任务包

## 定位

人类与 AI 双向学习、可信知识、证据与经验沉淀系统。不是 Agent Runtime、工作流调度器或通用聊天平台。

## P0：真实学习闭环

1. 多格式导入：PDF、网页、Markdown、图片/OCR、音视频转写；保留原件、来源、时间、哈希和解析版本。
2. 阅读锚点：页码/段落/时间轴/区域可回到原件；笔记、摘录、引用双向关联。
3. 可信知识流：candidate → review → verified；AI 产出只可生成候选，不能直接成为事实。
4. 学习闭环：知识卡、间隔复习、回忆题、错误原因、掌握度和复盘；明确区分人类学习与机器侧训练材料。
5. 本地/离线模型实验接口：受控调用，不允许会话或外部 Agent 直接写入 canonical knowledge。

## P1：能力增强

- 证据冲突、版本变更与不确定性标记。
- Obsidian 兼容往返：导入、编辑、链接、搜索、引用与回滚。
- 对其他项目提供只读、审核后的知识包；所有调用可追溯。
- 九锚认知等内容仅做可选反思/学习卡，不参与自动事实判断。

## 验收

从一份真实材料跑通“导入—锚定—摘录—候选知识—人工审核—复习—引用问答”；任一结论可回到原始证据，撤销审核后下游不再将它作为真值。
