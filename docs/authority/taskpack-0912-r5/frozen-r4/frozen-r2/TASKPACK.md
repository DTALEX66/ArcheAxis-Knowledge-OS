### 3.1 内容入库不能被证据门误伤

- 原始资料一经用户导入即可保存；个人定义、观察、笔记、解释、假说、传闻报告和预测都可留存、检索和学习。
- 内容类型、来源、识别质量、事实核查状态、用户接受状态分开。USER_ACCEPTED 不等于外部事实已证实；机器不能伪造用户身份或接受动作。
- 事实核查展示原始出处、支持/反证、来源独立性、日期、适用范围、未查到与争议。转载十次不等于十份独立证据。
- 科学假说、未来预测、未经测试、证据不足、疑似谣传和已被原始资料反驳分开；不能用“未检索到”直接判假。
- 文学诠释和个人术语允许多种解释。按用户选定定义教学时显示定义范围，不强行被网上惯用说法覆盖。
- 无联网/无云端凭据时照常保存和本地学习，明确“核查待完成”；缺少真实云端核查证据时不得称全链已经通过。

### 3.2 四种质量分别测量

1. 转换忠实度：中文/英文分层 CER、适用分词规则下的 WER、数字/单位、表格结构、公式和页/区域/时间戳锚点。保留金标、预测、规范化规则和样本数；CER 可能大于 1，不能把 1-CER 无条件当通用准确率。
2. 事实核查质量：可核对标签集上的正确性、误判、遗漏、引用有效性和来源覆盖；模型自报置信度或多模型投票不能代替金标评测。
3. 人类学习效果：即时与延迟回忆、理解解释、应用、迁移和讲回分别记录；FSRS 回忆概率不是综合理解分数。
4. 机器能力：按任务族、模型/提示/工具/知识版本记录成功、失败与适用范围；未测标 UNMEASURED。取到文档、答对一次、更新检索库，都不等于训练了模型权重。

### 3.3 R2：审核、定位与撤销的实际行为

附件的 `candidate → review → verified` 只表示简写流程；X04 必须继续独立记录内容类型、用户接受、外部核查、版本和使用范围。AI 通过 Core 提交候选，不能自授人工身份或有效事实状态。个人定义无需外部证明即可保存、学习和按范围调用。

笔记、摘录与引用能回到对应版本的原件位置；从原件位置也能查看关联内容。原件变化或定位失效时显示重定位/待复核，不能默默跳到错误段落。个人内容回到原始输入，推导回到资料与方法，不伪造外部证据。

撤销审核或替换知识后，Core 后续受控检索和上下文输出先检查当前资格；异步索引未刷新也不能把失效版本当有效事实。人类题目、机器上下文与缓存标记过期/待复核；活动任务在下次读取或结果入库时检查版本。旧回答、原件及学习历史保留并标注，不声称能收回外部已生成文字。G07 同时检查两侧再次调用与重启恢复。

### 4.1 复用决策与退出规则

每个缺口先看旧资产与已调研登记，再选主候选。X03 的首次验证预算建议 4 个有效工程小时；遇阻只处理有证据的安装/兼容问题，记录失败后选一个备选。该预算是防止无限调研的控制点，不是要求超时就自研。

复用方式按成本判断：现成课程/资源→直接运行→标准导入导出→官方接口/CLI→适配→合法 fork/vendor→独立实现。需要付费 API 时记录必要性、本地替代与实际费用范围，使用已授权的服务与预算；不能因为有价格就默认重写，也不能擅自订阅付费服务。

自研准入需要一份小型缺口记录：具体用户功能、已试候选与失败、接口/许可/成本障碍、可替代性、最小实现范围、维护成本、验收样本。付费或难集成不构成复制未授权代码/素材或绕过服务控制的理由。原则上先冻结，待 M0 可用后按收益解冻。

## 5. 语言定位：调整表现层策略，不重开全量迁移

| 层 | 选择 | 责任与限制 |
|---|---|---|

这里的 Web 不是复活旧 Tauri 为另一默认产品。旧 React/Tauri 继续作为维护、恢复和资产供体；若调用其某个组件，登记具体范围。若 Avalonia 承载上游页面需要高成本 WebView 授权或重写，第一版直接打开本地浏览器，不让桌面封装阻塞。

保留同仓 vNext 与独立新库：legacy Python 仅写旧库，Rust 仅写新库。旧库快照→只读导出→Rust staging 导入→差分→激活；禁止双写、实时双向同步和让新 Rust 服务直接改旧库。

上游 Tutor 的索引、缓存可重建；其会话、笔记等用户产物必须经 API/可靠导出回收，回收前不能当缓存清理。适配器未完成时只能算上游单独可用，不能宣称 ArcheAxis 已贯通。Anki 原生复习数据库也不直接交给 Rust 写：通过明确适配保留事件与版本，不做两个排程器互相覆盖。

## 6. 最快闭环：M0 先交付，M1 扩覆盖

### M0：能日常使用的人机双侧版本

支持的首批样本至少包含：手写个人定义/Markdown、文本 PDF、截图、静态网页、一个动态网页/长页、扫描或混合 PDF。网页/图片/扫描材料都要实际进入转换与引用链；功能缺失诚实显示。其他已通过同一验收的格式可直接随包提供，不人为等待下一版。

必须完成一个可见旅程：

导入资料→保留原件→本地识别/转换→定位疑似错误→云端查询公开原始资料并比较→保存带类型和核查状态的知识→建立学习目标/路线→讲解与练习/讲回→复习记录→AI 客户端检索和执行一个受控知识任务→反馈修正→再次调用新版本→重启及备份恢复。

“受控知识任务”可以是按规则完成资料核对、生成带引用的结构化学习材料或执行一个纯本地无副作用计算；不能只返回搜索结果就结束。

M0 不要求联网证明每条个人笔记，也不要求每张截图都由云模型重新识别。要求真实配置的一次本地模型识别和一次云端检索核查成功；缺少模型、网络或凭据时其状态为 BLOCKED_RESOURCE，不拿 mock 代替。

### M1：多格式与更完整使用体验

## 9. 仓库规范化必须控制真实写入

### 9.1 位置

| 位置 | 定位 |
|---|---|
| `crates/` | Rust 核心与服务 |
| `services/python-workers/` | 可替换计算能力 |
| `apps/ArcheAxis.Desktop/` | 既有 C# 桌面与生命周期 |
| `apps/learning-web/`（确有适配代码时才建立） | 上游学习/交互的薄适配；不复制第二业务后端 |
| `packages/contracts/` | 跨语言单一语义 |
| `config/`、`scripts/`、`tests/`、`docs/`、既有 `.project/` | 默认配置、可执行入口、必要测试与唯一当前权威 |
| `<repo>/.project-local/` | 项目内、ignored 的开发运行根；不是软件安装目录或永久知识库 |
| 用户配置的产品 workspace | 原件、知识、笔记、学习记录和备份；永久资产 |
| 工具自身配置目录 | CODEX/DSH/HERMES 的会话、配置、技能；按工具实际配置，不擅自迁移 |

`.project-local` 分别保存 run 的 tmp/log/artifact、构建、缓存、盘点和保留证据；保留证据不能跟缓存一起 TTL 删除。私有资料、模型权重、数据库、凭据、完整聊天档案不进 Git。

### 9.2 必须同批修复的执行面

AGENTS、当前规范、.gitignore、启动/测试脚本、conftest、网页截图、CI/nightly/release、打包和相关测试一起对齐。只改说明文档或全局替换字符串不能算完成。

Chromium Unix socket 有路径长度限制：普通输出用项目运行根；必要短根必须显式配置、受控、按 run 隔离并记录例外。禁止静默创建 C 盘/其他项目临时根，禁止未经授权访问 E 盘。链接/junction 解析到未授权范围时拒绝继续。

不要改 HOME、CODEX_HOME 或工具全局配置冒充项目重定向。AGENTS/.gitignore 不是操作系统沙箱；对工具或系统不可控的写入记录真实例外，需要严格物理限制时用已有权限/沙箱。不能宣称“仓库规范保证所有软件绝不外写”。

验收同时看 tracked/ignored 文件的前后差分、路径归属、失败退出、并发 worktree 和浏览器运行。对旧 `.hermes` 先只读盘点并保全唯一收据、补丁和会话。56.6GB/55.3GB 的旧表存在算术及缓存分类冲突，不能据此整体删除或承诺能释放 40GB。

### 9.3 多软件/多模型不漂移

- 所有执行器读取同一项目入口；工具专用配置只做短指针，不能维护几份不同规则。
- 一个切片一个允许路径集与 tested SHA；分支/worktree/run 分开。共享契约、锁文件、迁移编号、CI、权威索引由当前集成负责人串行修改。
- 模型名称不提供身份、签名或权限。使用现有真实授权入口，不自签 owner grant、不关 scope gate。
- 用户已授权的常规可逆任务连续执行；不设置“必须等 GPT 下轮发话”的人为依赖。实际缺少权限/资源只阻塞对应动作，不伪造权限，也不停止全部无关任务。
- 正常自身提交后，下一切片记录新基线；原收据仍证明原 tested SHA，不能因 HEAD 前进就全部销毁或改写。真正合并/代码变更影响的结论才重测。
- 任务状态分 TODO、IN_PROGRESS、BLOCKED_RESOURCE、IMPLEMENTED_PENDING_AUDIT、VERIFIED；DEFERRED_RETAINED 不是 DONE。
- PR/候选资格看同一源码树、依赖与安装包；必需 job 的 skipped/cancelled 不算成功。变更感知测试保留，但发布总门不能靠文档检查替代。
