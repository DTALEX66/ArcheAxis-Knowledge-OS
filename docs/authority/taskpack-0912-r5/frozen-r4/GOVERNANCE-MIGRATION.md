# 仓库规范化与语言迁移｜R3.1执行专项

这是R3的强制增量，不是可选建议。原R3第7节及X00/X01/X02/X04/X13等已有方向，但未充分展开迁移对象与退出条件；本补充拆成5项仓库规范化、7项语言迁移，共12项强制切片。

## 定位与完成口径

ArcheAxis继续采用Rust权威核心、Python计算能力、C#/Avalonia宿主和Web/TypeScript表现层。语言迁移包含领域语义、实际调用入口、状态数据、兼容接口和旧实现退役，不是把全部Python文件翻译成Rust，也不是只在文档宣布分工。
原语言方向保留，具体尚未完成的迁移必须继续执行；本轮没有新增源码审计，不把此前文件清单冒称最新完整清单。

|语言/层|应承接|应该退出的情况|应继续保留|
|---|---|---|---|
|Rust Core|权威知识/版本/审校/资格、事务、入库、作业、事件与归档规则|旧语言平行写入主库或自定权威状态|成熟Rust依赖与既有有效实现|
|Python workers|OCR/解析/媒体/模型SDK及计算|直接读写主库、绕过Core的领域审批与任务完成状态|成熟算法、工具适配、必要测试和迁移工具|
|C#/Avalonia|Windows宿主、进程生命周期、诊断、窗口与入口|Welcome占位、未经验证的重复业务状态|既有桌面方向；不为迁移强制重写全部页面|
|Web/TS/JS|现成学习工作台、交互/图谱/动画/3D表现|独立权威知识库/成绩库、伪装已回流的私有状态|上游合法UI、必要适配及未来可换renderer|

外部软件自身需要的数据应标明投影、缓存或唯一用户产物，不能一概删除；第三方独立库不直接修改ArcheAxis主库。其唯一产物必须纳入导出恢复。

## 执行清单

### GOV01 唯一规范与活动入口

- 父任务：X00。范围：M0。
- 执行：核对AGENTS、项目契约、语言索引、决策账本、任务板、各执行器短指针；消除冲突和乱码，旧证据保留。
- 交付：实际入口路径、有效版本、冲突→裁决映射、待更新调用方。
- 完成验收：所有入口指同一有效规则；同一受限操作各入口结果一致，改文档不等于守卫生效。
- 既有场景：AUTH-01。

### GOV02 开发运行目录执行治理

- 父任务：X01。范围：M0先止增。
- 执行：逐项检查cargo、Python测试、浏览器、下载、打包、CI/nightly真实输出；沿现有dev入口约束路径，覆盖失败与取消。
- 交付：生产者→允许输出根→配置/脚本→例外依据清单及前后差分。
- 完成验收：默认入口不再生成根target或.hermes开发产物；路径含中文/空格、并发worktree、越界链接都有实测。
- 既有场景：PATH-01。

### GOV03 源码与资产归属盘点

- 父任务：X02、X13。范围：M0当前链；M1全仓收口。
- 执行：盘点tracked与ignored，区分运行入口、供体、兼容层、冻结资产、缓存和唯一数据；为实际文件登记去向，不先全仓搬家。
- 交付：原路径/hash→保留/适配/迁移/退役候选→目标路径→调用者→父任务。
- 完成验收：M0实际调用链无归属空白；M1登记剩余全仓资产，未知项不可标迁移完成或删除。
- 既有场景：REUSE-01。

### GOV04 清理、容量和防止再增长

- 父任务：X14。范围：X01/X02后提前；M1实测收口。
- 执行：同工具同范围盘点；核验保全后按精确授权删除可重建缓存；运行开发/打包后再次计量。
- 交付：删除逐项收据、完整范围/排除表、逻辑字节/卷空间、后续增长结果。
- 完成验收：不把19.146GiB当全仓；不整删.hermes，不碰E；唯一资料无误删；无实测不报释放量。
- 既有场景：CLEAN-01。

### GOV05 依赖、构建与发布一致性

- 父任务：X11、X13。范围：M0候选；M1规范收口。
- 执行：锁定直接/间接依赖和模型/内容许可；从现有正式入口构建、测试和打包，收敛重复脚本及工作区硬编码。
- 交付：源码树/锁文件/组件版本→CI/run→候选hash链、启动/停止/诊断/卸载数据说明。
- 完成验收：Windows非开发环境可运行；失败/跳过job不能冒充通过；依赖、路径规则在实际打包生效。
- 既有场景：RELEASE-01。

### LANG01 语言边界和迁移范围冻结

- 父任务：X00、X02、X04。范围：M0。
- 执行：逐模块判定领域权威、计算引擎、宿主、表现层；核实原决策冲突后登记，沿Rust/Python/C#/Web职责迁移。
- 交付：实际模块/入口/依赖清单与迁移台账；文件数作盘点，不作完成率。
- 完成验收：每项有源路径/hash、目标、调用方、处置类别、测试、退出和回滚；未核实不填迁移已完。
- 既有场景：AUTH-01。

### LANG02 把领域权威从旧实现迁入Rust

- 父任务：X04、X05、X07。范围：M0。
- 执行：旧Python中的审校/版本/资格、权威作业与入库规则按行为迁入Core；事务边界唯一；同义旧实现退出生产写入。
- 交付：旧→新API/领域规则对应、差分fixture、唯一写入调用链。
- 完成验收：实际主路径只经Rust权威服务；Python等第三方不能直接读写主库；旧修订、权限、事务负例通过。
- 既有场景：REVISION-01、IDENTITY-01。

### LANG03 Python保留为受控能力层

- 父任务：X02、X05、X06、X12。范围：M0代表格式；M1其余格式。
- 执行：拆开旧业务数据库访问与算法；复用OCR/解析/ASR/模型SDK，经既有worker协议交给Core，不把成熟引擎重写成Rust。
- 交付：纯计算输入输出、版本锁、进程边界、超时/取消/错误契约及损失报告。
- 完成验收：真实Core→worker→Core入库闭合；worker重启/取消不重复入库；M1各格式按原矩阵验收。
- 既有场景：JOB-01、IMPORT-01。

### LANG04 C#宿主和Web学习界面承接

- 父任务：X03、X08、X11。范围：M0。
- 执行：C#/Avalonia承担生命周期/窗口/诊断；DeepTutor/Web承担学习体验；旧bridge改Core API投影和事件，不保留平行主库。
- 交付：启动入口→Core/服务→实际学习页面→事件回收链，旧UI入口去向。
- 完成验收：Welcome不算迁移完成；实际用户学习和FSRS回流可重启读回；不强制全量Web转XAML。
- 既有场景：UI-01、HUMAN-01、FSRS-01。

### LANG05 跨语言契约与语义迁移

- 父任务：X04、X08、X09。范围：M0。
- 执行：以现有契约定义身份、版本、锚点、作业、学习/机器事件；统一序列化/错误/时间/幂等；兼容改变显式升级。
- 交付：Rust/Python/C#/Web字段映射与真实进程契约测试，保留旧行为差异及适配策略。
- 完成验收：不止各语言单测；真实宿主/worker/MCP同事件无丢失、身份无扩大、资格出口一致。
- 既有场景：EVENT-01、MACHINE-01。

### LANG06 数据与旧备份迁移

- 父任务：X05、X10。范围：M0。
- 执行：旧语言运行数据通过一致快照和新staging迁移；原件/附件/关系/修订/两侧记录全覆盖，兼容历史归档。
- 交付：旧库只读身份/hash、导出校验、逐项差分、恢复与回滚收据。
- 完成验收：真实旧11表v3恢复；旧库不变；实际用户库未切换明确未执行，合成fixture不能替代现场完成。
- 既有场景：ARCHIVE-01、MIGRATION-01。

### LANG07 旧入口退役和迁移终验

- 父任务：X02、X11、X13。范围：M0关键路径退出旧权威；M1剩余生产模块收口。
- 执行：先切默认入口并验证调用者，再移除确认无引用的重复权威分支；供体/冻结资产登记保留；删除按现有授权逐项处理。
- 交付：生产入口反查、动态调用收据、回退开关、旧模块状态、遗留缺口与下一任务。
- 完成验收：迁移完成须行为等价/有批准差异、单一权威、实际新入口、兼容恢复和回滚成立；Rust占比提高或旧文件减少不算完成。
- 既有场景：REUSE-01、RELEASE-01。

## 迁移台账必须逐模块填写

字段：源路径与hash、实际运行入口/调用者、原行为、数据权威、目标路径/语言/接口、处置方式、父任务/本切片、行为差分、兼容窗口、测试run/源码SHA、切换证据、旧入口退出条件、回滚、剩余缺口。

处置方式区分：原样保留、计算worker化、领域语义迁移、适配器接入、测试/设计供体、保留冻结、可退役候选。不能把未检查模块统一填“已吸收”。
状态：盘点→范围确定→实现→差分通过→默认入口切换→旧权威退出→验收；保留冻结独立，不计已完成迁移。
原路径已明确的优先供体包含app/integrations/deeptutor_bridge.py、app/adapters/deeptutor/authority.py、app/adapters/anki_zotero.py、app/knowledge/due_queue.py及services/python-workers。执行时核对实际HEAD与调用关系，不因该文件存在就宣称仍在生产运行。
