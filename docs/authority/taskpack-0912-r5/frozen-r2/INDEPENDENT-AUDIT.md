# 独立 GPT 审计：先看可用软件，再核对任务和蓝图

在独立会话中审计提交者提供的候选，不将实现者自评作为最终结论。输入：候选源码 SHA/tree、Windows 安装/便携包及哈希、任务状态、真实日志/样本与旧资产映射。只能对已取得的证据作结论。

## M0 必需检查

| 门 | 实际操作 | 通过证据 |
|---|---|---|
| G01 来源身份 | 对照最新远端、本地候选、依赖和安装包 | 源码/产物对应；没有把另一个 SHA 的测试抄过来 |
| G02 原件与转换 | PDF、截图、扫描/混合 PDF、静态和动态网页、个人定义进入同一路径 | 原件字节、结构、页/区域/URL 锚点、失败与损失可查；不以空文本成功 |
| G03 质量与核查 | 用已标注样本检验本地识别；真实云端查公开原始资料 | 金标/预测/指标可复算，支持/反证有定位，转载分组；没查到不直接判假 |
| G04 个人知识 | 保存无外部证据的自定义术语并用它学习/调用 | 能保存；类型与范围明确；不被网上不同定义静默覆盖 |
| G05 人类学习 | 目标→先修/路线→理解→练习/讲回→应用→复习→重启 | 真实学习事件、题目来源、开放题依据、复习恢复；不靠假进度 |
| G06 机器学习 | 真实 MCP 客户端获得范围内知识，并完成有验收标准的任务 | 调用与结果、来源、版本、失败/独立留出案例；不只 list_tools/search |
| G07 双向反馈 | 人或 AI 指出错误→复核→新版本→人类题目和机器再次调用 | 两条链拿到修正；旧题进入复核；不自动把人掌握或模型自评变成真理 |
| G08 权限与数据 | 伪造接受状态、提示注入、越界路径/链接、重复/取消/失败 | 真实入口拒绝；模型/worker 不能改主库；知识材料中的命令不成为授权 |
| G09 原子与恢复 | 重复完成 job、失败写入、重启、损坏备份和恢复候选 | 不重复 transform、不假 completed、篡改拒绝、原件及事件恢复一致 |
| G10 旧资产 | 非空迁移、关系/附件/学习记录、旧库不变 | 逐项差分和损失报告；合成 fixture 与真实用户库资格明确区分 |
| G11 Windows 可用 | 从候选包启动，选择工作区，完成上述流程，停止/重启 | 不依赖隐藏开发环境；没有只有 Welcome 页或截图演示 |
| G12 运行目录 | 运行前后 tracked/ignored 路径变化、失败退出与并发 | `.hermes` 无新写入，项目材料位置正确，短根例外真实记录 |
| G13 能力/历史 | 校验 16 CAP、蓝图 Program 与历史任务去向 | 3D、宫殿、动画等仍保留；旧名称/过时实现不覆盖最新决定 |
| G14 依赖与发布 | 检查当前相关门禁、full qualification、版本与许可清单 | 必需测试未跳过；候选字节一致；没有浮动上游冒充锁定 |

Q00 对 M0 出结论。M0 不因为尚未完成所有 Office/音视频或远期宫殿而失败，但不能宣称那些格式/能力已支持。

R2 在既有门内增加以下实际检查，不另造一套审计队列：

- G02/G05：从摘录回到原件位置，再从该位置找到笔记/引用；原件变化造成锚点失效时可见，不静默错位。
- G04/G08：个人定义接受后可学习调用，外部核查仍独立；机器提交 `verified` 或人类身份字段不能自授资格。
- G07：对已被题目和机器客户端使用的版本撤销审核，再次读取，确认两侧撤销/待复核/新版行为；模拟索引延迟，检索资格检查仍生效；重启后状态一致，历史回答不被伪改。

## M1 追加检查

- FORMAT-COVERAGE.json 中 F01–F16 每项都有实际覆盖等级、测试输入、损失与界面操作；F01–F12 核心格式须通过，F13–F15 扩展能力按真实引擎资格声明，F16 专业格式只保管/预览时不得宣称完全语义转换。
- 中文、英文、多栏、旋转/低清图片、表格数值/公式、音视频时间对齐、Canvas 附件/链接往返有代表性样本。
- R2 的 Obsidian/Vault 往返：用非空中文笔记、属性、相互链接、块/标题引用、附件及 Canvas，经导入、编辑、导出、再导入核对内容与关系；检查并发编辑冲突、未知字段保留和回滚。未实测客户端时标开放格式资格，不冒称应用完整兼容，不执行 Vault 自带脚本。
- ENHANCEMENT-COVERAGE.json 的 11 项均有裁决与承接；九锚内容缺少定义时仍可保留但不伪称科学效果，跨项目只读包仍属 F04，不加入 M0/M1 强制依赖。
- 所有 tracked 文件分类与当前入口一致；运行位置规则实测；未知 `.hermes` 文件未被整体删除；单独记录剩余资产语义审查。
- 使用中的学科资源能打开/操作；可回收事件的已回收；不能回收的标外部活动，不伪造学习成绩。
- 当前六空间能力可达、必要空态和错误处理、缩放/键盘/减少动效通过；品牌美化不替代功能。
- 对同一集成候选重新执行受影响测试和发布必需验收；原 Q00 通过不自动证明新候选。

## 审计输出

分别给出：M0 是否可用、M1 是否可用、哪些格式/功能可用、实际未测项、严重缺陷、建议修复顺序、蓝图保留情况和回滚方案。可用候选与公开发布是两个状态。

任一关键门缺证据记 NOT_VERIFIED/BLOCKED；故障记录回归属 X 任务修复，不能由审计者悄悄改完再自审通过。不得虚构签名或 CI attestation。
