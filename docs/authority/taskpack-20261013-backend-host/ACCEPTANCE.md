# 验收与证据

验收目标为真实短闭环、完整前端、小栖文本学习与个人本地使用。每项至少保留：source_sha、environment_versions、commands_and_exit_codes、artifact_hashes、limitations、rollback_handle。状态记录在现有唯一执行账本；本包初始 PLANNED 不是产品进度真值。

## 共同门槛

- 结构：22 页及全部能力细则有入口，别名打开同一视图。37／173 是导航记录，34／158 是去别名模块与功能区。
- 交互：空、加载、正常、部分、错误、离线、未配置、未授权、不兼容、未来、恢复；重试保留输入，关闭视图不是取消任务。
- 持久化：保存、重开、重启、崩溃恢复、版本冲突和布局重置不丢业务内容。
- 模型：真实连接、用途和目的地明确，无隐式转云，费用与加载未知时不造数。
- 小栖：一个共享会话及音频／重渲染所有者，资料范围可见，真实取消与记忆控制。
- 多格式：逐 store／preview／extract／edit／export／roundtrip、版本与 profile 记录；原件保存与提取分开。
- 性能：先测目标安装版基线；首次可交互、输入、拖动、空闲、峰值、隐藏回落及模型并发分别取证。
- 互联：只读关联可先行，Observer 无执行按钮；远端缺失不阻断本地。候选或 hash 不自动升级接纳、签名或真实交付。
- 素材：来源、许可、hash、尺寸、透明背景、质量档位、原始源与生产资源齐全；概念效果图与安装版截图分开。

## 五条用户旅程

1. 首次进入 → 导入或新建 → 阅读。
2. 导入 → 选段提问／提示 → 复述 → 保存反馈 → 重开 → 导出。
3. 新增模型连接 → 检查 → 模型 → 用途 → 试运行 → 保存 → 重启。
4. 首页小栖 → 阅读陪学 → 改呈现 → 停止 → 查看／纠正记忆。
5. 并排工作 → 保存布局 → 重启恢复 → 远端只读关联 → 返回本地。

开发 fixture 必须标为 SYNTHETIC 且不写正式资料、任务或绿灯资格。PASS 分别指向源码、定向测试、真实服务、安装或人工观察；不批量翻绿，不以概念图替代安装版。目标系统和已支持格式由实际构建及样例决定，不写未经采样的帧率、显存、费用或长期学习效果保证。
