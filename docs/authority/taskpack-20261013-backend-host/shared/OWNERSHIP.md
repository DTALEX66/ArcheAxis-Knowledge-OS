# 接口与仓库所有权

BE01 是主项目有限宿主合同的唯一写入任务。合同变化先记录版本、差异、兼容和消费者，不各自修改共享提案形成三个真值。前端 FE05/FE14/FE18 消费登记后的合同；GF04 适配 ASTRYN 已有八类端口。

FE18 写主项目前端槽位；GF08 只写 ASTRYN 的组件导出、呈现和交接。BE05/BE06 在主项目实现会话及记忆；GF02/GF06 实现消费与交互。前端 FE06 持有视图布局，BE02 持有其正式偏好数据。各包独立分支，跨包改动分开验证与回退。

前端材质库是共享视觉变量与组件皮肤，ASTRYN 通过导出入口和变量映射使用，不把头像控制器复制到主项目。统一模型入口仅管理主项目用途；其他产品可按真实适配范围引用共同服务，各自原生配置和凭据保持所有权。
