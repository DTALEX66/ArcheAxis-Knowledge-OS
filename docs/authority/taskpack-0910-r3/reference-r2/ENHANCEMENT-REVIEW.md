## 2. 知识状态的修正

附件中的三态只能作为审核流程的简写，不作为整个知识系统的唯一状态机。复用 X04 的原有契约，将以下维度独立表达：

- 内容类型：事实主张、用户定义、笔记、解释、假说、预测等。
- 审核流程与用户动作：候选、待审、接受、驳回、撤销及实际执行身份。
- 外部核查：未核查、支持、反驳、争议、证据不足、不适用，以及资料时间与范围。
- 使用资格：允许用于何种上下文、版本是否有效、何时需要重新核查。

AI 可以通过受控接口保存候选和建议；不能凭响应里的 `verified=true` 或 `created_by=human` 获得权限。人工接受一条个人定义，允许后续按该定义学习与调用，但不将其改写成已获外部证实的普遍事实。

“任一结论回到原始证据”应落实为：对外部事实回到原始出处；对个人定义回到用户原始输入及版本；对推导回到所用资料、方法和版本。不能给没有外部来源的用户知识编造引用。

## 3. 撤销与修订要实际影响下游

在现有版本与事件机制内补齐资格检查，不为此单独自研通用事件平台。知识 ID、修订版本、原件/锚点和审核/核查记录能够定位派生的题目、上下文、索引及机器资产。

撤销某次审核或替换某版知识后：

1. Core 先提交状态变化；后续受控检索/上下文输出检查当前资格，即使索引刷新尚未完成，也不能继续以旧的有效状态返回。
2. 已生成的人类题目、机器上下文和缓存标记过期或待复核。受控活动任务在下一次工具读取或结果入库时检查依赖版本。
3. 保留原件、旧回答与学习历史，标明旧回答引用了哪个失效版本；不假装能撤回模型已经生成的所有文字。
4. 独立 GPT 审计使用一个已被人类题目与机器客户端引用的知识版本：撤销后再次请求，确认两侧看到撤销/新版；检查重启和异步索引延迟路径。

未来对外只读包包含包/知识版本、哈希、来源、核查与用户接受状态、适用范围、导出时间和重新校验策略。消费者按策略重新校验，失效对象不得再作为当前有效事实。完全离线的外部副本无法被服务端即时撤回，必须展示快照时间及未重新校验状态；需要新鲜资格的调用拒绝或降级。个人定义仍可按明确类型和范围导出使用。

## 4. Obsidian：做文件互操作，不复制整个产品

官方说明确认 Vault 是本地 Markdown 文件夹，可以被其他编辑器修改；因此，复用现有文件导入导出是适合本项目的连接方式。这是基于官方文档作出的集成判断，还需要目标机器验收。[Obsidian 数据存储](https://obsidian.md/help/data-storage)

普通 Markdown 可读不代表 Obsidian 全部链接都兼容：官方文档区分 Markdown 链接、Wikilink、标题链接及特有块引用。X12 必须逐项声明支持范围，未支持语法保留原文并报损失。[Obsidian 内部链接](https://help.obsidian.md/Linking+notes+and+files/Internal+links)

Canvas 优先遵循公开的 JSON Canvas 1.0；该格式可供任意工具实现，相关资源采用 MIT。节点、位置、边和文件引用都属于要保留的数据，不能只导出一段纯文本。公开格式的许可不等同于 Obsidian 应用代码的许可。[JSON Canvas](https://jsoncanvas.org/)、[格式规范](https://jsoncanvas.org/spec/1.0/)

Obsidian 官方许可页说明应用可免费使用，同时保留应用内容与代码的权利。这里不把应用当成可任意复制的开源代码，也不要求购买 Sync/Publish 作为闭环前提。[Obsidian 许可说明](https://obsidian.md/license)

M1 的最小非空往返样本：两篇相互引用的中文笔记、标题/块引用、附件、属性和一份有节点与边的 Canvas。导入→在 ArcheAxis 编辑→导出到独立测试 Vault→按实际可用客户端复核→再次导入，检查正文、关系、来源、搜索与回滚。未知属性、未支持节点或插件扩展保留原件，禁止静默丢弃后宣称无损。

外部编辑通过新候选/修订进入 Core。使用导出时的基线哈希识别并发修改；有冲突不直接覆盖，也不把外部文件里的审核标记当实际审核动作。首版采用显式导入/导出，无需增加实时双写同步系统。

读取 Vault 不执行其插件或模板脚本，不访问越界链接目标，不依赖修改 Obsidian 内部数据库。真实 Vault、附件及应用配置不是清理缓存。官方说明 Windows 全局配置使用 `%APPDATA%\Obsidian\`；若实际运行客户端，沿用 X01 的路径与例外核对，不能声称修改 ArcheAxis 运行根就重定向了外部应用全部写入。[Obsidian 数据存储](https://obsidian.md/help/data-storage)

没有实测客户端时标记“开放格式测试通过，Obsidian 应用往返未验证”。此项不阻塞 M0；在 M1 中如实显示资格。
