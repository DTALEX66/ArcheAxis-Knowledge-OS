## 恢复顺序

1. 切到 `main` 并执行 `git pull --ff-only`；确认干净工作树。
2. 阅读本文件、最新 `workspace/intake/` 记录和 `docs/PROJECT_STATUS.md`；不要凭历史手工总结推断当前事实。
3. 为任何隔离验证设置项目内 `COGNITIVE_DATA_DIR`，先执行 `python -m app.runtime_entrypoint migrate`，再启动服务或测试。
4. 桌面开发使用仓库 `.venv`；release 验证必须确认使用 bundled Python，而非 PATH Python。
5. 修改前先读相关实现和测试；修改后运行最小定向门禁，冻结 diff 后跑必要完整门禁，推送后只认新 exact-SHA CI。
6. 不自动删除 `.hermes/`、虚拟环境、runtime data、日志或 build 输出；只有在确认可再生成且用户授权时才清理。
