# 01｜B线总流程

## B线定义

B线是核心认知系统线，不依赖 Obsidian，不处理美化和 Vault 写入。

B线包含三个项目：

```text
Inspiration-Research
Knowledge-Base
Cognitive-OS
```

## B线总目标

```text
研究输入
  ↓
结构化知识
  ↓
上下文包
  ↓
任务包
  ↓
运行时执行
  ↓
Trace / Eval / MachineLesson
```

## B线完整流程

```text
[1] 外部输入
    GitHub / 网页 / 文档 / 人工想法 / 课程摘要 / 技术调研
        ↓

[2] Inspiration-Research
    Research Note
    Source Evidence
    Open Source Profile
    Intake Card
    Engineering Contract
        ↓

[3] Knowledge-Base
    Document
    Source
    Chunk
    Knowledge Card
    Machine Knowledge Unit
    ContextPack
    TaskPack
        ↓

[4] Cognitive-OS
    Ingest
    Route
    Retrieve
    Compile Task
    Permission Check
    Execute
    Trace
    Evaluate
    MachineLesson
        ↓

[5] 反馈回流
    MachineLesson → Knowledge-Base
    FailurePattern → Inspiration-Research
    NextConstraint → TaskPack Policy
```

## B线第一阶段只做 MVP

只做：

```text
Research Note → Intake Card → Engineering Contract
Document → ContextPack → TaskPack
TaskPack → Cognitive-OS /run
/run → ExecutionTrace → EvalResult → MachineLesson
```

先不做：

```text
Obsidian
Canvas
Dashboard
插件
复杂 Web UI
自动执行系统命令
多 Agent 自主协作
完整向量数据库
```
