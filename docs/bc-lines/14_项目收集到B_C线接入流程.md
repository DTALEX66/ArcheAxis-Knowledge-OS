# 14｜项目收集到 B+C 线接入流程

## 总流程

```text
每日项目收集
  ↓
GitHub AI 项目筛选表
  ↓
OpenSourceProjectProfile
  ↓
IntakeCard
  ↓
EngineeringContract
  ↓
Knowledge-Base experimental
  ↓
TaskPack
  ↓
Cognitive-OS /run
  ↓
ExecutionTrace / MachineLesson
```

## 第 1 步：项目进入候选池

来源：

```text
每日9点推送
GitHub trending
手动收集
历史项目清单
别人推荐
AI调研结果
```

输出：

```text
github_project_candidate.json
```

## 第 2 步：生成 OpenSourceProjectProfile

字段：

```text
项目名
类别
用途
适合接入层
吸收方式
许可证风险
安全风险
维护状态
是否本地优先
是否省 Token
是否提升效率
```

## 第 3 步：生成 IntakeCard

只有满足以下条件才生成：

```text
与当前系统有关
能服务 IR / KB / Cognitive-OS / Obsidian-Assistance
风险可控
不是纯概念
不是许可证高风险
```

## 第 4 步：生成 EngineeringContract

EngineeringContract 必须包含：

```text
目标
交付物
禁止事项
验收标准
目标仓库
风险等级
```

## 第 5 步：进入 KB experimental

进入 experimental 后：

```text
不能直接 active
不能自动改核心
不能自动安装依赖
必须人工审核
```

## 第 6 步：C线联调

C线用 fixtures 测试：

```text
open_source_project_profile
intake_card
engineering_contract
taskpack
trace
lesson
```

## 第 7 步：决定吸收方式

```text
S级：直接 Adapter 开发
A级：补调研后开发
B级：只参考设计
C级：暂缓
Reject：拒绝
```
