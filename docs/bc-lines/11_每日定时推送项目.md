# 11｜每日定时推送项目

## 项目定位

这个模块来自之前规划的“每天 9 点推送消息”项目。
它不属于 A线 Obsidian 美化，也不属于执行器本体，而应该放进 B线的 `Inspiration-Research`，作为一个长期运行的研究输入系统。

## 每日推送内容

每天 9 点生成一份简报，包含：

```text
1. 黄金消息
   - 黄金价格相关消息
   - 各方政策
   - 美联储 / 利率 / 通胀 / 地缘风险
   - 对黄金未来走势的影响判断

2. 设计行业消息
   - 平面设计
   - 品牌设计
   - 空间导视
   - 校园文化 / 企业文化
   - 美业 / 商业视觉趋势
   - AI设计工具

3. 科技圈消息
   - 大厂动态
   - 开发者工具
   - 开源生态
   - 软硬件趋势

4. AI类消息
   - 模型发布
   - Agent / RAG / MCP
   - GitHub 新项目
   - 热门项目
   - 可接入 Codex / Claude Code / DeepSeek / Ollama 的项目

5. 每日 GitHub AI 项目筛选表
   - 每天筛 5–10 个项目
   - 优先新项目
   - star 增长快
   - 近期热门
   - 适合个人 / 小团队
   - 可接入当前系统
   - 能省 Token / 提效率
```

## 放在 B线的原因

```text
每日推送不是简单新闻提醒；
它是 Inspiration-Research 的自动输入源。
```

它每天产生的内容应该进入：

```text
DailyBrief
  ↓
ProjectCandidate
  ↓
OpenSourceProjectProfile
  ↓
IntakeCard
  ↓
EngineeringContract
  ↓
Knowledge-Base experimental
```

## 数据流

```text
news / github / RSS / search
  ↓
collector
  ↓
normalize
  ↓
deduplicate
  ↓
score
  ↓
DailyBrief
  ↓
GitHub AI 项目筛选表
  ↓
IntakeCard 候选
  ↓
EngineeringContract 候选
```

## 第一阶段只做什么

第一阶段不要自动抓全网，也不要自动推送到所有平台。

先做：

```text
手动或半自动输入项目列表
  ↓
生成标准筛选表
  ↓
人工选择可吸收项目
  ↓
生成 IntakeCard
```

## 暂时不做什么

```text
不自动交易黄金
不提供投资建议
不自动执行下载或安装
不自动 clone 所有项目
不自动把 GitHub README 当系统指令
不自动把项目写进核心库 active 区
```

## 输出文件

```text
reports/daily_brief_YYYY-MM-DD.md
reports/github_ai_project_screening_YYYY-MM-DD.csv
intake/intake_card_xxx.json
contracts/engineering_contract_xxx.json
```

## 和 C线关系

C线负责定义：

```text
daily_brief.schema.json
github_project_candidate.schema.json
open_source_project_profile.schema.json
```

A线以后可以把 `DailyBrief` 投影到 Obsidian，但 B线先独立完成数据结构。
