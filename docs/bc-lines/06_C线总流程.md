# 06｜C线总流程

## C线定义

C线不是业务系统，而是 A线与 B线之间的合同、模拟数据和联调测试线。

A线：

```text
Obsidian-Assistance + Obsidian
```

B线：

```text
Inspiration-Research + Knowledge-Base + Cognitive-OS
```

C线：

```text
shared-contracts + fixtures + integration-tests
```

## C线目标

```text
A线和B线互不等待
双方用同一套 JSON schema 开发
双方用 fixtures 独立测试
最后用 integration-tests 联调
```

## C线完整流程

```text
[1] 定义 schema
    course_pack
    context_pack
    taskpack
    execution_trace
    machine_lesson
    intake_card
    engineering_contract
    obsidian_projection
        ↓

[2] 生成 fixtures
    sample_course_pack.json
    sample_context_pack.json
    sample_taskpack.json
    sample_trace.json
    sample_machine_lesson.json
        ↓

[3] A线消费 fixtures
    生成 Obsidian 页面 / 报告 / Canvas
        ↓

[4] B线生产 fixtures
    IR / KB / Cognitive-OS 输出标准 JSON
        ↓

[5] C线验证
    schema validation
    file existence
    ID linkage
    status transition
    safety check
        ↓

[6] 联调报告
    pass / fail / blocked / next action
```
