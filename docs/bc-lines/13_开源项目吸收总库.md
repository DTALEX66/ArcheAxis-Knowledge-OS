# 13｜开源项目吸收总库

## 总原则

这些项目不是全部直接接入核心，而是按四种方式处理：

```text
直接用：可以进入核心工具链或一线 Adapter
Adapter：只通过适配器接入，不污染核心
只参考：学习设计，不作为依赖
暂缓/安全研究：只收集，不自动执行
```
