# 05｜B线开发阶段与验收

## Phase B0：建立骨架

### 目标

```text
三项目能独立启动
shared-contracts 能被三项目共同引用
```

### 验收

```text
schemas 能被校验
fixtures 能被读取
README 明确边界
```

---

## Phase B1：IR 最小研究闭环

### 流程

```text
Research Note
  ↓
Intake Card
  ↓
Engineering Contract
```

### 验收

```text
输入一段调研内容
能生成 intake_card.json
能生成 engineering_contract.json
```

---

## Phase B2：KB 最小知识闭环

### 流程

```text
Document
  ↓
Source
  ↓
ContextPack
  ↓
TaskPack
```

### 验收

```text
能读取 sample_intake_card.json
能生成 sample_context_pack.json
能生成 sample_taskpack.json
```

---

## Phase B3：Cognitive-OS 最小运行闭环

### 流程

```text
TaskPack
  ↓
/run
  ↓
ExecutionTrace
  ↓
EvalResult
  ↓
MachineLesson
```

### 验收

```text
输入 sample_taskpack.json
输出 execution_trace.json
输出 machine_lesson.json
高风险工具 blocked
safe_write 默认 dry-run
```

---

## Phase B4：B线整体联调

### 流程

```text
Research Note
→ Intake Card
→ Engineering Contract
→ ContextPack
→ TaskPack
→ ExecutionTrace
→ MachineLesson
```

### 验收

```text
一条模拟研究任务能跑完整链路
每个资产有 ID
每个资产可追溯上游
失败能生成 FailurePattern
```
