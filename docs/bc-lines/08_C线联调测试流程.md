# 08｜C线联调测试流程

## 测试 1：B线输出 TaskPack，A线渲染

```text
B线输出 sample_taskpack.json
  ↓
A线读取 TaskPack
  ↓
生成 Obsidian TaskPack 页面
  ↓
C线校验页面存在、字段完整
```

## 测试 2：B线输出 Trace，A线渲染报告

```text
Cognitive-OS 输出 sample_execution_trace.json
  ↓
A线生成 Trace Report
  ↓
C线校验 trace_id / task_id 关联正确
```

## 测试 3：B线输出 MachineLesson，A线生成经验页

```text
MachineLesson
  ↓
Obsidian Machine Lesson 页面
  ↓
校验 lesson / anti_pattern / next_constraint
```

## 测试 4：A线输出 CoursePack，B线吸收

```text
A线输出 sample_course_pack.json
  ↓
KB 转 Document / Card / ContextPack
  ↓
C线校验 source_ids / cards / sections
```

## 测试 5：IR 输出 EngineeringContract，KB 生成 TaskPack

```text
IR EngineeringContract
  ↓
KB TaskPack
  ↓
Cognitive-OS /run
  ↓
Trace / Lesson
```

## 测试 6：安全阻断

```text
输入含 shell/delete/token/private key 的 TaskPack
  ↓
Cognitive-OS PermissionDecision
  ↓
blocked / review
  ↓
不得输出执行成功状态
```
