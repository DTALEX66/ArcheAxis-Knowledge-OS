## 产品和对象

为 Windows 桌面端的 ArcheAxis Knowledge／星环知识系统设计一套本地优先的个人知识、研究与人机双向学习工作台。保留现有 Tauri + React 宿主、Rust Core 唯一持久化写入者、对象 ID、来源/版本、草稿保护、22 个历史页面身份、五种主题和既有小栖资产。不要把 DeepTutor / OpenMAIC 整个网站、独立导航或数据库直接套进来。

先设计共同外壳和 5 个相互连贯的任务场景：

1. 工作台：继续上次任务、到期复习、最近资料、导入；空库不显示虚构计数。
2. 资料与知识：同一对象的正文、原件、来源、版本和关联；选中段落可按需问小栖或对照原件，普通保存直接可用。
3. 研究与比较：一个问题下比较多个来源、自己的判断和待确认点，保留出处和分歧。
4. 学习与表达：主题或资料形成学习大纲；同一学习场景可展示阅读、讲解、课堂、练习、反馈和复习。保留 OpenMAIC 的讲解／测验／互动／项目实践目标及 DeepTutor 的书籍／路径／练习／伴读体验，但明确未接入与实验状态。
5. AI 助手：对话只是入口之一，独立呈现任何领域的 AI 工作知识候选、采用与授权、实际使用、反馈修订、独立复测；外部原始上下文留在来源系统。

## 核心交互

- 全局导航只负责切换主要领域；菜单负责低频命令，对象标签只表示打开对象，页内切换只影响当前对象/任务，不重复堆叠四套导航。
- 当前材料、课程、题目、笔记、图谱节点共享可追溯的对象与版本。显示所用材料和来源更新状态；旧产物允许保留历史或经用户选择生成新版。
- 课堂以内容为主舞台，目录、来源、问答和小栖按需展开；阅读时可由选区唤出助手，辅导、用户自评和独立复测分开呈现。
- 知识星图可表达真实已建立关系，提供局部聚焦、搜索列表及打开原对象；不能让示意粒子或模型推测冒充已确认知识关系。
- 数据、离线、失败、等待、未知、未实现、来源过期与导出损失等状态要真实、可理解；不得为追求完整截图虚构实际数据或效果。

## 视觉与窗口

使用提供的项目原始知识星系／关系扇出参考和已纠正的黑灰白界面作为视觉依据：深黑、炭灰、灰白文字、白色主要操作，局部暖色光，细腻克制的玻璃层次。避免此前偏蓝／青色的误导方向。阅读和课堂正文优先，装饰不遮字；动效可降低或关闭。不得用生成的人物替换现有小栖形象。

参考本仓[历史 UI 支线对照](仓库分支界面对照.md)：借鉴快速搜索、紧凑主导航、按需对象导航和来源检查器。两条历史支线是 Avalonia 前后版本，其共用样板是示例图，不是现行 UI 或已验收截图；保留当前 Tauri／React 宿主，按当前产品范围重构界面。

只设计一套流式布局；分别展示普通非最大化窗口和 1920×1080 满屏，其他尺寸自然适配，极小窗口整体缩放需实际验证。小窗口折叠可选侧栏，保证可读正文、主舞台和输入。兼顾键盘、焦点、对比度与错误提示。
