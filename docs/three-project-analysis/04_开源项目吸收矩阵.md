# 可吸收 / 可直接套用开源项目矩阵

## S级：可以直接进入核心或优先做 Adapter

### MarkItDown

用途：

```text
文件转 Markdown
PDF / Word / PPT / Excel / HTML / 图片 / 音频 / CSV 等输入预处理
```

接法：

```text
shared/adapters/converters/markitdown_adapter.py
```

原则：

```text
只输出 markdown + metadata + source record
不直接写核心数据库
```

### Docling

用途：

```text
高质量 PDF / 文档解析
页面布局
阅读顺序
表格结构
公式 / 代码 / 图片理解
```

接法：

```text
Docling = 精修模式
MarkItDown = 快速模式
```

### sqlite-vec

用途：

```text
本地向量检索
SQLite + FTS5 的增强
```

接法：

```text
SQLite + FTS5 = 默认搜索
sqlite-vec = 可选向量增强
Qdrant / Chroma = 后期可选
```

### MCP reference servers

用途：

```text
学习 MCP 工具 schema
学习工具注册与调用方式
学习权限边界
```

原则：

```text
不直接照搬
自己做 KB MCP namespace
```
