## 0. 摘要

ArcheAxis 不是"AI 帮人学"，也不是"把资料喂给 AI"，而是**人和机器围绕同一份知识资产形成双向学习闭环**：

- 同一份知识同时经历**人类学习链**（理解 → 练习 → 遗忘 → 复习 → 应用 → 掌握）与**机器学习链**（解析 → 图谱 → 记忆 → 推理 → 实践 → 技能 → 掌握）；
- 两边的掌握结果重新汇聚为可验证、可持续进化、可随时调用的知识能力；
- 掌握差距（Mastery Gap）自动触发方向的流转：**AI 强于人 → 教人；人强于 AI → 蒸馏人**。

目前未发现一个成熟开源项目同时完整覆盖
Evidence → Human Mastery → Machine Memory → Procedural Skill → Tool Invocation → Experience Feedback → 再学习
的整条双向链。这是 ArcheAxis 的机会窗口。

## 3. 分方向项目深挖

### 3.1 AI Personal OS 方向

**taOS ⭐⭐⭐⭐⭐（强烈关注）**

理念：Your AI / Your Hardware / Your Data——AI、数据、模型、机器都属于你。

架构：Desktop UI → Agent Runtime → Memory System → Knowledge Graph → Model Router → App Store → File System → Multi Agent。

最值得吸收：
1. **Temporal Knowledge Graph**：知识节点 + 时间 + 变化 + 冲突检测（旧知识自动失效，如 Photoshop 2025 UXP → 2027 API 变化）。
2. **Zero-loss Archive**：所有数据永久保存、不可丢失、可追溯（对应 ArcheAxis 原件库/证据库/学习库/机器库）。

**OpenDAN Personal AI OS ⭐⭐⭐⭐⭐**

定位：个人 AI 基础设施。架构：AI OS Kernel → Agent → Skill → Knowledge → Device → Service。

适合 ArcheAxis：吸收 **Agent Marketplace** 思想 → 未来 ArcheAxis Plugin Store（PDF 专家 / 设计专家 / 代码专家 / 学习专家 / 研究专家）。

**OpenSwarm ⭐⭐⭐⭐**

定位：Local-first Operating System for AI Agents。核心：多 Agent 协作（Coordination Layer + Shared Memory）。

对 ArcheAxis：Manager Agent 分治 —— Research / Learning / Design / Coding / Memory / Review Agent 各自独立，由协调层统一。

**Agent OS ⭐⭐⭐⭐⭐（与 WORK-LAB 高度同构）**

重点：不是聊天，而是 AI 完成任务闭环：Plan → Execute → Verify → Recover → Approve → Ship。
与 WORK-LAB（任务 → CI → 审核 → 门禁 → 观测）互补。

### 3.2 Memory OS 方向

**MemoryOS ⭐⭐⭐⭐⭐（学术路线）**

四层：Storage → Updating → Retrieval → Generation。主张 AI 拥有类人记忆：短期 / 中期 / 长期 / 人格记忆。

对应 ArcheAxis Memory Layer 建议：
- L1 工作记忆（当前任务上下文）
- L2 项目记忆（WORK-LAB / DESIGN-LAB）
- L3 专业记忆（设计 / 编程知识）
- L4 长期人格记忆（用户习惯、方法论）

**MemOS ⭐⭐⭐⭐⭐（工业路线）**

重点：Memory API + Graph Memory + Multi-modal Memory + Skill Reuse。建议 ArcheAxis 增加 **Memory Kernel** 而非简单 RAG。

**Hermes Memory OS ⭐⭐⭐⭐⭐（与当前 Hermes 组合最契合）**

7 层记忆：Workspace → Sessions → Facts → Knowledge → Wiki → Vector → Recall。与 Hermes + ArcheAxis 组合非常契合。

### 3.3 Agent OS / 桌面 AI OS 方向

- **Open Interpreter 方向**：AI 控制电脑（Agent → Computer → Software），对应 DESIGN-LAB：AI 控制 Photoshop / Illustrator / Blender。
- **AI Desktop Environment**：未来 Windows + AI Layer + Agent Desktop，值得长期关注。

### 3.4 Research OS 方向

- **AI Scientist**：Paper → Hypothesis → Experiment → Result → Knowledge 的科研自动化管线。ArcheAxis 借鉴：研究管线（搜索论文 → 提取观点 → 建知识图谱 → 生成学习路径 → 形成个人知识资产）。
- **Paperless AI Research Brain**：PDF → OCR → Embedding → Citation → Knowledge Graph，对应证据库。

### 3.5 人类学习 Workspace 方向（本轮新发现）

**DeepTutor ⭐⭐⭐⭐⭐（人类学习工作台首要参考）**

Agent-Native Learning Workspace：Chat / Quiz / Research / Visualize / Solve / Mastery Path 共用 Agent runtime；知识库、书籍、Notebook、题库、Memory 上下文跨工作流连续存在。
两层插件体系：Tools（单次调用）+ Capabilities（多阶段能力流程），由 ChatOrchestrator 路由。
覆盖 ArcheAxis 的"资料 → 研究 → 教学 → 问答 → 练习 → Mastery Path"。

**Studyield ⭐⭐⭐⭐⭐（"检测人是否学会"）**

Knowledge Graph + Flashcards + Quiz + SRS + Research + Multi-Agent Problem Solving + **Teach-Back Evaluation**。
Teach-Back：不是 AI 讲给你，而是你讲给 AI，AI 判断你理解到什么程度。
→ 启示：Mastery = 能解释 + 能回忆 + 能迁移 + 能解决问题，不是 Reading/Notes/RAG。

**OpenCognition ⭐⭐⭐⭐**

与 LLM 学习 → 自动保存学习成果 → Knowledge Graph → Spaced Repetition → Feynman Learning；通过 MCP 让 LLM 成为 Socratic 学习伙伴。
理念核心：**学习活动本身就是知识生产过程**（资料 → 人机讨论 → 理解改变 → 学习产物 → 重新进入知识系统）。

**OpenTutor ⭐⭐⭐⭐**

FSRS 4.5 + Knowledge Graph + Concept Mastery + prerequisite relationships + weak areas + learning path。
升级点：知识图谱节点挂掌握状态（mastery / recall_probability / last_practice / weak_points / evidence；机器侧 confidence / source_count / verified / skill_refs）。

**OATutor / pyBKT / pyKT ⭐⭐⭐⭐（掌握度计算）**

- OATutor：Bayesian Knowledge Tracing 估计技能掌握程度。
- pyBKT：从连续答题行为估计认知掌握程度。
- pyKT：DKT / SAKT / GKT / AKT / LPKT / QIKT / forgetting-aware / uncertainty-aware / graph knowledge tracing。
→ Human Knowledge Model 不应是"学过/没学过"，而是 Knowledge State Vector（understanding / recall / transfer / application / confidence / forgetting_risk / misconceptions / evidence_count）。

**FSRS ⭐⭐⭐⭐（机器反过来学习"你怎么遗忘"）**

FSRS optimizer 根据个人历史复习数据学习该用户的记忆模式并调整复习参数。
→ 第一次真正出现"双向学习"：人学习知识 → 系统观察记忆行为 → 机器学习"这个人如何学习" → 调整策略 → 人学得更好。
→ ArcheAxis 至少应有三个模型：**Knowledge Model / Learner Model / Machine Model**。

**Tutor MCP ⭐⭐⭐⭐（学习状态与模型解耦）**

把学习者状态、复习安排、Session Memory、误解记录、Metacognition、教学决策做成 MCP Runtime，让任意 MCP-capable LLM 成为长期自适应导师。
→ 关键：**学习状态属于 ArcheAxis Learner Model，不属于 LLM**；换模型 ≠ 换掉"你已学到哪里"。模型只是临时老师。

**adaptive-knowledge-graph ⭐⭐⭐**

Knowledge Graph + Local LLM + BKT + IRT + KG-RAG + 动态测评。
→ 知识图谱还能承担：课程结构、先修关系、能力诊断、题目映射、学习路径。

### 3.6 人 → 机器（Human Distillation）方向（本轮核心新发现）

**colleague-skill / awesome-human-distillation ⭐⭐⭐⭐⭐**

从真实专家留下的多源痕迹（对话、文字、声音）中提取工作经验 / 判断规则 / 思维方式 / 专业方法 / 决策模式，转成可调用 Agent Skill（Work Skill / Persona 两层）。
→ 解决"人的隐性知识怎么进入机器"：人掌握 → 实践 → 判断 → 经验 → 系统采访/观察/分析 → 提取隐性知识 → 规则 → Procedure → Skill → AI 学会。

**AI 采访你的场景**

设计经验（"为什么这张招商海报不行"）→ 系统提问 → 记录 Candidate Principle → 跨案例验证 → Expert Rule → Design Skill。
→ 建议正式命名 ArcheAxis 模块：**Human Knowledge Distillation Engine**。

### 3.7 机器知识方向（本轮新发现）

**ReMe ⭐⭐⭐⭐⭐（机器学习侧关键项目）**

Conversation / Resource / Experience → Markdown Memory / Wiki Links / Knowledge / Procedures / Reflections；人和 Agent 都可编辑；支持成功路径 / 失败路径 / 可复用过程 / 周期反思。
→ 机器侧升级链：知道是什么 → 知道何时用 → 知道如何完成 → 有验证过的工作流（Knowledge → Procedure → Capability）。

**OpenViking ⭐⭐⭐⭐**

Agent context 三分法：**Resource / Memory / Skill**，统一到 viking:// 虚拟文件系统；recall trace 可解释"为什么召回某知识"。
→ 可转译成 ArcheAxis：Source（原件）/ Knowledge（已验证）/ Memory（AI 经历与认知）/ Skill（可执行能力）。

**Cognee ⭐⭐⭐⭐⭐（机器知识层参考）**

raw data → ECL（Extract / Cognify / Load）→ Knowledge Graph + Vector；长期 Agent memory、graph reasoning、ontology、traceability。
→ 资料 ≠ embedding：资料 → 实体 → 概念 → 关系 → 本体 → 知识图 → Agent reasoning。

**Graphiti ⭐⭐⭐⭐⭐（知识必须有时间）**

Temporal Knowledge Graph：知识什么时候成立、后来是否变化、来源、当前哪个事实有效。
→ Knowledge Node 应含：fact + valid_from/valid_to + source + version + supersedes + contradicts + confidence。

**Meta Knowledge Graph（Neo4j Labs，2026）⭐⭐⭐⭐⭐**

Self-learning memory for AI agents：Neo4j + MCP + Agent lifecycle capture + knowledge injection，harness-agnostic。
→ 完全符合 ArcheAxis：Hermes / Codex / Claude Code / OpenCode → MCP → ArcheAxis Knowledge Core。

**agent-memory-mcp ⭐⭐⭐⭐（Canonical Knowledge）**

区分 Raw Memory 与 Canonical Knowledge：只有确认后的高价值内容才晋升；支持知识治理、过期标记、验证、合并、temporal validity。
→ 防止"聊天、猜测、错误答案、临时信息"污染知识库。
→ 知识晋升机制：RAW → MEMORY → CANDIDATE → VERIFIED → CANONICAL；冲突 → Review → Superseded → V2。类似代码 PR 的 **Versioned Knowledge**。

### 3.8 机器技能与自进化方向（本轮新发现）

**Corpus2Skill ⭐⭐⭐⭐⭐（关键桥梁）**

Documents → Hierarchical Skill Directory：整个语料库蒸馏成层级 Agent Skills，Agent 像浏览目录一样逐层导航。
→ 机器"掌握知识" = 知识 → Procedure → Skill → Callable Capability（SKILL.md / Workflow / MCP Tool / Agent Capability / Tool Contract）。

**SkillRL ⭐⭐⭐⭐**

把 Agent 历史经验从原始轨迹抽象成 Hierarchical Skill Library，与后续训练/任务共同演化。
→ ArcheAxis 机器侧不能只有 Memory Engine，还必须有 **Skill Learning Engine**。

**ReasoningBank ⭐⭐⭐⭐**

从 successful + failed trajectories 提取 reasoning memory 供未来任务调用。
→ 与人"做题 → 错误 → 分析 → 经验 → 避免"同构。ArcheAxis 应有 Experience → Knowledge Pipeline。

**EvolveR ⭐⭐⭐⭐**

完整经验生命周期：Execute → Trajectory → Reflect → Abstract Principle → Store → Retrieve → Next Execution。
→ 机器学习不必须重训权重：Context / Memory / Knowledge / Reasoning / Skill / Workflow 即可实现持续学习。

**Voyager ⭐⭐⭐⭐（机器"掌握技能"范式）**

探索 → 完成任务 → 形成技能 → 进入 Skill Library → 后续组合调用（lifelong learning agent）。
→ AI 何时算真正掌握？不是"能回答"，而是"在正确场景选择 + 能执行 + 得到正确结果 + 以后能复用"。

**Skill Evolution 生态 ⭐⭐⭐⭐**

Awesome-Agent-Skill-Evolution / Awesome-Dynamic-Agent-Skills / Skill Surveys：Skill 本身能创建、评估、修复、组合、演化。
→ SKILL.md 不是终点：Skill v1 → Use → Measure → Fail → Analyze → Patch → Verify → Skill v2。

**Hermes Agent Self-Evolution（Nous Research）⭐⭐⭐⭐⭐（与当前体系直接相关）**

DSPy + GEPA：从执行轨迹分析失败原因 → 生成 Skill/Prompt 候选改进 → 测试与约束门禁选优。Skill 文件优化已实现，Tool 描述/系统 Prompt/代码优化规划中。
→ 闭环：ArcheAxis Knowledge Core → Skills → Hermes → Execution → Experience → 评估 → Hermes Self-Evolution → 更新记忆/知识/技能 → 再执行。

## 4. 核心架构吸收点

### 4.1 双向学习定义（双链）

原始世界（文档/网页/视频/书籍/项目/实践）→ Evidence/Source 层（证据化、版本化）→ 分叉为两条链：

- **人类学习循环**：理解/阅读/观看 → 概念/知识图谱 → 学习路径/课程 → 问答/练习/教授 AI → 间隔复习 → 实践/应用 → 能力验证
- **机器学习循环**：抽取/解析 → Knowledge Graph → Semantic Memory → Episodic Memory → Procedural Memory → Skill Distillation → Skill Verification

两链汇聚 → **KNOWLEDGE CORE（已验证知识资产）** → 再回写实践 → 新证据。

### 4.2 人类掌握模型（M 等级）

M0 见过 → M1 能识别 → M2 能回忆 → M3 能解释 → M4 能解决标准问题 → M5 能迁移解决新问题 → M6 能创造/教别人 → M7 专家化。

### 4.3 机器掌握模型（K 等级）

K0 Raw（有原资料）→ K1 Indexed（可检索）→ K2 Structured（已转知识结构）→ K3 Reasonable（可推理）→ K4 Procedural（知道执行步骤）→ K5 Callable（已生成 Skill/Tool/Workflow）→ K6 Verified（技能经验证）→ K7 Adaptive（可据失败更新）→ K8 Transferable（可跨场景复用）。

### 4.4 Dual Mastery（双轴知识节点）

同一知识节点挂两组状态：

- Human：understanding / recall / transfer / application / mastery / misconceptions / evidence
- Machine：structured / verified / proceduralized / skillified / confidence / skill_refs / memory_refs

示例：Photoshop Smart Object —— Human Mastery=0.42（AI 会但你不会 → AI 教你）；Human=Expert & Machine=K2（你比 AI 懂 → 采访你 → 捕获经验 → 验证 → 沉淀机器知识 → 提取 Skill）。

### 4.5 三轴模型（+ Evidence Maturity）

Knowledge Node = Human Mastery + Machine Mastery + **Evidence Maturity**。
人和 AI 都会犯错：两个都"掌握"了过时知识时，Evidence=Outdated 必须报警。

### 4.6 Mastery Gap Engine（知识不平衡检测器）

Δ = Machine mastery − Human mastery：
- Δ > 0 → Teach Human（生成课程/解释/练习/Teach-back/项目/Mastery Test）
- Δ < 0 → Distill Human（启动 Expert Distillation：采访/案例分析/规则抽象/Candidate Skill/AI 执行测试/用户审核/正式 Skill）
- Δ ≈ 0 → Collaborative Practice

### 4.7 知识生命周期与晋升机制

RAW → INGESTED → PARSED → EVIDENCED → STRUCTURED → VERIFIED → LEARNABLE → HUMAN_LEARNING → HUMAN_MASTERED → MACHINE_LEARNED → PROCEDURALIZED → SKILLIFIED → CALLABLE → EXECUTED → VALIDATED → EVOLVED

晋升：RAW → MEMORY → CANDIDATE → VERIFIED → CANONICAL（V1 → 冲突 → Review → Superseded → V2）。

### 4.8 时序知识

事实必须带 valid_from / valid_to / source / version / supersedes / contradicts / confidence，否则 AI 学得越久，旧知识污染越严重。

### 4.9 外部化 vs 内部化学习

- 机器 Level A — Externalized Learning（成本低）：Memory / Knowledge / Graph / Skill / Prompt / Workflow / Tool。V1/V2 重点。
- 机器 Level B — Internalized Learning（成本高）：SFT / LoRA / Knowledge Distillation / RL / Model Adapter。
- 人同样两层：外部记忆（笔记/卡片/练习）→ 反复调用 → 内化。→ 镜像结构：**Dual Knowledge Internalization**（同一知识分别记录 human internalization 与 machine internalization）。

### 4.10 "调用知识"五种方式

Recall（检索事实）→ Reason（基于知识推理）→ Teach（用于教人）→ Create（用于生产新内容）→ Act（调用工具真实执行）。
最后一层才是 Knowledge → Capability（如 Adobe 印刷规范：识别文件 → 读取规格 → 检查出血/颜色模式/字体 → 修复 → Preflight → 导出）。
