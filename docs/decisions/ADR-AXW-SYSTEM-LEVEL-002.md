# ADR-AXW-SYSTEM-LEVEL-002 — 系统级定位与反漂移边界

- **状态**：Accepted（Owner 任务包 v1 2026-08-11）
- **日期**：2026-08-12
- **决策**：产品是"本地优先、原件保全、证据可追溯、开放互操作的人机双向学习与可信知识治理工作台"——系统级（一体化数据与体验系统），但**不等于**通用操作系统、通用 Agent Runtime、自治工作流平台或多 Agent 产品。
- **理由**：Owner 裁决要求同时防止"缩窄成轻量 Obsidian/PDF 工作台"和"扩张成通用 Agent OS"两个方向。
- **后果**：固定一级空间 Workspace/Library/Evidence/Learning/AI Assets/Settings；聊天/执行器/Agent 只能受控可选 Adapter；不得用"系统级"恢复 OS/Runtime/Agent Platform 为产品名。
- **关联**：PRODUCT_IDENTITY_V2.md、AUTHORITY_AND_STATUS_RULES_V1.md、AXW-1202
