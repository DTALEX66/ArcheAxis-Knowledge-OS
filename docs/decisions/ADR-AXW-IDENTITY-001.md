# ADR-AXW-IDENTITY-001 — 产品身份与命名契约

- **状态**：Accepted（Owner 任务包 v1 2026-08-11）
- **日期**：2026-08-12
- **决策**：主品牌 `ArcheAxis`；英文产品名 `ArcheAxis Knowledge`；中文产品名 `星环知识平台`；固定短句"同一份可信知识，人学得更深，AI 用得更准。"；旧名只留 Legacy/Migration 语境。
- **理由**：Owner 明确裁决，防止项目被错误缩窄/扩张；命名是产品身份的机器真相。
- **后果**：所有新文档首次中文产品名必须"星环知识平台（ArcheAxis Knowledge）"；技术身份（repo/包/CLI/bundle）为 planned，需分阶段授权迁移。
- **关联**：NAMING_CONTRACT_V1.md、PRODUCT_IDENTITY_V2.md、AXW-1201/1208
