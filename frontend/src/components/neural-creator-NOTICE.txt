AAOS adaptation: presentation/neuralGraph.ts and components/ConstellationGraph.*.
The AAOS adaptation retains its existing SVG semantic object renderer, fixed
Core references, filters, lists and canonical persistence. It replaces upstream
quadratic force-layout iteration and index seeds with deterministic layout,
stable identities, indexed adjacency and bounded display state. Star points are
procedurally generated. No upstream astronomical star tables, sample content,
App shell, import scripts, agent skill or localStorage persistence are copied.
