## 归位结果

AI侧将任何领域AI工作中可复用的内容、成果、问题、错误、解决办法、方法、工作流、规范与更新提炼为知识候选。成功、失败、假设和更新均可进入，分别保留来源、状态、版本及适用/禁用条件；编程只是例子，不设领域白名单。

沿现有Document/AiAsset及原CL/J维度完成候选、去重/冲突/适用性审查、准入、授权任务使用、反馈纠正、更新/失效、独立复测与重启导出恢复。规范或工作流被保存为知识，不自动修改项目规则/Agent配置或获得执行权限。人类侧继续原知识与学习闭环，两侧按权限共享知识。

原始对话、执行轨迹与运行记忆仍由来源系统管理；必要定位和版本随授权知识候选保留。跨来源获取与自动提炼能力、知识治理、实际消费和效果分开验收，不从产品目标推导全项目/全Agent采集权限。工作区会话是交互入口，不能代替AI侧知识生命周期。
