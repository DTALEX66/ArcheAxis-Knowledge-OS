# Design System: 星环知识系统 ArcheAxis Knowledge

本文件服务2026-10-29 STITCH交接，与01-STITCH完整提示词共同使用。本轮设计基准是黑灰、白色透明玻璃、局部关系光效。用户要求优先于通用设计技能默认值：不做移动端/多套尺寸版，不强制营销Hero、单一色点或每个组件循环动画。

## 1. Visual Theme & Atmosphere

安静、清楚、可组合的桌面知识工作空间；日常工作密度5/10、布局变化4/10、动效3/10。正文与真实行动优先，空间图作为局部探索。顶部菜单、浮动工作区、对象Tab、按需工具、小栖和紧凑Dock共同构成桌面。五主入口为工作台、资料与知识、研究与比较、学习与表达、AI助手；资源、系统、任务为工具。

## 2. Color Palette & Roles

| 颜色 | 值 | 用途 |
| --- | --- | --- |
| 中性近黑 | #080808 | 应用底；不用蓝黑 |
| 黑灰工作面 | #101010 | 主工作区背景 |
| 烟灰工具面 | #191919 | 浮动/辅助工具 |
| 抬升炭灰 | #242424 | hover、选中面及局部层次 |
| 白色主文 | #F2F2F0 | 标题、正文、主行动 |
| 中性次文 | #B4B4B0 | 说明与次级信息 |
| 弱元信息 | #898985 | 不承担关键状态的元信息 |
| 细白边 | rgba(255,255,255,.14) | 结构边缘；焦点更清楚 |
| 局部绿色 | #7AB897 | 真实成功/连接语义；带文字图标 |
| 局部玫瑰 | #D38FA3 | 少量流体摘要/明确异常语义 |
| 局部暖金 | #C8B27B | 选中关系/警告及少量星核光 |
| 局部淡紫 | #B4A5C9 | 区分关系分类；不用于满屏霓虹 |

局部流体摘要允许温和混色，主行动仍白色。禁蓝、藏青、青蓝铺底/描边/光圈，禁止蓝紫霓虹整体风格。旧主题ID与保存偏好不删除，本轮效果稿不输出蓝色主题变体。

## 3. Typography Rules

- 中文本地无衬线：Microsoft YaHei UI、PingFang SC、Noto Sans CJK SC及现有系统回退，不依赖远程字体。
- 标签14–16px，正文16px/1.6，标题20–28px。层级通过字重、间距和明暗形成，不靠巨型口号。
- 阅读行长约30–42个中文字符。数字表格采用tabular数字，必要代码/身份用本地等宽字体。
- 中文为主；必要专名保留原文，不铺满双语微小文字。关键操作与未知/错误不得使用过小低对比元信息样式。

## 4. Component Stylings

- 面板圆角16–20px，控件8–12px；4/8px间距体系，主要区域留白16–24px。命中区40–44逻辑px。
- 玻璃背景blur约6–10px并可关闭；正文近实色。灰白边缘、高光、轻阴影、浅透视形成层次，不叠多层blur。
- 白色主按钮、透明/边框次按钮，清楚hover/focus/pressed/disabled，按压反馈轻微；不做光晕按钮墙。
- 卡片仅在资料叠放、空间分类或层次有意义时使用；长列表采用分隔与对齐，不每行三层卡。
- 输入label清楚、错误就近、未提交状态保留。读取中保留旧正文与局部骨架，错误不伪为空。
- 一对象标题、一保存状态、一当前主动作。工程ID、SHA、原始JSON和详细诊断进入详情。

## 5. Layout Principles

同一套流式布局，默认普通稍小非最大化窗口与1920×1080满屏两个评审状态。自然伸缩、主任务优先、辅助视图可收起，极小时统一缩放并恢复100%。不单独设计手机/平板或多档比例，不给普通窗新钉死尺寸。

支持移动、调大小、停靠、分栏、浮动、铺满/还原、关闭、固定及保存组合。配方安排现场，不执行能力。窗口/工具跟随或固定对象版本；关闭留草稿和已提交任务，缺工具留引用。原生最大化、内部铺满与图谱缩放分别处理。

## 6. Motion & Interaction

常规过渡120–240ms，transform/opacity及适量弹簧。星核低频局部呼吸，关系依真实选择展开与高亮，白色叠卡选中轻抬升。正文、按钮和整窗不循环缩放。

装饰粒子不制造数据、不穿正文；输入和拖动时降噪。隐藏/离屏/最小化停绘，有暂停、减少动态和同范围列表。Canvas显示尺寸/DPR与界面坐标一致，不以动画承诺未测FPS。

语义节点/列表能用键盘选择和打开；hover不自动导航，明确打开激活原Tab，返回保留筛选与视口。命令面板、中文IME、右键、Esc和焦点恢复均可用。

## 7. State & Accessibility

至少设计读取、空、部分/截断、陈旧、未知、冲突、取消请求、停止未知、离线、缺依赖、未配置、恢复、未来规划。每个状态有明确下一步并保留已有内容。

文字/焦点对比可读，状态有标签与图标，不只靠颜色。图谱有等效列表，关闭人物不丢会话。普通保存不依赖联网/模型/事实审批。设计提案与已实现/已验证事实分开。

## 8. Anti-Patterns

不做蓝色仪表盘、宇宙壁纸铺底、霓虹光环、过度磨砂、营销Hero、巨大口号、emoji导航、十几个常驻栏目、22页按钮墙或186项能力墙；不照抄作者品牌/统计/作品和视频控件。

不以随机粒子冒充知识节点，不以图形相似冒充Canvas往返，不以“已安装”冒充“已授权执行”，不编造学习率/准确率/接口成功。不同大小不造不同产品；同一文档不复制多个写入编辑器。
