# Knowledge-Base\n\nB线核心资产层。A线（人类学习）与 B线（机器知识）双主线系统。\n\n## 目录结构\n\n```\nKnowledge-Base/\n  documents/           # 文档资产\n  sources/             # 来源管理\n  chunks/              # 文本分块\n  search/              # FTS5 搜索\n  cards/               # 知识卡片\n  context_pack/        # ContextPack 生成\n  taskpack/            # TaskPack 生成\n  machine_knowledge/   # 机器知识单元\n  reviews/             # 复习调度\n  mistakes/            # 错题管理\n  tests/\n```\n\n## 双主线\n\n| 线 | 用途 | 核心资产 |\n|----|------|----------|\n| A线 | 人类学习 | Document → Card → Review → Mistake → Mastery |\n| B线 | 机器知识 | ContextPack → TaskPack → MachineKnowledgeUnit |\n\n## 安全边界\n\n- 不直接执行工具\n- 不直接写 Obsidian Vault\n- 不联网抓取全部内容\n- 外部内容经过 raw → quarantined → approved\n
