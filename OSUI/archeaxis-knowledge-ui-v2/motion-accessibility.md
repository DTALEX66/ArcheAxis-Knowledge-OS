# 动效与无障碍交付说明

## 动效 storyboard

| 场景 | 正常模式 | 减少动效 |
| --- | --- | --- |
| 一级空间切换 | 180–240ms 淡入与 8px 内位移 | 立即切换 |
| Inspector 内容更新 | 锚点高亮后 180–220ms 内容替换 | 静态描边 + 立即替换 |
| 原件锚点定位 | 滚动定位，1.2–1.8 秒非闪烁描边 | 直接跳转，保留静态描边 |
| 复习证据揭示 | 160–220ms 淡入 | 立即显示 |
| 未来课件播放 | 可暂停的逐步揭示 | 静态分镜 / 逐步文本 |
| 空间记忆移动 | 可中断的短距离聚焦 | 2D 地图定位 |

不使用持续浮动、自动旋转、背景粒子、庆祝动效或不可中断镜头运动。

## 可访问性

- 原生按钮、输入和链接提供键盘路径及 `:focus-visible`。
- `prefers-reduced-motion` 已在 `app.css` 中覆盖；未来页面提供结构性替代，而不依赖动画表达状态。
- `forced-colors: active` 已在 `liquid-glass.css` 中覆盖：玻璃、阴影与背景光场自动回退为系统 Canvas、CanvasText 与 Highlight，保证高对比环境中的边界、选中态和焦点可辨识。
- Canvas 提供“列表视图”入口；空间记忆明确提供 2D 地图与文字路线。
- 所有能力状态同时给出文字和形状标记；冲突、支持和背景不只依赖颜色。
- 内容面使用实色、正文有可读行长；窄屏移除多窗格并改用空间标签切换。
