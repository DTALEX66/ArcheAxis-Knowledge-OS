# 公开研究 DOI 声明离线比对候选

本模块是未注册的后端候选。它接收调用方提供的两组现有 Core v1 回执、各自选中
的 `hit_id` 和 `source_original` 回执，不启动检索、模型、网络请求或子进程，不写入
数据库或文件；这不建立操作系统网络隔离。调用方须自行保管原回执与完整原件。
它没有接入 Core、宿主或界面。

每侧必须在已完成或部分完成的回执中唯一找到 `research` 渠道的选中 hit，绑定
`workspace_id`、`restore_epoch`、`request_id`、provider、原 hit ID 和该渠道的
`raw_source`。`source_original` 中的 `source_id` / `sha256` 必须与该引用相同，
并对实际解码字节重算 SHA-256。历史和当前 epoch 可以不同，但两个工作区声明须相同。
当前范围限定两个不同 request：现行 Crossref 仅在 OpenAlex 未取得结果时回退。
这些都是调用方提供的字段，SHA 一致只能说明提供的字节自洽，不认证 Core、回执、
原件、外部服务、材料权限或工作区身份。两份完全伪造但自洽的输入仍可能产生候选。

原件最多 128 KiB，gzip 展开后也不超过 128 KiB；每个原始结果集最多 512 条，
回执最多四个渠道且每渠道最多三个 hit。OpenAlex 原结果集中的每项都须具有可比较的
规范 `W` ID；任何重复 W，或任意两项存在的 DOI 完全相同／仅大小写不同，均拒绝。
未选中项的缺失或 null DOI 可保留为未知；存在但不符合限定的 DOI 使该结果集未知。
Crossref 的每项须有受支持 DOI，整个结果集任何重复或大小写冲突也拒绝。选中项从对应
原响应保留 OpenAlex 原始 DOI URL 声明及 Crossref 原始 DOI 声明。
允许的 DOI 是有界 ASCII 子集，遇缺失、错误、危险路径、百分号编码、Unicode DOI、
其他未支持格式、重复 W/相同或大小写冲突的 DOI、原件缺失或篡改时为 `UNKNOWN`。
不会根据标题推断，不对大小写、URI 编码或 Unicode 归一化作等价推断；受限范围之外
可能是真实合法 DOI，也只报告未知。严格 JSON 解码后，只有将 OpenAlex 声明的固定
`https://doi.org/` 前缀去掉，其 DOI 标识与 Crossref 的 DOI 字段逐字一致，才给
`POSSIBLE_SAME_DECLARED_DOI`：这是可能属于同一作品的提示，不合并来源、不保证发表
事实，也不能把转载或同一作品当作独立证据。不同声明返回 `UNKNOWN / DECLARED_DOI_DIFFERENT`，
只表示声明不同或未建立同一关系，不能据此推断一定是不同作品。

默认输出只有固定状态和原因，不回显查询、标题、正文或具体身份。仅调用方显式传入
`include_details=True` 时，返回每侧 provider、请求与工作区声明、原 hit ID、原件
引用、SHA 检查状态及符合限定的 DOI 原声明；这些详情仍是私有数据，不能自动写日志
或上传。输入中不合格的 DOI 不会作为详情回显，原始字节仍由调用方保留。

为复用当前严格 JSON/gzip 行为，模块只读取本目录 `public_research.py` 的固定字节
（18,998 字节，SHA-256 `cb54f07bb86263fe264809f22817fccb9b7f6705cb26c3a6efde7baa1a3fc321`），
从该字节加载其五个解析函数，不执行 worker 的网络入口或传输模块。校验失败或文件
缺失即 `UNKNOWN`；读取前后检查有限祖先的符号链接／已观察到的 Windows reparse 属性，
拒绝多硬链接，并比较文件句柄与路径的设备、inode、长度及修改时间。未来更改 worker
后须重新审查并更新固定身份。解析继承 64 层本地
上限、UTF-8/16/32、重复键/非有限数拒绝与解压上限，不声称有限浮点完全无损。
上述检查无法排除所有路径替换或竞争；固定哈希与内存编译不是进程沙箱或已安装程序资格。
同步源文件读取不具备系统级超时。运行该候选的宿主仍须控制解释器/源码身份、并发和截止
时间，并避免字节码写入。
