# 小栖角色资产目录

- `STATE-ASSET-INDEX.json` — 角色资产清单（版本、来源、状态映射、呈现档的登记处）。
  v1 = 原创内联 SVG 基线（ACTIVE，永远保留）；v2 = MINIMAX 升级位图（PENDING_EXTERNAL，
  回传后落 `upgraded/v1/` 并逐张登记哈希与权利条款）。
- `upgraded/v1/` — 升级资产落库目录（等待外部回传；空目录以 .gitkeep 占位）。
- `concepts/` — 视觉方向概念图（场景/界面概念，含烘焙文字与角标；仅参考，永不进运行时）。
- `../original/`、`../third-party/` — 既有来源声明目录，规则不变。

规则：

1. 任何新资产先登记清单再使用；未登记的文件不得被运行时引用。
2. 权利与来源：本项目产出的角色资产为原创；外部产出物按执行方协议登记，不得作为
   “本项目原创”记录；**禁止把真实人物照片/截图裁作产品人物资产**（验收红线）。
3. 表情与口型：只允许“真实文本事件的离散帧”驱动；音素口型未实现，不得宣称。
4. 外观升级不删除旧版本：渲染失败或权利争议时回退到 v1 内联 SVG。
