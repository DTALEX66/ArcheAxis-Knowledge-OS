# 原创素材来源

本目录只存放本项目**原创**绘制或撰写的角色素材。

- `../../src/avatar/xiaoqi-avatar.ts`：角色"小栖"的初始视觉，由本项目以 SVG 形状与配色手写生成，未使用任何第三方角色模型、贴图、字体或素材文件。
- 状态到视觉特征的映射表在 `../../src/avatar/state-visuals.ts`，同样为原创撰写。
- 许可证：随本仓库代码，标注为 `UNLICENSED`（未对外授权），见根目录 `package.json`。

引入任何第三方形象、模型权重或素材时，必须：

1. 先取得可复核的官方许可证全文，并放入 `../third-party/` 的许可记录；
2. 区分代码许可与权重/素材许可，含糊者一律标 `UNKNOWN` 并不得落地；
3. 不下载、不提交模型权重（根目录 `.gitignore` 已排除 `*.safetensors`、`*.gguf`）。

当前 `assets/third-party/` 为空（仅有 `.gitkeep`），即：本项目未包含任何第三方素材。
